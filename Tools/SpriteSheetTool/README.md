# 스프라이트 시트 툴

스프라이트 시트 png를 불러와 재생해 보고, 프레임을 넣고 빼고, 위치를 손본 뒤 새 시트나 프레임별 png로 저장하는 독립 툴. Unity와 상관없다. 설치할 것도 없다.

## 실행
- `index.html`을 **Chrome이나 Edge**로 연다(더블클릭). 파일 하나에 다 들어 있다.
- [시트 열기…]를 누르거나 png를 창에 끌어다 놓는다.
  - 한 장 = 시트. 여러 장을 한꺼번에 고르면 한 장 = 한 프레임(이름 순서)으로 한 줄 시트를 만든다(PixelLab `이름_0.png`… 확인용).
- 로컬 서버로 띄우면 주소에 `?src=그림주소`를 붙여 바로 열 수도 있다.
  ```powershell
  cd I:\workshop\apogirl\apogirl; python -m http.server 8765
  ```
  → `http://127.0.0.1:8765/Tools/SpriteSheetTool/index.html?src=/ArtInbox/sprites11/player_summer_bat_attack_sheet.png`

## 하는 일
- **자동 감지**: 배경(투명 / 마젠타 `#ff00ff` 같은 단색 — 귀퉁이 색으로 판단)과 가로·세로 칸 수, 칸마다 그림 위치(노란 상자). 칸 경계를 넘은 그림(대걸레 끝·발)은 이어진 덩어리째 가장 많이 겹친 칸에 붙는다.
- **재생**: fps 조절, 고정 바닥선(빨간 선, 숫자로 고치거나 [자동] = 그림 아래 끝 중앙값), 가운데 세로선, 어니언 스킨(이전 1~3장 붉게, 다음 1장 파랗게).
- **칸 손보기**: 칸 수·칸 크기·여백·칸 사이 간격을 고치고 [이 칸으로 프레임 다시 뽑기].
- **프레임 편집**: 오프셋(무대를 끌거나 화살표 1px, Shift 10px), 복제·복사/붙여넣기·삭제, 순서 바꾸기(띠에서 끌기 또는 Alt+←→). 원본 시트 칸을 더블클릭하면 그 칸을 프레임으로 다시 넣는다. 되돌리기 Ctrl+Z.
  - 도우미: [발을 바닥선에], [머리 기준 가로 맞춤](좌우 흔들림 줄이기, 선택 프레임 기준). 공격처럼 몸이 움직여야 하는 동작에는 쓰지 않는다.
- **저장**: 가로 칸 수·칸 크기(바로 고르기 `96×78` 등)·배율([맞춤] = 모든 프레임이 칸에 들어가는 최대 배율)·바닥 여백. 원본의 (칸 가운데, 바닥선)이 출력 칸의 (가운데, 아래 − 바닥 여백)에 온다.
  - [시트 png 저장] → `이름_sheet.png`
  - [프레임별 png 저장] → 고른 폴더에 `이름_0.png`, `이름_1.png` … (폴더를 고를 수 없는 브라우저는 zip)
- **편집 기록 저장/불러오기**: 칸 설정·프레임 순서·오프셋·출력 설정을 json으로. 같은 시트를 다시 열고 불러오면 이어서 고칠 수 있다.

## 단축키
Space 재생/멈춤 · `,` `.` 이전/다음 프레임 · 화살표 오프셋 · Ctrl+D 복제 · Del 삭제 · Ctrl+C/V 복사/뒤에 붙여넣기(Shift = 앞에) · Alt+←→ 순서 · Ctrl+Z/Y.
