# 동료 역할 재기획: 역할 = 학교의 방 + 적성 + 동료 탐험

> 상태: **기획안 (2안 + 적성으로 결정, 동료 탐험 추가)**. 2026-11-22.
> 관련: [PROPOSAL_CD_DEPTH_EXPANSION.md](PROPOSAL_CD_DEPTH_EXPANSION.md) C.2·C.5·D절, [UI_REDESIGN_PROPOSAL.md](UI_REDESIGN_PROPOSAL.md) 10절(학교 단면도).
> 이전 판의 1안(방 하나에 역할 하나)과 3안(방에 사람을 앉히기)은 이 문서 끝 "버린 안"에 한 줄씩 남긴다.

---

## 0. 한눈에 보기

| 무엇 | 한 줄 요약 |
|---|---|
| **역할 6개** | 경비·정찰(기본) + 간호·살림·공부·위로. 역할마다 **방 묶음**이 있다 |
| **방 = 자리** | 묶음 가운데 열린 방이 있어야 맡길 수 있고, 동료는 그 방에 가 있다. 열린 방이 늘수록 효과가 커진다 |
| **적성** | 동료마다 잘 맞는 역할이 1~2개 있다. 맡기면 효과 ×1.25, 함께한 시간 호감 +1 더, 전용 말풍선 |
| **함께한 시간** | 주인공이 그 방의 스케줄을 하면, 그 방을 맡은 동료의 호감이 오른다 |
| **동료 탐험** | 동료마다 주 1~2번 낮에 혼자 나가 물자를 구해 온다. 그동안 자리를 비운다 |
| **자리 비움** | 나간 동안에는 그 동료의 역할 효과도, 함께한 시간 호감도 없다 |

**바라는 경험**
- 거점을 넓힐수록 동료가 설 곳이 생긴다.
- 같은 방에서 지내는 시간이 관계가 된다.
- 동료도 자기 몫을 하러 밖에 나가고, 그 빈자리가 느껴진다.

---

## 1. 왜 바꾸나 (지금의 문제)

- **방과 맞지 않는다.** 요리 담당은 급식실(할 일 없음)에 서고 요리 수업은 가사실에서 한다. 정비 담당은 창고에 서는데 공학 공부는 과학실에서 한다.
- **방이 열려도 달라지는 게 없다.** 음악실을 찾지 않았어도 분위기 메이커를 맡길 수 있다.
- **함께 지낸다는 느낌이 없다.** 그 방을 맡은 동료가 곁에 있어도 아무 일이 없다.
- **호감 단계가 닿지 않는다.** 지금 콘텐츠를 모두 골라도 동료 호감이 7~46이라 20·50·80 단계가 거의 쓰이지 않는다.
- **동료가 거점에만 있다.** 물자는 주인공 혼자 구해 오므로, 동료는 먹기만 하는 사람으로 느껴진다.
- **이벤트가 없는 역할 이름을 쓴다.** `student`, `lookout`, `scout`가 그렇다.

## 2. 역할과 방 묶음

### 2.1 역할 표

| 역할 | 방 묶음 (서는 순서) | 효과 (방 1개, 관계 보통 기준) | 함께하는 스케줄 |
|---|---|---|---|
| **경비** (기본) | 현관 → 교무실 | 밤 습격·낮 침입 방어 +6 | 바리케이드 보강·출입구 보강·함정 설치·깡통 경보장치·야간 경계·창문 가림막 |
| **정찰** (기본) | 옥상 → 방송실 | 탐험 스트레스 −10%, 수색 속도 +10% | 옥상에서 하늘 보기·빗물통·옥상 텃밭·무전 청취·발전기 수리 |
| 간호 | 보건실 | 감염·선생님 병세 −1/주 | 응급처치 독학·부상 치료·감염 처치·선생님 돌보기 |
| 살림 | 가사실 → 급식실 → 창고 | 이틀에 한 번 식량 1 절약 | 요리 수업·목발 만들기·의족·야간 작업 |
| 공부 | 교실 → 도서실 → 과학실 | 교육 성장 +8% | 국어·인문·생존 기술·야간 자습·도현 과외·명상·과학·공학·물 정수 |
| 위로 | 음악실 → 체육관 | 휴식 회복 +10% | 음악 수업·호신술 훈련 |

- 경비와 정찰은 방(현관·옥상)이 처음부터 열려 있어 **처음부터 맡길 수 있다.**
- 나머지 넷은 묶음 가운데 **한 방이라도 열려야** 역할 단추에 나온다.
- 한 역할을 여러 명에게 맡길 수 있다. 같은 방에 함께 서고, 효과는 더해진다.

### 2.2 열린 방 수 배율

- 묶음 안에서 열린 방이 하나 늘 때마다 효과가 **+25%** 커진다. 1개 ×1.0, 2개 ×1.25, 3개 ×1.5.
- 예: 공부 역할은 교실만 열렸을 때 +8%, 도서실·과학실까지 열리면 +12%.
- 탐험으로 방을 찾고 시설을 여는 일이 그대로 역할 성장으로 이어진다.

### 2.3 서는 자리

- 동료는 묶음에서 **처음 열린 방**에 선다. 같은 역할이 두 명 이상이면 다음 열린 방으로 나눠 선다.
- 밤에는 거처로 돌아간다. 다만 경비는 밤에도 현관에 남는다(지금과 같다).
- 다쳤으면 거처에 누워 있다.

### 2.4 효과에 곱하는 것 (지금 규칙 유지 + 적성)

효과 = 기본 × 열린 방 배율 × 관계 단계 배율 × 스트레스 배율 × 적성 배율

| 배율 | 값 |
|---|---|
| 관계 단계 | 호감 음수 ×0.5 / 0~49 ×1 / 50~79 ×1.25 / 80 이상 ×1.5 |
| 스트레스 70 이상 | ×0.5 |
| 적성 | ×1.25 |
| 다침·자리 비움 | 0 (효과 없음) |

정수 효과(식량·감염)는 지난번에 고친 "소수점 누적"으로 평균이 정확히 맞는다.

## 3. 적성

| 동료 | 적성 역할 | 까닭 (설정) |
|---|---|---|
| 박 선생님 | **간호** | 보건 선생님 |
| 도현 | **경비** | 몸으로 지키려 한다 (경계 시설에 민감, C.5) |
| 송예지 | **위로**·공부 | 말없이 옆에 있어 주는 사람, 조용한 방을 좋아한다 |
| 최하린 | **살림**·정찰 | 예전 동네 사정을 알고, 손이 빠르다 |
| 선배 | **정찰**·위로 | 길을 안다, 방송반에서 기타를 쳤다 (CD 1번) |

적성 역할을 맡기면 다음이 붙는다.
- 효과 ×1.25.
- 함께한 시간 호감 +1 더(4절). 주 상한도 2에서 3으로 오른다.
- 전용 말풍선 2~3개. 역할을 맡길 때와 함께한 시간에 가끔 나온다.
- 인물 서랍에는 "보건실이 편해 보인다" 같은 **느낌 문구로만** 보인다. "적성"이라는 말과 숫자는 보여 주지 않는다.

## 4. 함께한 시간 (호감)

- 주인공이 방 R의 스케줄을 하면, 그 슬롯에 **방 R에 있는** 동료의 호감이 **+1** 오른다. 적성 역할이면 +2.
- 한 사람당 **주 2까지** 오른다. 적성 역할이면 주 3까지.
- 그 주의 돌봄 기록(`care`)도 이번 주로 바뀐다. 그래서 "오래 돌보지 않음" 감소(C.5)가 생기지 않는다.
- **오르지 않는 때:** 그 동료가 다쳤을 때, 그리고 **그 슬롯에 탐험을 나가 자리를 비웠을 때**(5절)다.
- 실행 중에는 그 방에서 동료 머리 위에 말풍선이 뜨고, 결과 한 줄에 "도현과 함께 했다"가 나온다.
- 기대치는 52주 동안 동료 한 명당 +30~60이다. 50 단계는 대략 2막 후반, 80은 적성 역할을 꾸준히 할 때 4막에 닿는다.
- 하린처럼 가해자였던 인물도 오르는 양은 같다. 대신 말풍선은 거리를 둔 말투로 쓴다. 용서를 강요하지 않는다(13장).

## 5. 동료 탐험 (새로 추가)

### 5.1 흐름

1. **계획 단계(주 시작):** 동료마다 이번 주에 나갈 **낮 슬롯 1~2개**와 **갈 곳**이 정해진다.
   - 계획 보드의 그날 낮 칸 위에 동료 얼굴 배지와 갈 곳이 작게 표시된다.
   - 예: "수 낮 · 도현 → 편의점".
2. **실행 중:** 그날 아침 동료가 단면도에서 현관으로 걸어 나가 사라진다. 그 방은 빈다.
3. **귀환(그날 밤 시작):** 동료가 현관으로 들어와 제 방으로 간다. 머리 위 말풍선에 구해 온 물자가 뜬다(예: "통조림 3개 구했어"). 실행 결과 한 줄에도 나온다.
4. **주간 결산(일기장):** "이번 주 동료들이 구해 온 것"이 한 줄로 모인다.

### 5.2 횟수와 나가지 않는 때

| 항목 | 규칙 |
|---|---|
| 기본 횟수 | 주 1번. 40% 확률로 2번 |
| 정찰 역할 | 늘 2번 |
| 나가지 않는 동료 | 다침, 스트레스 70 이상, 호감 음수(아직 믿지 못해 따로 움직이지 않음) |
| 하루 상한 | 같은 날 낮에 많아야 2명 (거점이 너무 비지 않게) |
| 겹치지 않기 | 주인공이 낮 탐험을 나가는 날에는 동료가 많아야 1명만 나간다 |
| 밤 | 동료는 밤에 나가지 않는다. 그래서 경비의 밤 방어는 동료 탐험 때문에 빠지지 않는다 |
| 1주차 | 창고에 갇혀 있는 동안(`Confined`)은 없다 |

### 5.3 갈 곳과 물자

- **갈 곳:** 주인공이 한 번이라도 가 본 지역 가운데서 고른다. 거점에 가장 모자란 자원(식량·식수·자재·의약품)을 많이 주는 곳을 고를 확률이 높다.
- **물자:** 그 지역의 자원 산출 표에서 주인공 헤드리스 탐험의 **약 40%**를 굴린다. 정찰 역할 적성(선배·하린)이면 +30%.
- **기호품:** 10% 확률로 그 동료 자신이나 다른 사람의 기호품을 하나 가져온다. "예지한테 주려고 주웠어" 같은 말풍선이 붙는다.
- **위험:**
  - 6% 확률로 다쳐서 돌아온다. 정찰 역할이면 4%. 다치면 부상 규칙(의약품 치료)을 따른다.
  - 나간 동료는 스트레스 +8, 포만·수분이 더 빠진다.
  - **죽거나 돌아오지 않는 일은 없다.** 동료의 생사는 이야기 이벤트만 다룬다.
- **돌아온 뒤 호감:** 구해 온 물자를 받으면 따로 오르지 않는다. 동료 자신의 일이므로 함께한 시간과 겹치지 않게 한다.

### 5.4 자리를 비운 동안 (요청 사항)

| 무엇 | 나간 슬롯에서 |
|---|---|
| 함께한 시간 호감 | **없음.** 주인공이 그 방 스케줄을 해도 오르지 않는다. 결과 한 줄에 "도현은 탐험을 나가 자리에 없었다"가 나온다 |
| 슬롯 단위 역할 효과 (교육 성장·휴식 회복·판정 보너스·탐험 스트레스) | **없음** |
| 하루 단위 효과 (살림의 식량 절약) | 그날은 없음 (저녁을 준비하지 못했다) |
| 주 단위 효과 (간호의 감염·병세 감소) | 나간 날만큼 줄어든다. 하루 나가면 6/7, 이틀이면 5/7. 소수점 누적으로 평균을 맞춘다 |
| 낮 침입 방어 (경비) | 경비가 나간 날 낮에 침입이 오면 경비 보정이 없다 |
| 밤 습격 방어 (경비) | 영향 없음 (밤에는 돌아와 있다) |
| 단면도 | 그 방이 비고, 방 이름 옆에 "외출" 표시가 붙는다 |

### 5.5 플레이어가 할 수 있는 것

- **붙잡기:** 인물 서랍에서 동료마다 "이번 주는 남아 줘"를 켤 수 있다.
  - 그 주에는 나가지 않아, 물자가 없는 대신 자리를 지킨다.
  - 3주 연속 붙잡으면 그 동료의 스트레스가 조금 오른다(+3, "답답하다").
- **날짜 바꾸기:** 계획 보드에서 동료 배지를 다른 날 낮으로 옮길 수 있다. 하루 상한(2명)은 지켜야 한다.
- 정해진 갈 곳은 바꿀 수 없다. 동료가 스스로 판단한다.

## 6. 화면에서 보이는 것

| 화면 | 바뀌는 것 |
|---|---|
| 허브 거점 칸 (동료 단추) | 순환이 **열린 역할만** 경비 → 정찰 → 간호 → 살림 → 공부 → 위로 → 없음. 단추 툴팁에 역할 효과와 "지금 서 있는 방" |
| 학교 단면도 | 동료가 역할 방에 선다. 나가는 날 아침에는 현관으로 걸어 나가고, 밤에 돌아온다. 함께한 시간 말풍선, 귀환 말풍선 |
| 계획 보드 | 동료가 나가는 낮 칸 위에 얼굴 배지와 갈 곳, 끌어서 날짜 바꾸기 |
| 인물 서랍 | 역할·서 있는 방·이번 주 외출 날짜, "이번 주는 남아 줘" 토글, 적성 느낌 문구 |
| 실행 결과 한 줄 | "도현과 함께 했다" / "도현은 자리에 없었다" / "선배가 돌아왔다: 자재 4" |
| 주간 결산 일기장 | "동료들이 구해 온 것" 한 줄 |

화면 문자열은 모두 `ko.json`에 둔다. 말풍선 문구는 동료마다 데이터로 둔다.

## 7. 데이터와 규칙 (구현 메모)

| 영역 | 내용 |
|---|---|
| `RoleDef` | `Rooms`(방 묶음, 순서), `Actions`는 방에서 끌어온다(`hub_section.json`의 방 `Actions`를 코어로 옮기거나 `RoleDef.RoomActions`에 복사). 효과 `Modifiers`는 그대로 |
| 방 열림 | 코어가 알 수 있게 방 → 시설 ID / 수색 플래그 표를 `m6_systems.json`에 둔다. 지금은 단면도 설정에만 있다 |
| 적성 | `BalanceConfig.Aptitudes`(동료 → 역할 1~2개), `AptitudeMultiplier` 1.25, `AptitudeAffinityBonus` 1 |
| 함께한 시간 | `RoomBondRules`(가칭). `WeekRunner.ExecuteNextSlot`에서 슬롯 행동이 방 행동이면 호감을 올린다. 수치는 `RoomCompanionAffinity` 1, `RoomCompanionWeeklyCap` 2·3 |
| 동료 탐험 | `CompanionOutingRules`(가칭). `PrepareWeek`에서 일정을 정하고, 그날 낮 슬롯 시작에 "나감", 그날 밤 슬롯 시작에 "귀환 + 물자"를 처리한다. RNG는 별도 스트림(`Seed ^ 상수`)이라 기존 판의 난수 순서를 흔들지 않는다 |
| 자리 비움 | `NpcState.AwayThisSlot`(런타임) → `TraitRules.Sum`의 역할 합산과 함께한 시간에서 뺀다 |
| 세이브 | v7 → v8. `NpcState`에 이번 주 외출 일정·붙잡기·연속 붙잡은 주를 넣는다. 예전 역할을 바꾼다: 요리·정비 → 살림, 공부 친구 → 공부, 분위기 메이커 → 위로, 경비·정찰·간호는 그대로 |
| 이벤트 역할 이름 | `lookout` → `GUARD`, `scout` → `SCOUT`, `student` → 역할 없음 (`act1_events.json`, `m3_samples.json`) |
| 수치 | 모두 `BalanceConfig`의 "동료 역할·탐험" 절에 둔다 |

## 8. 밸런스 영향과 확인

- **물자가 늘어난다.** 동료 5명 × 주 1.4번 × 주인공 탐험의 40%이므로, 동료가 다 모인 뒤에는 주인공 탐험 2~3번 몫이 더 들어온다. 배드 엔딩(굶주림·탈수) 비율이 내려갈 수 있다.
  - 봇 시뮬레이션(`ApoGirl/Balance/Run Bot Simulation`)으로 배드 목표 45~55%를 다시 맞춘다.
  - 조절할 곳은 수확 비율(40%)과 2번 나갈 확률(40%)이다.
- **동료의 소모가 늘어난다.** 나간 동료는 더 먹고 마신다. 그래서 물자가 순수하게 늘지만은 않는다.
- **호감 분포:** 엔딩 조건 중 호감을 쓰는 것(관계 엔딩)이 너무 쉬워지지 않는지 본다. 관계·서사 엔딩 목표는 6~12%다.
- **봇:** 봇도 역할을 맡기게 한다(전략 파일에 "역할 배정" 한 줄: 적성 우선). 그래야 시뮬레이션이 실제 플레이에 가깝다.
- **테스트:**
  - 방 열림과 역할 맡기기, 열린 방 수 배율, 적성 배율.
  - 함께한 시간과 주 상한, 자리 비움 때 0.
  - 외출 일정(횟수·상한·제외 조건), 외출 물자, 세이브 변환.

## 10. [결정 필요]

앞선 판에서 추천안으로 둔 것은 그대로 적용한다:
- 함께한 시간 주 상한 2;
- 이벤트 역할 이름 정리;
- 역할 세이브 변환.

새로 정할 것은 아래 세 가지다.

1. **동료 탐험 일정을 누가 정하나**
   - 자동으로 정하고, 플레이어는 붙잡기와 날짜 옮기기만 한다 **(추천)**: 손이 덜 가면서 빈자리를 계획에 넣을 수 있다.
   - 완전히 자동: 가장 단순하지만 "왜 하필 오늘"이 생긴다.
   - 플레이어가 동료마다 날짜와 갈 곳을 직접 고른다: 통제는 크지만 매주 손이 많이 간다.
2. **동료가 탐험에서 다칠 수 있나**
   - 낮은 확률로 다친다(6%, 정찰 4%) **(추천)**: 나가는 일에 무게가 생긴다.
   - 다치지 않는다: 순수한 이득이 되어 밸런스가 쉬워지지만 긴장이 없다.
3. **동료가 탐험에서 물자를 얼마나 가져오나**
   - 주인공 헤드리스의 40% **(추천)**.
   - 25%(보조 수준).
   - 60%(주인공 탐험을 줄여도 되는 수준).
