# 자원

## 1. 자원 종류

| 이름 | 쓰는 곳 | 얻는 곳 |
|---|---|---|
| 식량 | 하루 소모, 요리, 배분, 통행세, 거래 | 탐험, 텃밭, 동료 외출, 거래 |
| 물(식수) | 하루 소모, 배분 | 탐험(생수·음료수), 물 정수 |
| 빗물(정수 필요) | 물 정수로 식수가 된다 | 매주 자동, 비 오는 주에 더 |
| 의약품 | 부상 치료, 감염 처치, 선생님 돌보기, 배분 | 약국·의원, 탐험, 거래 |
| 자재 | 방어 설비, 시설, 거래 | 탐험(고철·덕트 테이프·전자 부품 등) |
| 연료 | 겨울 난방 | 라이터·부탄가스·발전기 연료통 |
| 전력 | **쓰면 줄지 않는 발전 용량** | 발전기 복구, 배터리 연결 |
| 배터리 | 발전 용량 늘리기 | 건전지, 무전기 부품 |
| 탄약 | (예약된 항목) | — |
| 정보 | 단서 | 교과서 |

시작할 때 가진 양: 식량 14, 물 20, 의약품 2.

## 2. 하루 소모

- **식량 2, 물 2** (주인공과 선생님 두 사람 기준. 동료가 늘면 같이 늘어난다)
- **폭염**: 물 +1/일
- **겨울**: 식량 ×1.3(소수점까지 쌓아 두었다가 나눠 쓴다. 한 주에 약 18)
- 난이도 소모 배율이 곱해진다.
- 단, **포만·수분이 0 이상이면 그날은 먹지 않는다**(아낀다). → [몸 상태 §4](14_몸_상태.md#4-포만과-수분)

## 3. 물 공급

먹는 물은 모두 빗물에서 나온다.

| 들어오는 물 | 양 |
|---|---|
| 매주 생활용수 | 빗물 +5 |
| 비 오는 주(양동이) | 빗물 +5 |
| 비 오는 주 + 빗물통 | 빗물 +10 더 |

- 빗물은 **물 정수**(낮)로 식수로 바꾼다. 한 번에 최대 12, 성공하면 80%가 식수가 된다.

## 4. 식량 부패

- 주간 결산 때 식량이 **60을 넘으면**, 넘는 양의 **20%** 가 상한다(올림).
- **냉장고**가 켜져 있으면 기준이 90으로 오른다.
- 폭염에는 음식이 상하는 이벤트가 따로 있다.

## 5. 전력과 배터리

> **전력은 쓰는 자원이 아니라 유지력이다.**

- **발전기 복구**(자재 3)를 하면 **발전 용량 3**이 생긴다. 쓴다고 줄지 않는다.
- **여유 전력 = 용량 − 켜진 전기 기기**

| 기기 | 전력 | 효과 | 얻는 법 |
|---|---|---|---|
| 냉장고 | 1 | 식량 부패 기준 +30 | 가사 실습실 수색 |

| 전력이 필요한 행동 | 여유 전력 |
|---|---|
| 방송 3종 | 2 |
| 무전 청취 | 1 |
| 야간 자습 | 복구만 되어 있으면 됨 |

- **용량 늘리기**: 배터리를 모아 "배터리 연결"을 하면 +1. 배터리 5개가 들고, 공학 Lv마다 1개씩 줄어든다(최소 2). 상한은 6이다.
- **발전기 고장**: 이벤트로 고장 나면 **정전**이 된다. "고장 난 발전기 고치기"(자재 2)로 고친다.
- 위쪽 띠에 **전력 a/b**(쓰는 양/용량)가 표시된다. 정전이면 단면도가 더 어둡다.

## 6. 겨울 난방

- 겨울(40~52주)에는 매주 **연료 2**가 든다. 모자라면 스트레스 +6이다.

## 7. 그 밖에 들어오는 것

- **옥상 텃밭**: 겨울을 빼고 매주 식량 +7
- **고양이**: 매주 식량 1을 먹는다(없으면 쥐를 잡는다)
- **동료 외출**: 주인공 수확의 30%만큼을 한 종류로 가져온다. → [동료 외출](33_동료_외출.md)
- **세력 거래**: → [외부 세력](41_외부_세력.md)
- **급식실**: 식량 절약 1
- **살림 역할**: 이틀에 한 번 식량 1 절약
