# 자원

## 1. 자원 종류

| 이름 | 쓰는 곳 | 얻는 곳 |
|---|---|---|
| 식량 | 하루 소모, 요리, 배분, 통행세, 거래 | 탐험, 텃밭, 동료 외출, 거래 |
| 물(식수) | 하루 소모, 배분 | 탐험(생수·음료수), 물 정수 |
| 빗물(정수 필요) | 물 정수로 식수가 된다 | 매주 자동, 비 오는 주에 더 |
| 의약품 | 부상 치료, 감염 처치, 선생님 돌보기, 배분 | 약국·의원, 탐험, 거래 |
| 자재 | 방어 설비, 시설, 거래 | 탐험(고철·덕트 테이프·전자 부품 등) |
| 연료 | 겨울 난방, 끓임 정수대 | 라이터·부탄가스·발전기 연료통 |
| 전력 | **쓰면 줄지 않는 발전 용량** | 발전기 복구, 배터리 연결 |
| 배터리 | 발전 용량 늘리기, 제작 재료, 바닥난 손전등 채우기 | 건전지, 무전기 부품 |
| 탄약 | (예약된 항목) | — |
| 정보 | 단서 | 교과서 |

시작할 때 가진 양: 식량 14, 물 20, 의약품 2.

- 위쪽 띠에는 식량·물·빗물·의약품·자재·연료가 보인다. 배터리와 창고에 쌓인 물건은 거점 서랍의 **보관함**에서 본다. → [허브 화면](18_허브_화면.md)

## 2. 하루 소모

먹고 마시는 양은 **이번 주 식단**으로 정한다. 식량과 물을 따로 고른다. → [이번 주 배분하기 §1](34_배분하기.md#1-이번-주-식단)

| 식단 | 한 사람이 하루에 쓰는 양 |
|---|---|
| 아껴 먹는다 | 1 |
| 챙겨 먹는다 | 2 |
| 잘 먹는다 | 3 |

- 사람 수는 주인공 + 선생님 + 합류한 동료다(고양이는 세지 않는다). 둘이서 "챙겨 먹는다"면 하루에 식량 4, 물 4다.
- **폭염**: 물이 한 사람당 하루 +1 더 든다.
- **겨울**: 식량 ×1.2(소수점은 날마다 나눠 쌓는다).
- 난이도는 소모를 줄여 주지 않는다. 대신 구해 온 식량·물이 쳐지는 값이 달라진다. → [난이도](17_난이도.md)
- 모자라면 있는 만큼 나눠 먹는다. 그날은 모두 스트레스가 +2~5 오른다.

## 3. 물 공급

먹는 물은 모두 빗물에서 나온다.

| 들어오는 물 | 양 |
|---|---|
| 매주 생활용수 | 빗물 +5 |
| 비 오는 주(양동이) | 빗물 +10 |
| 비 오는 주 + 빗물통 | 빗물 +10 더 |

- 빗물은 **물 정수**(낮)로 식수로 바꾼다. 한 번에 최대 12, 성공하면 80%가 식수가 된다(대성공 100%, 실패 50%).
- 정수 설비를 만들면 정수 칸을 아낄 수 있다. → [제작 §5](19_제작.md#5-정수-줄)
  - 모래 필터: 결산 때 빗물 4를 저절로 거른다.
  - 끓임 정수대: 연료 1을 쓰면 한 번에 18까지 거른다.
  - 자동 정수기: 아침마다 빗물 3을 거른다(전력 1).
- **살림** 역할 동료가 있으면 아침마다 빗물 1을 걸러 둔다.

## 4. 식량 부패

- 주간 결산 때 식량이 **60을 넘으면**, 넘는 양의 **18%** 가 상한다(올림).
- **냉장고**가 켜져 있으면 기준이 90으로 오른다.
- 폭염에는 음식이 상하는 이벤트가 따로 있다.

## 5. 전력과 배터리

> **전력은 쓰는 자원이 아니라 유지력이다.**

- **발전기 복구**(자재 3)를 하면 **발전 용량 3**이 생긴다. 쓴다고 줄지 않는다.
- **여유 전력 = 용량 − 켜진 전기 기기**

| 기기 | 전력 | 효과 | 얻는 법 |
|---|---|---|---|
| 냉장고 | 1 | 식량 부패 기준 +30 | 가사 실습실 수색 |
| 자동 정수기 | 1 | 아침마다 빗물 3을 식수로 | 제작(정수 줄 3단계) |
| 스프링클러 | 2 | 밭이 그날 ×1.5로 자란다(빗물 1) | 제작(식량 줄 3단계) |

- 기기는 위 표의 순서대로 켜진다. 용량이 모자라면 뒤쪽 기기부터 꺼진다.

| 전력이 필요한 행동 | 여유 전력 |
|---|---|
| 방송 3종 | 2 |
| 무전 청취 | 1 |
| 야간 자습 | 복구만 되어 있으면 됨 |

- **용량 늘리기**: 배터리를 모아 "배터리 연결"을 하면 +1. 배터리 5개가 들고, 공학 Lv마다 1개씩 줄어든다(최소 2). 상한은 6이다.
- **발전기 고장**: 이벤트로 고장 나면 **정전**이 된다. "고장 난 발전기 고치기"(자재 2)로 고친다.
- 위쪽 띠에 **전력 a/b**(쓰는 양/용량)가 표시된다. 정전이면 단면도가 더 어둡다.
- 거점 서랍의 전력 칸에서 여유 전력, 켜진 기기, 모은 배터리를 한눈에 본다.
- 정전 중에 밤 칸에서 제작을 하면 판정이 −10%다.

## 6. 겨울 난방

- 겨울(40~52주)에는 매주 **연료 2**가 든다. 모자라면 스트레스 +4다.

## 7. 그 밖에 들어오는 것

- **옥상 텃밭**: 겨울을 빼고 한 주에 식량 10만큼 자란다. 비닐하우스로 올리면 16(겨울에는 반)이다. → [제작 §6](19_제작.md#6-식량-줄)
- **고양이**: 매주 식량 1을 먹는다(없으면 쥐를 잡는다)
- **동료 외출**: 주인공 수확의 70%만큼을 한 종류로 가져온다. → [동료 외출](33_동료_외출.md)
- **세력 거래**: → [외부 세력](41_외부_세력.md)
- **급식실**: 식량 절약 1
- **살림 역할**: 이틀에 한 번 식량 1 절약
