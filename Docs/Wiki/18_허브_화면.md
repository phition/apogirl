# 허브 화면 읽는 법

허브 화면은 교실의 물건들로 만들어져 있다.

| 재질 | 쓰이는 곳 |
|---|---|
| **칠판** | 늘 보이는 틀이다. 위쪽 띠, 아래 도크, 계획 보드, 서랍의 바탕. 분필 글씨로 적힌다 |
| **종이** | 읽는 정보다. 결과 카드, 그날 보고, 선생님 한마디(포스트잇), 방 패널, 말풍선 |
| **표시** | 노란 분필 테두리 = 지금 고른 것, 빨간 펜 = 경고, 초록 분필 = 좋음, 도장 = 판정·완료 |

화면의 자리는 이렇다.

| 자리 | 있는 것 |
|---|---|
| 위 | 위쪽 띠: 날짜, 자원, 전력, 방어·위협, 단추들 |
| 왼쪽 | 주인공 입상과 간이 수치 |
| 가운데 | 학교 단면도 |
| 오른쪽 위 | 선생님 한마디 |
| 아래 | 14칸 도크와 "한 주 실행 ▶" |

## 1. 장면(단면도)
- 1주차에는 창고 그림이고, 그 뒤로는 교실동 **3층 + 옥상** 단면도다.
- **계단실이 건물 가운데**에 있고, 방은 좌우 날개로 나뉜다.

| 층 | 왼쪽 날개 | 오른쪽 날개 |
|---|---|---|
| 옥상 | 옥상 | |
| 3층 | 방송실 · 음악실 | 컴퓨터실 · 체육관 |
| 2층 | 교실 · 과학실 | 도서관 · 가사실 |
| 1층 | 현관 · 창고 · 급식실 | 보건실 · 교무실 |

- 건물 왼쪽 바깥에는 **마당과 낮은 담, 교문**이 있다.
- **방을 누르면** 그 방에서 할 수 있는 행동 목록이 뜬다. 방의 효과와 "○○ 자리: 맡은 사람"도 함께 나온다.
- 열지 않은 방은 어둡고 "?"로 보인다. 버려 둔 흔적이 실루엣으로 비친다. 마우스를 올리면 "아직 열지 않은 곳"이 뜬다.
- **지은 설비는 그 방 안에 놓인다.** 창고의 작업대, 과학실의 정수기, 옥상의 텃밭, 마당의 허수아비 같은 것들이다. → [거점과 시설 §4](15_거점과_시설.md#4-단면도에-보이는-설비)
- 실행 중에는 주인공이 방으로 걸어가고, 동료는 맡은 방에 있다.
  - 외출하는 동료는 낮에 현관을 나가 교문 쪽으로 걸어가고, 방 이름 옆에 "· 외출"이 붙는다. 밤에 그쪽에서 돌아온다.
  - 고양이는 방을 돌아다닌다.
- 밤에는 사람이 있는 방만 불이 켜진다. 정전이면 더 어둡다.
- 배경에 마을·하늘·해와 달·구름·비·눈이 보인다. 폭설 기간에는 지붕에 눈이 쌓인다.
- 방송실 벽에는 **CD 자켓 자리 8개**가 있다. 자켓을 누르면 크게 보고, 방을 누르면 CD 플레이어가 뜬다. → [CD 수집과 음악실](45_CD와_음악실.md)
- **컴퓨터실의 컴퓨터**를 누르면 PC통신에 접속한다(선생님에게 모뎀 이야기를 들은 뒤). → [PC통신 '이제누리'](46_PC통신.md)

## 2. 상시 표시
- **위쪽 띠**: 날짜·요일·계절·날씨, 자원(식량·물·빗물·의약품·자재·연료), 전력 a/b, 방어 a · 위협 b, 구조까지 N주(30주 이후), 거점·사람들·저장·메뉴 단추.
  - 배터리는 위쪽 띠에 없다. 보관함에서 본다.
  - 거점 단추에 **빨간 점**이 붙으면 거점에 살펴볼 일이 있다는 뜻이다.
- **주인공 입상**(왼쪽): 계절 교복·방어구·부상·피로에 따라 그림이 바뀐다. 눈을 깜빡이고 이따금 움직인다.
- **간이 수치**(입상 위): 누르면 생활기록부가 열린다. 계획 보드를 열어도 그대로 보인다.
- **선생님 한마디**(오른쪽 위, 포스트잇): 상황에 맞는 조언을 해 준다.
  - 말이 바뀌면 쪽지가 **5초 동안 펼쳐졌다가** 선생님 얼굴 뱃지만 남는다.
  - **뱃지를 누르면** 마지막 말이 다시 펼쳐진다. 펼쳐진 쪽지를 누르면 다음 말로 넘어간다.
  - 호감 50 이상인 동료가 4번에 1번꼴로 대신 말한다.
- **14칸 도크**(아래): 요일과 행동 아이콘. 누르면 계획 보드가 열린다. 토요일은 하늘색, 일요일은 붉은색 글씨다.
- **결과 한 줄**: 실행 중에 칸마다 무슨 일이 있었는지 화면 위로 흐른다.

## 3. 서랍
| 서랍 | 여는 법 | 내용 |
|---|---|---|
| **생활기록부** | 간이 수치 | 다이어리 한 쪽이다. 지난달 대표 장면 폴라로이드, "오늘의 몸" 쪽지, 능력치 상자(한 주에 3 이상 오르면 빨간 동그라미, 마우스를 올리면 힌트), 숙련 스티커(별 = Lv), 전투력·스트레스 한계, 선생님의 한마디 |
| **거점 상황** | 위쪽 띠 "거점" | 거점 상황판(§4). 왼쪽 가장자리의 "◀ 보관함" 탭 |
| **사람들** | 위쪽 띠 "사람들" | 인물 서랍(§5). 왼쪽 가장자리의 "◀ 세력" 탭 |
| **이번 주 계획** | Tab / 도크 | 계획 보드 → [한 주의 흐름](10_한주의_흐름.md) |

- 오른쪽 서랍이 열리면 선생님 한마디가 옆으로 비킨다.

## 4. 거점 상황 서랍
거점에 지금 무슨 일이 있고 다음에 무엇을 하면 좋은지 한 장에 모아 보여 준다. 칸은 접을 수 있다.

| 칸 | 내용 |
|---|---|
| 알림 | 급한 일(식량이 모자란다, 발전기가 고장 났다 등) |
| 다음 할 일 | 선생님의 한마디 두 줄. 누르면 계획 보드에서 그 행동을 고르거나 역할 칸으로 간다 |
| **안전** | 이번 주 밤 습격 가능성(없음·낮음·보통·높음)과 그 까닭, "습격이 오면: 든든하게 막는다 / 막을지 반반 / 뚫리기 쉽다", 막는 힘 대 습격 세기, 함정·경보·허수아비, 낮 침입 |
| **식량과 물** | 지금 양 → 주말 예상, 남은 아침에 드는 양, 모자라기 시작하는 요일, 상하기 시작하는 양, 빗물 |
| **전력** | 여유 전력 / 용량, 켜진 기기와 꺼진 기기, 모은 배터리 |
| **시설** | 단면도의 방마다 한 줄. 연 방의 효과와 쓰임, 잠긴 방은 여는 방법 힌트. 줄에 마우스를 올리면 단면도의 그 방이 빛나고, 누르면 그 방을 보여 준다 |
| **역할** | 역할마다 한 줄. 맡은 사람 뱃지, 빈 자리 [+]를 누르면 후보가 나온다. 뱃지를 오른쪽 클릭하면 뺀다. 쉬는 사람도 따로 보인다 → [동료 역할](32_동료_역할.md) |

- 칸마다 있는 행동 단추를 누르면 계획 보드가 그 행동을 든 채로 열린다.

### 4.1 보관함
거점 서랍 왼쪽의 **"◀ 보관함"** 탭을 누르면 펼쳐진다.
- 자원(배터리 포함), 장비(착용 중 표시와 남은 내구), 소모품, 기호품, 기타로 나뉘어 있다.
- 무엇을 얼마나 쌓아 두었는지 여기서 확인한다.

## 5. 인물 서랍
- 인물마다 뱃지, 호감 느낌 문구, 몸 상태 막대(스트레스·포만·수분), 부상, 맡은 역할, 켜져 있는 특기가 나온다.
- 계획 중에는 외출 예고와 "이번 주는 남아 줘" 단추, 동아리 짝 고르기가 있다. → [동료 외출](33_동료_외출.md), [방과후 동아리](42_동아리.md)
- 아래 글줄은 색으로 나뉜다. 붉은 줄은 나쁜 소식(부상·지침), 푸른 줄은 주의(정원 초과·방 없음)다.

### 5.1 세력 덧판
인물 서랍 왼쪽의 **"◀ 세력"** 탭을 누르면 펼쳐진다. 알게 된 세력만 나온다.
- 세력마다 카드 한 장이다. 얼굴, 이름, 관계 단계, 최근 3주의 평판 변화(▲▼), 다섯 단계 띠 위의 지금 자리, 지금 받는 영향, 거래를 할 수 있는지가 적혀 있다.
- 카드를 누르면 거래 화면이 열린다. → [외부 세력](41_외부_세력.md)

## 7. 대화
- 이벤트 대화가 열리면 입상과 선생님 한마디가 잠시 숨는다.
- 말하는 사람의 초상은 대화창 안 왼쪽 액자에 나온다.
- Space·Enter로 넘기고, 선택지는 눌러서 고른다.
