# 허브 화면 읽는 법

허브 화면은 다섯 겹으로 되어 있다.

```
┌──────────────────────── 위쪽 띠 ────────────────────────┐
│ N주차 · M월 D일 · 계절 · 날씨 │ 자원 │ 전력 │ 방어·위협 │ 사람들 │
├────────┬───────────────────────────────────┬────────────┤
│ 주인공  │                                   │ 선생님      │
│ 입상    │      학교 단면도 (0겹 장면)         │ 한마디      │
│ 생명    │      3층 + 옥상, 하늘·마을          │            │
│ 요약    │                                   │            │
├────────┴───────────────────────────────────┴────────────┤
│        14칸 도크 (1일 낮 … 7일 밤)        [한 주 실행 ▶]   │
└──────────────────────────────────────────────────────────┘
```

## 1. 장면(단면도)
- 1주차에는 창고 그림이고, 그 뒤로는 교실동 **3층 + 옥상** 단면도다.
- **방을 누르면** 그 방에서 할 수 있는 행동 목록이 뜬다.
- 열지 않은 방은 어둡고 "?"로 보인다. 마우스를 올리면 "아직 열지 않은 곳"이 뜬다.
- 실행 중에는 주인공이 방으로 걸어가고, 동료는 맡은 방에 있다.
  - 외출하는 동료는 낮에 현관으로 나가고, 방 이름 옆에 "· 외출"이 붙는다.
  - 고양이는 방을 돌아다닌다.
- 밤에는 사람이 있는 방만 불이 켜진다. 정전이면 더 어둡다.
- 배경에 마을·하늘·해와 달·구름·비·눈이 보인다.
- 방송실에는 **CD 진열장**이 있다. 방을 누르면 CD 플레이어가 뜬다. → [CD 수집과 음악실](45_CD와_음악실.md)

## 2. 상시 표시
- **위쪽 띠**: 날짜·계절·날씨, 자원, 전력 a/b, 방어 a · 위협 b, 구조까지 N주(30주 이후), 저장·메뉴·사람들 버튼.
- **주인공 입상**(왼쪽): 계절 교복·방어구·부상·피로에 따라 그림이 바뀐다. 눈을 깜빡이고 이따금 움직인다.
- **생명 요약**: 누르면 생활기록부가 열린다.
- **선생님 한마디**(오른쪽 위): 상황에 맞는 조언을 해 준다. 호감 50 이상인 동료가 4번에 1번꼴로 대신 말한다. 누르면 다음 말로 넘어간다.
- **14칸 도크**(아래): "N일"과 행동 아이콘. 누르면 계획 보드가 열린다.

## 3. 서랍
| 서랍 | 여는 법 | 내용 |
|---|---|---|
| **생활기록부** | 생명 요약 | 다이어리 한 쪽이다. 지난달 대표 장면 폴라로이드, "오늘의 몸" 쪽지, 능력치 상자(한 주에 3 이상 오르면 빨간 동그라미, 마우스를 올리면 힌트), 숙련 스티커(별 = Lv), 전투력·스트레스 한계, 선생님의 한마디 |
| **거점 · 사람 · 세력** | 오른쪽 | 시설, 동료 역할 바꾸기, 세력 카드 |
| **사람들** | 위쪽 띠 버튼 | 인물마다 뱃지·호감 느낌 문구·몸 상태 막대·부상·역할·외출 예고·"이번 주는 남아 줘"·동아리 짝 |
| **이번 주 계획** | Tab / 도크 | 계획 보드 → [한 주의 흐름](10_한주의_흐름.md) |

- 이벤트 대화가 열리면 입상과 선생님 한마디가 잠시 숨는다.
- Space·Enter로 넘기고, 선택지는 눌러서 고른다.
