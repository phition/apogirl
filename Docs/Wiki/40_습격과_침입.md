# 습격과 침입

## 1. 밤 습격

### 1.1 확률
- **4주차부터** 일어난다.

```
습격 확률(밤 칸마다) = 1% + (위협 − 방어) × 0.15%   (최대 30%)
```

- 밤 탐험을 나간 밤에는 거점에 습격이 오지 않는다.
- 거점 상황 서랍의 **안전** 칸에 이번 주 습격 가능성과 그 까닭이 미리 나온다. → [허브 화면 §4](18_허브_화면.md#4-거점-상황-서랍)

- **위협**: 탐험마다 +2, 매주 +1씩 쌓인다(최대 100). 창문 가림막이 있으면 쌓이는 속도 ×0.7, 청소하면 −2.
- **방어**: 설비로 쌓는다. 상한은 60이고, 출입구 보강을 하면 80이다. → [행동 목록 §4.1](11_행동_목록.md#41-방어)

| 배율 | 값 |
|---|---|
| 비 | ×0.6 |
| 사거리 파 적대 | ×1.25 |
| 사거리 파 휴전 | ×0.9 |
| UBC 호의 | ×0.95 |
| 방송한 주(사거리 파 휴전 전) | ×1.2 |

### 1.2 세기와 방어력
```
습격 세기 = 위협 + (0~20) − 교문 허수아비
방어력   = 20 + 전투력 + 방어도 × 1.2 + 경비 역할 + 특기 + 함정 + 경보 + (0~20)
```
| 더하는 것 | 값 |
|---|---|
| 함정 | 하나당 +25(최대 3개, 한 번 쓰면 없어진다) |
| 깡통 경보장치 | +10 |
| 경비 역할 | +6(배율 적용) |
| 선배「든든한 등」 | +10 |
| 야간 경계 | 그날 밤 경계 +25 |
| 체육관 | 경계 +4 |
| 교문 허수아비 | 습격 세기 −12(자명종을 달면 −18). 막을 때마다 내구 −1, 뚫리면 쓰러진다 → [제작 §7.1](19_제작.md#71-교문-허수아비) |

- 무기·방어구 같은 탐험 장비는 습격 방어에 들어가지 않는다.

### 1.3 결과
| 결과 | 효과 |
|---|---|
| 막아냄 | 스트레스 +3, 방어도 −3 |
| 뚫림 | 체력 −10, 스트레스 +12, 식량 −3, 방어도 −10 |

- 막아도 방어도가 깎인다. 습격이 이어지는 철에는 바리케이드를 계속 다시 쌓아야 한다.

뚫렸을 때 피해를 줄이는 것
- 호감 60 이상 동료가 대신 다친다(50%). → [위기 이탈 §4](36_위기_이탈.md#4-대신-다침)
- 자명종을 단 교문 허수아비가 서 있었다면 식량을 덜 잃는다(×0.8).
- 도현「밤눈」: 피해 −20%
- 고양이: 피해 ×0.85
- 뚫린 주는 **위기 주**가 된다.
- 습격하는 밤에 체력이 0이 되면 배드 엔딩「무너진 바리케이드」다.

### 1.4 막 끝의 대습격
| 때 | 세기 |
|---|---|
| 13주 6일 밤(1막 끝) | 55 |
| 26주 6일 밤(2막 끝) | 70 |
| 39주 6일 밤(3막 끝) | 85 |
| 49주 6일 밤(마지막) | 80 · 95 · 105(세력 관계에 따라 달라진다) |

막 끝이 다가오면 방어 설비와 야간 경계를 준비해 둔다.

## 2. 낮 침입(깡패)
- **27주부터** 매주 확률로 일어난다: 3막 12%, 4막 18%.
- 세기 = 55(4막 +15) + (0~20)
- 사거리 파와 적대하면 ×1.3, 휴전하면 ×0.75다.

| 대응 | 결과 |
|---|---|
| 맞선다 | 방어력으로 겨룬다. 지면 물자 25%를 빼앗긴다 |
| 숨는다 | 성공 35%(깡통 경보장치가 있으면 +30%). 들키면 10%를 빼앗긴다 |
| 내준다 | 15%를 내준다 |

- 대비가 부족하면 동료 한 명이 2주 부상을 입는다.
- 낮 침입에서도 방어도가 깎인다(막으면 −3, 지면 −10).
- **교문 허수아비는 사람에게 통하지 않는다.**

## 3. 수학여행 중의 습격
- 거점을 비운 밤에 습격이 오면, 주인공의 전투력 없이 **방어도의 절반**으로 막는다.
- 주인공은 다치지 않는다. → [소풍과 수학여행](44_소풍과_수학여행.md)
