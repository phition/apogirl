## 1. 체력
- 범위는 0~100이고 100에서 시작한다. **0이 되면 게임 오버**다(원인에 따라 배드 엔딩이 다르다).
- 탐험에서 쓰러지면 체력 15로 돌아온다. 대신 배낭과 장비를 잃고 2일 요양이다.
- 휴식·요리·포만·수분으로 회복한다. **부상 중에는 회복되지 않는다.**
- 배가 고프면 **최대 체력**이 줄어든다(§4).

## 2. 피로와 스트레스
- 둘 다 0~100이다. 행동마다 피로·스트레스 비용이 붙는다.

**행동 스트레스**
- 쉬는 일정(휴식·소풍·수학여행·옥상·일기·선생님과의 대화·동아리)을 뺀 모든 행동이 스트레스를 준다.
- 수업·설비·제작 같은 행동: 무게 1~5단계에 따라 **+5 · 6 · 8 · 9 · 10**. → [행동 목록 §0](11_행동_목록.md#0-행동-스트레스)
- 탐험:

| 지역 | 낮 | 밤 |
|---|---|---|
| 교실동 · 편의점 | +10 | +13 |
| 약국·의원 · 빌라 골목 · 파출소 | +11 | +14 |
| 지하철 · 마트 · 정수장 | +13 | +15 |

- 더 받는 경우(더해서 곱한다): 피로 50 / 70 / 90 이상 +10% / +25% / +40%, 부상 +25%, 수면 부채 3·4단계 +25%, 5단계 +50%. 남의 것을 가져온 마음의 짐이 쌓여도 더 받는다.
- 한 번에 받는 양에 상한은 없다.
- 난이도: 이야기 중심 ×0.8, 하드 ×1.2.

**그 밖의 규칙**
- 판정에 영향을 준다: 스트레스 1당 −0.3%, 피로 1당 −0.2%.
- **스트레스가 60을 넘으면** 탐험 수색이 느려진다(100이면 +50%).
- **스트레스 한계**(50 + 의지×0.3 + 마음 Lv×5)를 넘으면 이벤트에서 무너지기 쉽다.
- **정신 붕괴**: 주간 결산 때 스트레스 100인 주가 **3주 연속**이면 배드 엔딩「멈춰 버린 시계」다.
- 한파에는 매일 스트레스 +2다.

**스트레스를 낮추는 방법**

| 방법 | 효과 |
|---|---|
| 옥상에서 하늘 보기 | −12 |
| 밤 휴식 | −12(낮잠은 −6) |
| 동아리: 노래 연습 | −9 |
| 선생님과의 대화 | −8 |
| 일기 쓰기 | −7 |
| 음악 수업 · 명상(성공했을 때) | −6 · −5 |
| 진통제(탐험 중 배낭에서 쓴다) | −15 |
| 고양이 무릎 | −4 |
| 예지 특기 | −3/주 |
| UBC와 호의 | −2/주 |

## 3. 수면 부채
- 0~5 단계다. **저절로 줄지 않는다.** **밤 휴식을 두 번 연속**하면 1씩 준다.

| 늘어나는 경우 | 양 |
|---|---|
| 밤 탐험 | +1 |
| 연속 출정 | +2 |
| 강제 휴식 위반 | +1 |
| 밤 탐험에서 새벽에 돌아옴 | +1 (피로 +10, 스트레스 +10도 붙는다) |

| 단계 | 효과 |
|---|---|
| 1 이상 | 효율 −10% |
| 2 이상 | 탐험 중 숨어 있다가 **잠들 수 있다**(→ [소음·시야·은신 §5](21_소음_시야_은신.md#5-숨기)) |
| 3·4 | 판정 −10%, 스트레스 ×1.25 |
| 4 이상 | 그 주 낮 칸 하나가 휴식으로 잠긴다 |
| 5 | 판정 −15%, 스트레스 ×1.5 |

> 윤 선생님: "눈 밑이 퀭하구나. 오늘 밤엔 꼭 자거라."

## 4. 포만과 수분
- 둘 다 **−100 ~ +100** 이고, **0이 보통**이다.
- **아침**(낮 칸이 시작할 때): 이번 주 식단대로 다 같이 먹고 마신다. **식량 1 = 포만 +14, 물 1 = 수분 +15**(한 사람 몫).
- **밤이 되기 전**(밤 칸이 시작할 때): 포만 −8, 수분 −8. 그리고 아래 단계의 효과가 적용된다.
- **탐험** 한 번에 포만 −5, 수분 −6이 더 빠진다.

| 식단 | 하루 소비(한 사람) | 하루 포만 | 하루 수분 |
|---|---|---|---|
| 아껴 먹는다 | 1 | +14 − 8 = **+6** | +15 − 8 = **+7** |
| 챙겨 먹는다 | 2 | **+20** | **+22** |
| 잘 먹는다 | 3 | **+34** | **+37** |

- 창고가 모자라 식단을 못 지킨 날은 먹은 만큼만 오르고, 주인공과 동료 모두 스트레스 +1~3이다.
- **허기**(포만이 0 아래)는 1당 **최대 체력 −1%**, **갈증**(수분이 0 아래)은 1당 **탐험 최대 스태미너 −1%** 다. 둘 다 절반까지만 깎인다.

| 포만 단계 | 범위 | 하루 효과 |
|---|---|---|
| 든든함 | +50~ | 체력 +2, 스트레스 −2 |
| 배부름 | +1~ | 체력 +1, 스트레스 −1 |
| 보통 | −29~0 | — |
| 허기짐 | −59~ | 스트레스 +3 |
| 굶주림 | ~−60 | 체력 −5, 스트레스 +5 |

| 수분 단계 | 하루 효과 |
|---|---|
| 넉넉함 | 체력 +1, 스트레스 −1 |
| 촉촉함 | 체력 +1 |
| 보통 | — |
| 목마름 | 스트레스 +3 |
| 탈수 | 체력 −10, 스트레스 +5 |

- 포만이나 수분이 −60 이하일 때 체력이 0이 되면 배드 엔딩「빈 찬장」이다.
- 동료와 선생님에게도 포만·수분이 따로 있다. → [이번 주 배분하기](34_배분하기.md)

## 5. 요리
"요리 수업"에 성공하면 요리·영양 숙련에 맞는 요리를 만들어 바로 먹는다. 대성공이면 한 단계 위 요리가 되고, 실패하면 태운다.

| 요리 | 숙련 | 재료 | 포만 / 수분 | 덤 |
|---|---|---|---|---|
| 주먹밥과 죽 | Lv0 | 식량 1·물 1 | +20 / +15 | — |
| 된장국 | Lv2 | 식량 2·물 2 | +35 / +40 | 스트레스 −2, 체력 +1 |
| 따뜻한 정식 | Lv4 | 식량 2·물 1 | +50 / +30 | 스트레스 −5, 체력·의지 +1 |

## 6. 부상
- **한 사건에서 체력을 30% 넘게 잃으면** 부상(INJURED)이 된다. 의학 Lv마다 이 기준이 +5%씩 오른다.
- 부상 중에는:
  - 체력이 회복되지 않는다.
  - 탐험 스태미너 상한이 25% 깎인다.
- **의약품으로만 낫는다.**
  - 부상 치료(의약품 1, 체력 +15)
  - 밤 휴식(의약품이 있으면 자동으로 1개 사용)
  - 응급처치 독학 성공(1개)
- 나으면 "부상을 치료했다. 이제 쉬면 낫는다."가 뜬다.

## 7. 청결
- 30에서 시작하고 **매주 −15**씩 준다. 청소·위생 +30, 물 정수 +5.
- **50 미만일 때 다치면 상처 감염**이 생긴다(청결 0이면 감염 +10).
- 물려서 생기는 감염도 더러울수록 커진다(최대 ×1.5).
- 일기 표현: "깨끗하다" → "꼬질꼬질하다" → "더럽다 (상처가 덧날 수 있다)"

## 8. 감염
- 탐험에서 쓰러지면 낮 25%, 밤 30% 확률로 **물린다**.
  - 감염 +30. 그 자리에서 응급처치에 성공하면 +8로 그친다(성공 확률 15% + 의학 Lv×10%).
- 감염이 0보다 크면 **매주 +5씩 진행**한다(의학 Lv마다 −1, 최소 2, 난이도 배율, 보건실·간호 역할로 −1).
- **100이 되면** 배드 엔딩「깨어난 열」이다.
- 숫자는 보이지 않는다. 미열 → 기침 → 손떨림 같은 **증상 문장**으로 알려 준다. 예고 없이 죽는 일은 없다.
- 낮추는 법: 상처 소독·감염 처치(의약품 2, −15)

윤 선생님의 병은 따로 정리했다. → [윤 선생님의 병](52_선생님의_병.md) ⚠️

## 9. 양심의 무게
- 0~10. 생활기록부에 동그라미 칸으로 보인다. 1마다 **스트레스를 받을 때 +5%**(10이면 +50%).
- 좀비를 치는 건 몸을 지키는 일이다. 다만 그 정당성은 스스로 붙이는 것이라, 마음에 무게가 남는다.

| 무거워지는 경우 | 양 |
|---|---|
| 한 탐험에서 좀비를 **5마리 이상** 쓰러뜨림 | +1 |
| 사람이 살던 방(빌라의 집·지하철 대피소)의 상자를 뒤짐 | +1 (탐험 한 번에 한 번) |
| 도움을 청한 사람에게서 돌아섬 (도현·선배·유랑자·다친 준·마트) | +1 |

| 덜어지는 경우 | 양 |
|---|---|
| 선생님과의 대화 (성공했을 때) | −1 |
| 방송: 사연 읽기 (성공했을 때) | −1 |
| 처음 무거워진 밤, 선생님께 털어놓기 (한 번) | −1 |

- 처음으로 무거워지면 그날 밤 선생님을 찾아가게 된다. 무엇을 말할지는 고르지만, 어느 쪽이든 조금은 가벼워진다.

> 윤 선생님: "그 돌은 혼자 들고 있으면 계속 무거워. 이렇게 꺼내 놓으면, 조금은 가벼워지고."
