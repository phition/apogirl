## 1. 체력
- 범위는 0~100이고 100에서 시작한다. **0이 되면 게임 오버**다(원인에 따라 배드 엔딩이 다르다).
- 탐험에서 쓰러지면 체력 15로 돌아온다. 대신 배낭과 장비를 잃고 2일 요양이다.
- 휴식·요리·포만·수분으로 회복한다. **부상 중에는 회복되지 않는다.**

## 2. 피로와 스트레스
- 둘 다 0~100이다. 행동마다 피로·스트레스 비용이 붙는다.
- 판정에 영향을 준다: 스트레스 1당 −0.3%, 피로 1당 −0.2%.
- **스트레스가 60을 넘으면** 탐험 수색이 느려진다(100이면 +50%).
- **스트레스 한계**(50 + 의지×0.3 + 마음 Lv×5)를 넘으면 이벤트에서 무너지기 쉽다.
- **정신 붕괴**: 주간 결산 때 스트레스 100인 주가 **3주 연속**이면 배드 엔딩「멈춰 버린 시계」다.
- 한파에는 매일 스트레스 +2다.

**스트레스를 낮추는 방법**

| 방법 | 효과 |
|---|---|
| 옥상에서 하늘 보기 | −12 |
| 밤 휴식 | −10 |
| 동아리: 노래 연습 | −9 |
| 선생님과의 대화 | −8 |
| 일기 쓰기 | −7 |
| 퀵슬롯 진통제 | −15 |
| 고양이 무릎 | −4 |
| 예지 특기 | −3/주 |
| UBC와 호의 | −2/주 |

## 3. 수면 부채
- 0~5 단계다. **저절로 줄지 않는다.** **밤 휴식을 두 번 연속**하면 1씩 준다.

| 늘어나는 경우 | 양 |
|---|---|
| 밤 탐험 | +1 |
| 연속 출정 | +2 |
| 강제 휴식 위반 | +1 |
| 밤 탐험에서 새벽에 돌아옴 | +1 |

| 단계 | 효과 |
|---|---|
| 1 이상 | 효율 −10% |
| 2 이상 | 탐험 중 숨어 있다가 **잠들 수 있다**(→ [소음·시야·은신 §5](21_소음_시야_은신.md#5-숨기)) |
| 3·4 | 판정 −10%, 스트레스 ×1.25 |
| 4 이상 | 그 주 낮 칸 하나가 휴식으로 잠긴다 |
| 5 | 판정 −15%, 스트레스 ×1.5 |

> 윤 선생님: "눈 밑이 퀭하구나. 오늘 밤엔 꼭 자거라."

## 4. 포만과 수분
- 둘 다 **−100 ~ +100** 이고, **0이 보통**이다.
- 매일 밤 포만 −25, 수분 −30이 줄어든다.
- 0 아래로 내려가면 그날 몫을 먹고 마셔 포만 +45, 수분 +55가 된다(0까지만 오른다).
- **0 이상이면 먹지 않는다.** 요리를 하거나 배불리 먹어 두면 식량을 아낄 수 있다.

| 포만 단계 | 범위 | 하루 효과 |
|---|---|---|
| 든든함 | +50~ | 체력 +2, 스트레스 −2 |
| 배부름 | +1~ | 체력 +1, 스트레스 −1 |
| 보통 | −29~0 | — |
| 허기짐 | −59~ | 스트레스 +3 |
| 굶주림 | ~−60 | 체력 −5, 스트레스 +5 |

| 수분 단계 | 하루 효과 |
|---|---|
| 넉넉함 | 체력 +1, 스트레스 −1 |
| 촉촉함 | 체력 +1 |
| 보통 | — |
| 목마름 | 스트레스 +3 |
| 탈수 | 체력 −10, 스트레스 +5 |

- 포만이나 수분이 −60 이하일 때 체력이 0이 되면 배드 엔딩「빈 찬장」이다.
- 동료와 선생님에게도 포만·수분이 따로 있다. → [이번 주 배분하기](34_배분하기.md)

## 5. 요리
"요리 수업"에 성공하면 요리·영양 숙련에 맞는 요리를 만들어 바로 먹는다. 대성공이면 한 단계 위 요리가 되고, 실패하면 태운다.

| 요리 | 숙련 | 재료 | 포만 / 수분 | 덤 |
|---|---|---|---|---|
| 주먹밥과 죽 | Lv0 | 식량 1·물 1 | +20 / +15 | — |
| 된장국 | Lv2 | 식량 2·물 2 | +35 / +40 | 스트레스 −2, 체력 +1 |
| 따뜻한 정식 | Lv4 | 식량 2·물 1 | +50 / +30 | 스트레스 −5, 체력·의지 +1 |

## 6. 부상
- **한 사건에서 체력을 30% 넘게 잃으면** 부상(INJURED)이 된다. 의학 Lv마다 이 기준이 +5%씩 오른다.
- 부상 중에는:
  - 체력이 회복되지 않는다.
  - 탐험 스태미너 상한이 25% 깎인다.
- **의약품으로만 낫는다.**
  - 부상 치료(의약품 1, 체력 +15)
  - 밤 휴식(의약품이 있으면 자동으로 1개 사용)
  - 응급처치 독학 성공(1개)
- 나으면 "부상을 치료했다. 이제 쉬면 낫는다."가 뜬다.

## 7. 청결
- 70에서 시작하고 **매주 −15**씩 준다. 청소·위생 +30, 물 정수 +5.
- **50 미만일 때 다치면 상처 감염**이 생긴다(청결 0이면 감염 +10).
- 물려서 생기는 감염도 더러울수록 커진다(최대 ×1.5).
- 일기 표현: "깨끗하다" → "꼬질꼬질하다" → "더럽다 (상처가 덧날 수 있다)"

## 8. 감염
- 탐험에서 쓰러지면 낮 25%, 밤 30% 확률로 **물린다**.
  - 감염 +30. 그 자리에서 응급처치에 성공하면 +8로 그친다(성공 확률 15% + 의학 Lv×10%).
- 감염이 0보다 크면 **매주 +5씩 진행**한다(의학 Lv마다 −1, 최소 2, 난이도 배율, 보건실·간호 역할로 −1).
- **100이 되면** 배드 엔딩「깨어난 열」이다.
- 숫자는 보이지 않는다. 미열 → 기침 → 손떨림 같은 **증상 문장**으로 알려 준다. 예고 없이 죽는 일은 없다.
- 낮추는 법: 상처 소독·감염 처치(의약품 2, −15)
