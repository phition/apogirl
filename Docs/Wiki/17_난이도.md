# 난이도

새 게임을 시작할 때 고른다. **시작한 뒤에는 바꿀 수 없다.**

| | 이야기 중심 | 표준 | 하드 |
|---|---|---|---|
| 설명 | 이야기를 따라가고 싶은 분께 | 살아남기 힘든 세계. 계획 하나하나가 생사를 가릅니다 | — |
| 먹고 마시는 양 | 같다 | 같다 | 같다 |
| 구한 식량·물의 값(통조림·생수 한 개) | ×1.5 (7.5) | ×1 (5) | ×0.8 (4) |
| 구한 의약품의 값 | ×1.5 | ×1 | ×0.8 |
| 그 밖의 수확 | ×1.5 | ×1 | ×0.9 |
| 행동·탐험 스트레스 | ×0.8 | ×1 | ×1.2 |
| 탐험 피해 | ×0.6 | ×1 | ×1.4 |
| 사람 위협(생존자·습격) | ×0.7 | ×1 | ×1.3 |
| 감염 진행 | ×0.6 | ×1 | ×1.3 |
| 자동 수색 맡기기 | 있음(얻는 양 70%) | 없음 | 없음 |
| 이번 주 되돌리기 | 있음(52주차 엔딩을 본 뒤) | 없음 | 없음 |

- 난이도는 먹는 양을 줄여 주지 않는다. 같은 통조림 하나가 몇 끼가 되느냐가 달라진다.
- 표준 난이도에서 여러 전략을 자동으로 돌려 보면 절반쯤이 배드 엔딩으로 끝난다. 사람이 하는 판의 실제 확률과는 다르다.
- 튜토리얼(창고 탈출)은 자동 수색을 쓸 수 없다.
