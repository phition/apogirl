# 난이도

새 게임을 시작할 때 고른다. **시작한 뒤에는 바꿀 수 없다.**

| | 이야기 중심 | 표준 | 하드 |
|---|---|---|---|
| 설명 | 이야기를 따라가고 싶은 분께 | 살아남기 힘든 세계. 계획 하나하나가 생사를 가릅니다 | — |
| 소모(식량·물) | ×0.75 | ×1 | ×1 |
| 탐험 피해 | ×0.6 | ×1 | ×1.4 |
| 사람 위협(생존자·습격) | ×0.7 | ×1 | ×1.3 |
| 감염 진행 | ×0.6 | ×1 | ×1.3 |
| 수확 | 식량·물 ×1.1, 의약품 ×0.85 | 의약품 ×0.75 | 식량·물 ×0.95, 의약품 ×0.7 |
| 자동 수색 맡기기 | 있음(얻는 양 70%) | 없음 | 없음 |
| 이번 주 되돌리기 | 있음(52주차 엔딩을 본 뒤) | 없음 | 없음 |
| 배드 엔딩 비율(봇 시험) | 약 10% | 약 45~55% | 약 84% |

- 봇 시험은 여러 전략을 자동으로 돌려 본 결과다. 사람이 하는 판의 실제 확률과는 다르다.
- 튜토리얼(창고 탈출)은 자동 수색을 쓸 수 없다.
