# 방송반 송출

> 학교 방송실에서, 누군가 듣고 있을지 모르는 밤으로.

## 1. 조건
- DJ 새벽과 교신한 뒤(3막)
- 발전기 복구, 방송실 개방, **여유 전력 2 이상**
- **밤, 주 1회**. 동아리와 같은 묶음이다.

## 2. 프로그램
| 프로그램 | 피로 | 효과 | UBC 평판 |
|---|---|---|---|
| 방송: CD 한 곡 | 2 | 공감 +1, 스트레스 −5 | +2 |
| 방송: 생존 정보 | 3 | 통솔 +1, 인간성 +1 | +3 |
| 방송: 사연 읽기 | 2 | 공감 +1, 스트레스 −2, 희망 +1 | +4 |

- "CD 한 곡"을 하려면 CD가 있어야 한다. → [CD 수집과 음악실](45_CD와_음악실.md)
- 첫 방송 장면에서 학교 이름을 밝힐지, 목소리만 낼지 고른다.

## 3. 응답
- 방송할 때마다 **30%** 확률로 누군가 응답한다. 그러면 다음에 응답 장면이 나온다.
- 응답 장면은 4편이다: 가족 / 아이(32주~, 가족 응답 뒤) / 마트 / 선물.

## 4. 위험
- 방송한 주에 **사거리 파와 아직 휴전하지 않았다면** 밤 습격 확률이 ×1.2가 된다. 목소리는 적에게도 들린다.
