# 프롤로그와 1주차

## 1. 프롤로그: 등굣길
3월 둘째 주 월요일 아침이다. 주인공은 친구와 이야기를 나누며 학교로 걸어간다. 이 대화에서 정하는 것들이 주인공의 시작점이 된다.

### 1.1 입력
| 항목 | 설명 |
|---|---|
| 이름 | 주인공 이름(기본 한서진) |
| 친구 연락처 이름 | 친구의 이름이 된다. "실제 친구 이름도 좋아요. 이 인물은 이야기 속에서 위험에 처할 수 있어요." |
| 생일 | 그 주에 생일 장면이 나온다 |

### 1.2 질문 7개
| 질문 | 선택지 | 쓰이는 곳 |
|---|---|---|
| 성격 | 네 글자 직접 입력 또는 4문항 퀴즈 | 성격 보정 → [능력치 §6](12_능력치와_성장.md#6-성격-유형) |
| 혈액형 | A / B / O / AB / 모름 | ⚠️ 4막에 중요해진다 |
| 배치고사 성적 | 4단계 | 시작 능력치 |
| 좋아하는 과목 | 국어 / 수학·과학 / 체육 / 기술·가정 / 생명과학 / 없음 | 시작 능력치. 국어를 고르면 윤 선생님 호감 +5. 그 과목 수업은 한 해 내내 성장 +1, 스트레스 −1 |
| 동아리 | 육상·요리·과학탐구·도서·미술·방송·보건·귀가부 | **특성** → [능력치 §5](12_능력치와_성장.md#5-특성) |
| 마음가짐 | 웃어넘김 / 서두름 / 친구에게 털어놓음 / 마주 봄 | 숨은 수치, 엔딩 대사. 고른 마음가짐에 따라 한 해 동안 이어지는 장면이 다르다 |
| 친구와의 약속 | 방과 후 떡볶이 / 다음에 | 엔딩 대사 |

- 고른 답마다 능력치가 조금씩 오른다(전체 약 +45).
- 몇몇 대답은 아주 나중에 다시 돌아온다. 성적과 동아리에 따라 달라지는 대사도 있다.
- 좋아하는 과목은 수업과 이렇게 이어진다: 국어 → 국어·인문, 수학·과학 → 공학·수리, 체육 → 호신술, 기술·가정 → 요리, 생명과학 → 응급처치. "없음"을 골랐다면 어떤 숙련이 Lv3이 될 때 좋아하는 과목을 찾는 장면이 나온다.
- 새 게임에서 난이도를 고르면 프롤로그 앞에 **등굣길 영상**이 나온다. 아무 키나 클릭으로 건너뛸 수 있다.

### 1.3 그날
방과 후 심부름으로 체육관 창고에 간다. 문이 밖에서 잠기고, 멀어지는 웃음소리가 들린다.
> "그게, 그날 본 {친구}의 마지막 모습이었다."
> "그리고 학교가 조용해졌다."

## 2. 1주차: 창고의 7일
| 날 | 칸 | 내용 |
|---|---|---|
| 1~6일 | 전부 "체육창고에서 버티기"(잠김) | 피로 −8, 스트레스 +2. 밤마다 "첫째 날 ~ 여섯째 날" 장면 |
| 6일 밤 | — | 누군가 창고 문을 연다 |
| 7일 낮 | 창고 탈출(튜토리얼 탐험) | 조작을 배운다. 체육 보호대·야구방망이를 챙길 수 있다. 가방이 없어 주머니(2×3칸)에 담는다 |
| 7일 밤 | 휴식 | — |

- 갇혀 있는 동안에는 습격과 무작위 이벤트가 없다.
- 선생님을 만나기 전에는 허브 오른쪽 위의 말이 **혼잣말**이다. 예: "(문은 밖에서 잠겨 있다. 지금은 버티는 수밖에 없다.)"
- 넷째 날 휴대폰 배터리가 다 닳는다.
- 탈출하면 **본관 창고**가 거점이 되고, 윤 선생님이 곁에 있게 된다. 손전등과 대걸레도 받는다.

## 3. 2회차에서 달라지는 점
- 창고에서 보내는 6일 동안 처음에는 몰랐던 문장이 섞인다.
- 여섯째 날에 회상 장면 「창고 안의 7일」이 나온다. ⚠️ 이 장면에서만 얻을 수 있는 단서가 있다.
