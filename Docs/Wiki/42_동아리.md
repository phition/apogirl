# 방과후 동아리

> 무너진 학교에서도 방과후는 온다.

## 1. 조건
- **밤** 행동이다. **14주부터**, 동료가 1명 이상 있을 때 할 수 있다.
- **주 1회**만 할 수 있다. 방송과 같은 묶음이라 한 주에 동아리와 방송 가운데 하나만 할 수 있다.

## 2. 활동
| 활동 | 피로 | 스트레스 | 성장 | 덤 |
|---|---|---|---|---|
| 동아리: 보드게임 | −4 | −5 | 지력 +1 | |
| 동아리: 노래 연습 | −3 | −9 | 공감 +1 | |
| 동아리: 운동 | +5 | −6 | 체력·민첩 +1 | |
| 동아리: 공부 모임 | +2 | −3 | 지력 +1 | 윤 선생님 호감 +1 |

## 3. 같이 할 사람
- 인물 서랍에서 **"이번 주 동아리 같이 하기"** 로 고른다. 고르지 않으면 호감이 가장 높은 사람이 함께한다.
- 함께한 사람의 호감은 **+4**, 그 사람이 **좋아하는 활동이면 +7**이다.

| 인물 | 좋아하는 활동 |
|---|---|
| 박 선생님 | 공부 모임 |
| 도현 | 운동 |
| 최하린 | 운동 |
| 송예지 | 노래 연습 |
| 선배 | 노래 연습 |
| 유랑자 | 보드게임 |

- 서랍에 힌트가 뜬다. 예: "노래할 때 표정이 풀린다."
- 좋아하는 활동을 **3번** 함께하면 그 사람의 **동아리 개인 장면**이 열린다.
- 활동마다 장면이 하나씩 있고, 함께한 사람에 따라 대사가 갈린다.
