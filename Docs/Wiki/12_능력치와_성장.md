## 1. 능력치 8종

| 능력치 | 주로 쓰이는 곳 |
|---|---|
| 체력 | 스태미너 최대치, 전투력 |
| 근력 | 전투력, 들 수 있는 무게 |
| 민첩 | 전투력, 숨는 속도 |
| 지력 | 교육 판정, 의사 엔딩 |
| 손재주 | 수색 속도, 공학 판정, 기술자 엔딩 |
| 의지 | 스트레스 한계 |
| 감수성 | 인문·교육 쪽, 교사 엔딩(공감) |
| 통솔 | 동료 설득, 리더 엔딩 |

- 모두 10에서 시작하고, 프롤로그 답에 따라 조금씩 더해진다(전체 약 +45).
- 상한은 999다. 값이 **100을 넘으면 오르는 양이 ×0.5**, **200을 넘으면 ×0.25**가 된다.
- 생활기록부의 막대는 250을 가득 찬 칸으로 그린다.
- 결산에서 한 주에 3 이상 오른 능력치에는 빨간 동그라미가 쳐진다.

## 2. 성장 배율

여러 배율이 곱해진다.

| 요인 | 배율 |
|---|---|
| 대성공 / 실패 | ×1.5 / ×0.5 |
| 선생님이 직접 가르침 | ×1.5 |
| 독학이지만 선생님이 지도 | ×1.15 |
| 선생님 병세 | 한 단계마다 지도 보정분 −20% |
| 같은 행동을 연속 | +0.1씩, 최대 +0.3(성격 J는 +0.4) |
| 선생님 호감 30 / 60 / 80 | ×1.1 / ×1.2 / ×1.3 (선생님이 가르치는 수업만) |
| 시설(도서관 +15% 등), 공부 역할(+8%), 특성 | 더해진다 |

## 3. 판정

```
성공 확률 = 기본 + 능력치×가중치 + 숙련 Lv×가중치
          − 스트레스×0.3% − 피로×0.2% − 수면 부채 패널티
```
- 범위는 **5~95%** 다. 성공 가운데 **15%** 가 대성공이다.
- 선생님 호감 보너스(선생님이 가르치는 수업만): 30↑ +5%, 60↑ +10%, 80↑ +15%(대성공 +5%).
- 수면 부채 3·4단계는 −10%, 5단계는 −15%다.

## 4. 숙련 9종

레벨은 Lv0~5다. 누적 경험치 **10 / 25 / 45 / 70 / 100** 에서 한 단계씩 오른다. 오를 때 "○○ 숙련도 상승!"이 뜬다.

| 숙련(약칭) | 효과 |
|---|---|
| 응급처치·의학(응급) | Lv마다 감염·선생님 병세 진행 −1/주, 부상 기준 +5%. 선생님 완치에 Lv4 필요 |
| 생존 기술 | 생존 판정 |
| 공학·수리 | Lv마다 배터리 비용 −1. 출입구 보강에 Lv2 필요 |
| 전술·호신술(호신) | Lv마다 전투력 +8 |
| 요리·영양 | 요리 단계(Lv0·2·4) |
| 어학·인문·기록(인문) | 교사·작가 엔딩 |
| 심리 관리(마음) | Lv마다 스트레스 한계 +5. 일기 쓰기로 오른다 |
| 과학·화학 | 거처를 교실로 옮기면 배울 수 있다 |
| 음악 | 위와 같음 |

## 5. 특성

프롤로그에서 고른 **동아리**가 특성 하나가 된다.

| 동아리 | 특성 | 효과 |
|---|---|---|
| 육상부 | 질주 | 달리기 +15% |
| 요리부 | 알뜰한 손 | 식량 절약(주 3번 하루 식량 −1) |
| 과학탐구부 | 수리공 | 공학 판정 +10% |
| 도서부 | 활자 중독 | 교육 성장 +10% |
| 미술부 | 세심한 눈 | 수색 속도 +20% |
| 방송부 | 주파수 | 인문 판정 +5% |
| 보건반 | 응급 감각 | 의학 판정 +10% |
| 귀가부 | 그림자 | 탐험 소음 −20%, 은신 +10% |

## 6. 성격 유형

프롤로그에서 성격(네 글자)을 직접 넣거나 4문항 퀴즈로 정한다.

| 글자 | 효과 |
|---|---|
| I | 휴식 회복 +10% |
| S | 수색 +10% |
| N | 인문 판정 +3% |
| T | 탐험 스트레스 −10% |
| J | 연속 행동 보너스 상한 +0.4 |
| P | 대성공 +5% |
| E · F | 효과 없음(대사만) |

## 7. 파생 수치

- **전투력** = 근력×0.4 + 민첩×0.3 + 체력×0.1 + 호신 Lv×8 → 밤 습격 방어에 더해진다.
- **스트레스 한계** = 50 + 의지×0.3 + 마음 Lv×5 (최대 90)
- 둘 다 생활기록부에 나온다.

## 8. 숨은 수치

화면에 숫자로 나오지 않지만 선택과 엔딩에 영향을 주는 마음의 수치들이다.

| 수치 | 시작 | 의미 |
|---|---|---|
| 희망 | 30 | 앞날을 믿는 마음 |
| 고립 | 20 | 혼자 걸으려는 마음. 「혼자 걸은 길」「아직 닫힌 문」 |
| 자기 이해 | 20 | 나를 아는 정도. 서사 엔딩 |
| 트라우마 회복 | 10 | 창고의 기억에서 벗어난 정도. 「열린 문」 |
| 인간성 | 40 | 남을 돕는 마음. 「함께한 사람들」, 선생님과 함께 남는 선택(72 이상) |
| 공감 | — | 교사 엔딩, 설득 판정 |

선택지의 결과 문장과 일기, 선생님의 한마디로 넌지시 드러난다.
