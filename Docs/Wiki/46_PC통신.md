# PC통신 '이제누리'

> "전화선만 살아 있으면 어디서든 닿습니다."

컴퓨터실의 낡은 컴퓨터로 접속하는 글자 통신망이다. 전국의 학교가 이어져 있던 **전국 학교 교육 통신망**이다. 지금 읽고 있는 이 '생존 백과'도 여기에 있다.

## 1. 열리는 때
1. 교실동 2층 **컴퓨터실**을 수색해서 연다.
2. 윤 선생님이 전화선 모뎀 이야기를 해 준다.
   - 유선 전화선은 긴급 상황에 대비해, 전력이 끊겨도 돌아가도록 되어 있다.
   - 전국 학교가 연결된 통신망을 쓸 수 있을지도 모른다.
   - "아마 01420이었나?"
3. 그 뒤로 허브 단면도에서 **컴퓨터실의 컴퓨터**를 누르면 접속한다.
4. 전화선과 모뎀은 전력 없이도 돌지만 **컴퓨터를 켜려면 여유 전력 2가 필요하다.** 발전기를 고치고, 전기 기기를 켜고도 전력이 2 남아야 한다. 모자라면 "전기가 모자라 컴퓨터가 켜지지 않는다"고 나온다. → [자원](13_자원.md)

## 2. 접속
- 모뎀이 01420으로 전화를 건다. 삐— 하는 소리가 이어지고, 연결되면 파란 화면에 〈이제누리〉의 첫 화면이 뜬다.
- 마우스로 누르는 화면이 아니다. **명령을 글자로 치고 Enter를 누른다.**
- 글은 **직접 쳐서** 쓴다. 다른 곳에서 써 둔 글을 붙여 넣을 수는 없다.

| 명령 | 뜻 |
|---|---|
| 번호 | 그 번호의 메뉴나 글로 들어간다 |
| P | 바로 앞 화면으로 |
| T | 처음 화면으로 |
| N / B | 다음 쪽 / 앞 쪽 |
| GO 이름 | 바로 가기(GO WIKI · GO BOARD · GO NOTICE · GO CHAT) |
| S 낱말 | 생존 백과에서 낱말 찾기(예: S 정수) |
| W | 열린 게시판에 글 쓰기 |
| R | (남의 글을 읽는 중) 그 글을 신고한다. 이어서 Y를 치면 신고된다 |
| H | 도움말 |
| X | 접속 끊기 |

## 3. 메뉴
| 번호 | 메뉴 | 내용 |
|---|---|---|
| 1 | 공지사항 | 통신망을 지키던 '누리지기'가 남긴 글 |
| 2 | **생존 백과** | 여러 학교에서 올라온 글을 갈래별로 엮은 것. 이 위키다 |
| 3 | 열린 게시판 | 다른 학교 사람들이 남긴 글. 글을 쓸 수도 있다. 회선이 닿으면 **다른 플레이어가 올린 글**도 보이고, 내 글도 건너간다 |
| 4 | 대화방 | 말을 걸어 볼 수 있다. 대답이 올지는 모른다 |
| 5 | 도움말 | 명령 목록 |

- 생존 백과에서 이야기 갈래의 글에는 앞일이 적혀 있다. **[!] 표시**가 붙은 글은 가려 읽는다.
- 열린 게시판은 여럿이 쓰는 곳이다. **욕설·비하·광고가 든 글은 올라가지 않고**, 남이 쓴 글에 든 그런 낱말은 ○로 가려 보인다.
- 보기 싫은 글은 읽는 중에 `R` → `Y`로 **신고**한다. 신고한 글은 내 화면에서 바로 사라지고, 여러 사람이 신고한 글은 모두에게 가려진다. 신고는 잠깐씩 쉬어 가며 할 수 있다.

## 4. 컴퓨터가 멎는다
- 학교 컴퓨터는 낡았고 전력이 불안정해서, 켜지더라도 **오래 버티지 못한다.**
- 접속하고 얼마 지나면 화면이 꺼진다. "컴퓨터가 멎었다. 다음 주에 다시 해 보자."
- 한번 멎으면 **그 주에는 다시 접속할 수 없다.** 다음 주가 되면 다시 켜진다.
- 남은 시간은 화면에 나오지 않는다. 읽고 싶은 글부터 먼저 읽는다.

## 5. 요령
- 찾는 것이 정해져 있으면 `S 낱말`이나 `GO WIKI`로 바로 간다. 메뉴를 한 칸씩 내려가면 시간이 모자란다.
- 한 주에 한 번뿐이다. 그 주에 궁금했던 것을 적어 두었다가 접속한다.
