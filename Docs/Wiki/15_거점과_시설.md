# 거점과 시설

## 1. 거점
- 처음 거점은 **본관 창고**다. 1주차 끝에 선생님이 창고 문을 열면서 생긴다.
- 교실동 1층 끝 교실 **1-5**를 수색하면 거처를 고르는 장면이 나온다.

| 선택 | 바로 열리는 것 | 나중에(1막 끝) 열리는 것 |
|---|---|---|
| 거점으로 삼는다(교실) | 공학·과학·음악 수업, 과학·음악 숙련 | 방어 설비 제작(함정·경보·출입구·가림막) |
| 창고에서 지낸다 | 방어 설비 제작 | 공학·과학·음악 수업 |

- 지금 지내는 곳은 단면도에서 침낭과 랜턴으로 보인다.

## 2. 시설(방) 목록

| 시설 | 열리는 때 | 효과 |
|---|---|---|
| 본관 창고 | 1주차 끝 | 첫 거점. 작업대를 놓는 곳 |
| 교실동 | 2주~, 1-5 수색 | 수업, 공부 역할 |
| 보건실 | 3주~(박 선생님 합류 때도) | 감염 저항 1, 선생님 돌봄 1, 응급처치 보너스, 간호 역할 |
| 옥상 | 4주~(탐험 중 옥상에 오르면 그보다 먼저) | 하늘 보기, 빗물통, 텃밭·비닐하우스·스프링클러, 정찰 역할 |
| 방송실 | 5주~(발전기 계획 이벤트) | 방송, 정찰 역할 |
| 급식실 | 2막 | 식량 절약 1, 살림 역할 |
| 도서관 | 2막 | 교육 성장 +15%, 공부 역할 |
| 체육관 | 2막 | 호신 판정 +10%, 습격 경계 +4, 위로 역할 |
| 과학실 | 탐험에서 수색한 그 주 일요일 밤(못 찾았으면 19주~) | 공학·의학 판정 +10%, 공부 역할, 자동 정수기 |
| 교무실 | 탐험에서 수색한 그 주 일요일 밤(못 찾았으면 20주~) | 인문 판정 +10%, 경비 역할 |
| 가사 실습실 | 탐험에서 수색 | 살림 역할, 냉장고, 끓임 정수대, 가방·보호구 제작 조건 |
| 음악실 | 탐험에서 수색 | 위로 역할 |
| 컴퓨터실 | 탐험에서 수색 | 손전등 줄·자명종 제작, PC통신 → [PC통신 '이제누리'](46_PC통신.md) |

- 2막을 여는 장면에서 급식실과 도서관 가운데 먼저 열 곳을 고른다.
- **과학실과 교무실은 직접 찾아가면 일찍 열린다.** 교실동 탐험에서 그 방의 상자를 뒤지면, 그 주 일요일 밤에 선생님과 방을 치우고 다음 주부터 쓴다. 둘을 같은 주에 찾았으면 한 주에 한 곳씩(과학실 먼저) 열린다. 찾지 않았어도 19주·20주가 지나 교실동을 탐험하면 열린다.
- 교실동의 특수실 6곳(교무실·양호실·가사 실습실·컴퓨터실·과학실·방송실·음악실 등)은 처음 수색할 때 발견 장면이 나온다.

## 3. 방어도와 위협
- **방어도**: 바리케이드·경보·함정·출입구 보강으로 쌓인다. 상한은 60이고, 출입구 보강을 하면 80이다.
- **위협**: 탐험마다 +2, 매주 +1씩 쌓인다(최대 100). 창문 가림막이 있으면 쌓이는 속도 ×0.7, 청소 −2.
- 위쪽 띠에 **방어 a · 위협 b** 로 표시된다. 둘의 차이가 습격 확률을 정한다. → [습격과 침입](40_습격과_침입.md)
- 거점 서랍의 **안전** 칸에서 이번 주 밤 습격 가능성과, 습격이 오면 막을 수 있을지를 미리 본다. → [허브 화면 §4](18_허브_화면.md#4-거점-상황-서랍)

## 4. 단면도에 보이는 설비
지은 설비는 단면도의 **그 방 안에** 그림으로 놓인다.

| 곳 | 보이는 것 |
|---|---|
| 현관 | 바리케이드(출입구를 보강하면 더 단단한 모습이 된다), 깡통 경보장치 |
| 창고 | 작업대(Ⅱ로 올리면 바이스·공구판) |
| 과학실 | 모래 필터 → 자동 정수기 |
| 가사 실습실 | 끓임 정수대 |
| 방송실 | 자전거 발전기, 벽에 걸린 CD 자켓 |
| 옥상 | 빗물통, 안테나, 텃밭 → 비닐하우스 → 스프링클러 |
| 바깥 마당 | 모래주머니(방어 20부터), 함정, 교문 허수아비 |

- 밤에는 사람이 있는 방에만 불이 켜진다.
- 열지 않은 방은 어둡고 이름이 "?"로 보인다. 버려 둔 흔적이 어둠 속에 실루엣으로 비친다.
- 폭설 기간에는 지붕에 눈이 쌓이고 1층 창에 판자가 덧대진다.
- 동료가 늘면 침낭 줄, 긴 식탁, 당번표 같은 살림이 늘어난다. 장마에는 물 새는 곳에 양동이가 놓인다.
