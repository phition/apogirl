# 이번 주 배분하기

"한 주 실행 ▶"을 누르면 실행 전에 **식단·배분 화면**이 뜬다. 맨 위에서 이번 주 식단을 정하고, 그 아래에서 사람마다 나눠 줄 것을 고른다. 고른 뒤 "배분하고 실행 (n)" 또는 "배분 없이 실행"을 누른다. 받은 사람은 그 주에 머리 위로 말풍선을 띄운다.

- 1주차(창고에 갇힌 주)에는 이 화면이 나오지 않는다.
- 동료가 많아지면 사람 목록을 스크롤해서 본다.

## 1. 이번 주 식단
식량과 물을 **따로** 고른다. 주인공·선생님·동료가 모두 같은 식단으로 먹는다.

| 식단 | 한 사람 하루 소비 | 아침마다 한 사람이 얻는 것 |
|---|---|---|
| 아껴 먹는다 | 1 | 포만 +14 / 수분 +15 |
| 챙겨 먹는다 | 2 | 포만 +28 / 수분 +30 |
| 잘 먹는다 | 3 | 포만 +42 / 수분 +45 |

- 화면에 "이번 주 N개 필요 · 창고 M개"가 나온다. 겨울에는 식량이 ×1.2 든다.
- 밤이 되기 전에 포만 −8, 수분 −8이 빠진다. "아껴 먹는다"로도 조금씩은 오른다.
- 창고가 모자라 식단을 못 지킨 날은 있는 만큼 나눠 먹고, 모두 스트레스 +1~3이다.
- 넉넉할 때 "잘 먹는다"로 포만을 올려 두면 든든함 단계의 덤(체력 +2, 스트레스 −2)을 받는다. → [몸 상태 §4](14_몸_상태.md#4-포만과-수분)

## 2. 나눠 주기
- 받을 수 있는 사람: 윤 선생님과 합류한 동료
- 한 사람에게 **종류마다 주 1회**

| 종류 | 비용 | 효과 |
|---|---|---|
| 먹을 것 | 식량 1 | 포만 +45, 스트레스 −3, 호감 +2 |
| 마실 것 | 식수 1 | 수분 +55, 스트레스 −2, 호감 +2 |
| 약 | 의약품 1 | 스트레스 −5, 호감 +2. **다친 사람이면 부상이 1주 빨리 낫고 호감 +4**. 가벼운 상처는 바로 낫는다 |
| 선물 | 창고의 기호품 1 | 좋아하는 물건(♥)이면 호감 +6·스트레스 −10, 아니면 +2·−3 |

- 같은 선물을 2주 안에 또 주면 효과가 반이다.

## 3. 기호품 16종
| 받는 사람 | 좋아하는 것 |
|---|---|
| 윤 선생님 | 문고본 소설, 빨간 볼펜 |
| 박 선생님 | 믹스커피, 핸드크림 |
| 도현 | 만화책, 이온음료 |
| 송예지 | 인형 키링, 스티커 |
| 최하린 | 머리끈·핀, 립밤 |
| 선배 | 기타 악보, 기타 줄 |
| 유랑자 | 낡은 지도, 사탕 |
| 고양이 | 참치캔, 고양이 간식 |

**얻는 법**
- 탐험 전리품: 지역마다 나오는 물건이 다르다. 자동 탐험이면 낮 30%, 밤 15% 확률.
- 동료가 외출에서 주워 온다(10%).

## 4. 요령
- 식단은 창고를 보고 정한다. 3주치가 넉넉하면 "잘", 한 주를 버틸 만하면 "챙겨", 아니면 "아껴"가 무난하다.
- 결산 일기장의 "몸과 마음" 쪽과 인물 서랍의 몸 상태 막대를 보고, **허기·목마름 단계에 있는 사람에게 먼저** 준다.
- 스트레스 70을 넘은 동료는 일을 반만 한다. 좋아하는 선물(−10)이 가장 빠른 처방이다.
- 식량이 넉넉하지 않을 때는 아무에게도 주지 않는 것도 선택이다. 다만 6주 동안 아무것도 챙기지 않으면 호감이 떨어진다.
