# 용어집

| 용어 | 뜻 | 문서 |
|---|---|---|
| 강제 휴식 | 탐험 바로 다음 칸. 다른 행동을 넣으면 위반 벌칙 | [한 주의 흐름](10_한주의_흐름.md) |
| 개인 장면 | 호감 20·50·60에서 열리는 동료 장면 | [특기와 개인 장면](35_특기와_개인장면.md) |
| 거점 상황 | 거점 서랍. 알림·안전·식량과 물·전력·시설·역할을 한 장에 보여 준다 | [허브 화면](18_허브_화면.md) |
| 거처 | 지금 지내는 방(본관 창고 또는 교실) | [거점과 시설](15_거점과_시설.md) |
| 결산 | 주말의 일기장 화면. 자동 저장 | [한 주의 흐름](10_한주의_흐름.md) |
| 고정 시간표 | 선생님 추천을 누를 때마다 같은 칸에 들어가는 행동. 압정으로 꽂는다 | [한 주의 흐름](10_한주의_흐름.md) |
| 그날 보고 | 진행 속도 "보통"에서 하루가 끝날 때마다 뜨는 확인 창 | [한 주의 흐름](10_한주의_흐름.md) |
| 깊은 곳 | 2막 이후 지역 다섯 곳의 지하층 미로 | [깊은 곳](25_깊은_곳.md) |
| 나침반 | 유랑자에게 받는 물건. 탐험 화면에 나가는 길이 표시된다 | [특기와 개인 장면](35_특기와_개인장면.md) |
| 내구도 | 무기·방어구·쇠지렛대가 닳는 정도. 0이 되면 부서진다 | [아이템](23_아이템.md) |
| 노출도 | 낮 탐험이 잦을수록 쌓여 적대적 생존자를 부른다 | [적](22_적.md) |
| 논문 | 탐험에서 주워 돌아오면 바로 읽는 종이 묶음. 수업 2번만큼 오른다 | [아이템](23_아이템.md) |
| 대성공 | 성공 가운데 15%. 성장 ×1.5 | [능력치](12_능력치와_성장.md) |
| 대신 다침 | 호감 60 이상 동료가 습격 피해를 대신 받음 | [위기 이탈](36_위기_이탈.md) |
| 도크 | 허브 아래 14칸 줄. 요일로 나온다 | [허브 화면](18_허브_화면.md) |
| 동아리 | 밤 행동 4종(14주~) | [동아리](42_동아리.md) |
| 방어(방어도) | 설비로 쌓는 거점 방어. 상한 60/80 | [습격과 침입](40_습격과_침입.md) |
| 배분하기 | 실행 전에 먹을 것·마실 것·약·선물을 나눠 줌 | [배분하기](34_배분하기.md) |
| 보관함 | 거점 서랍 왼쪽 덧판. 자원과 창고에 쌓인 물건을 본다 | [허브 화면](18_허브_화면.md) |
| 부상 | 한 번에 체력 30% 넘게 잃으면 생김. 의약품으로만 나음 | [몸 상태](14_몸_상태.md) |
| 비상구(일방 출구) | 깊은 곳에서 나가면 등 뒤에서 잠기는 문 | [깊은 곳](25_깊은_곳.md) |
| 빗물 | 정수해야 마실 수 있는 물 | [자원](13_자원.md) |
| 빗장 문 | 깊은 곳 특별한 방의 문. 조용히 열리지만 안에 감염자가 갇혀 있다 | [깊은 곳](25_깊은_곳.md) |
| 생존 백과 | PC통신 〈이제누리〉 안에서 읽는 이 위키 | [PC통신](46_PC통신.md) |
| 선생님 추천 | 계획 보드의 빈 칸을 윤 선생님이 채워 주는 기능 | [한 주의 흐름](10_한주의_흐름.md) |
| 설계도 | 제작 줄과 단계를 한눈에 보는 화면 | [제작](19_제작.md) |
| 세력 덧판 | 인물 서랍 왼쪽에 펼쳐지는 세력 카드 | [허브 화면](18_허브_화면.md) |
| 셔터 | 낮에는 열 수 없는 방 | [지역](24_지역.md) |
| 수면 부채 | 0~5. 밤 휴식 두 번 연속으로만 줄어듦 | [몸 상태](14_몸_상태.md) |
| 숙련 | Lv0~5. 수업으로 오르는 기술 | [능력치](12_능력치와_성장.md) |
| 습격 | 4주~ 밤에 거점을 노리는 무리 | [습격과 침입](40_습격과_침입.md) |
| 식단 | 이번 주에 한 사람이 하루에 먹고 마시는 양. 아껴·챙겨·잘 먹는다 | [배분하기](34_배분하기.md) |
| 여유 전력 | 발전 용량 − 켜진 기기 | [자원](13_자원.md) |
| 외출 | 동료가 낮에 혼자 물자를 구하러 나감 | [동료 외출](33_동료_외출.md) |
| 위기 주 | 식량·식수가 바닥나거나 습격이 뚫린 주. 떠나려는 동료의 말이 달라진다 | [위기 이탈](36_위기_이탈.md) |
| 위협 | 탐험·시간이 쌓아 올리는 습격 압력 | [습격과 침입](40_습격과_침입.md) |
| 이제누리 | 컴퓨터실에서 전화선으로 접속하는 PC통신(전국 학교 교육 통신망) | [PC통신](46_PC통신.md) |
| 자동 탐험(헤드리스) | 직접 조종하지 않고 결과만 받는 탐험 | [탐험 기초](20_탐험_기초.md) |
| 작업대 | 제작의 뿌리. Ⅰ은 2주차부터, Ⅱ는 공학 Lv2부터 | [제작](19_제작.md) |
| 적성 | 동료마다 잘 맞는 역할. 효과 ×1.25 | [동료 역할](32_동료_역할.md) |
| 전력(빛 도구) | 손전등·헤드랜턴이 켜 둔 동안 쓰는 것. 건전지·배터리로 채운다 | [아이템](23_아이템.md) |
| 전투력 | 근력·민첩·체력·호신에서 나오는 방어 수치 | [능력치](12_능력치와_성장.md) |
| 제작 중 | 여러 칸이 드는 제작의 뒤 칸. 계획할 때부터 잠긴다 | [제작](19_제작.md) |
| 챙길 것 | 출정 준비에서 창고 소모품을 배낭에 넣어 가는 칸 | [탐험 기초](20_탐험_기초.md) |
| 큰 문 | 깊은 곳 특별한 방의 무거운 철문. 길게 밀어 열고, 열리면 크게 울린다 | [깊은 곳](25_깊은_곳.md) |
| 특기 | 세 번째 개인 장면을 본 뒤, 호감 60 이상일 때 켜져 있는 동료 능력 | [특기](35_특기와_개인장면.md) |
| 특별한 방 | 깊은 층마다 둘 있는, 늘 찬 상자가 있는 방 | [깊은 곳](25_깊은_곳.md) |
| 특성 | 프롤로그 동아리가 주는 주인공 능력 | [능력치](12_능력치와_성장.md) |
| 포만·수분 | −100~+100. 아침에 식단대로 먹어 오르고 밤이 되기 전에 빠진다 | [몸 상태](14_몸_상태.md) |
| 함께한 시간 | 같은 방에 있던 동료의 호감이 오름 | [호감과 관계](31_호감과_관계.md) |
| 행동 스트레스 | 쉬는 일정이 아닌 모든 행동이 주는 스트레스. 1~5단계 = +5~10 | [행동 목록](11_행동_목록.md) |
| 허수아비 | 교문에 세우면 밤 습격 세기를 줄이고, 탐험에 들고 가면 좀비를 끌어모은다 | [제작](19_제작.md) |
| 황혼 | 낮 탐험 시계가 끝난 뒤. 모든 무리가 깨어나고, 낮에 잠긴 방이 열린다 | [탐험 기초](20_탐험_기초.md) |
| 후문으로 들어가기 | 보조 출구를 열어 둔 지역에 탈출로 쪽에서 들어가는 것 | [탐험 기초](20_탐험_기초.md) |
| 휴면 | 낮에 잠든 감염자 무리. 각성 게이지를 함께 씀 | [소음·시야·은신](21_소음_시야_은신.md) |
| 휴면열 | 이 세계의 감염병 이름 | [개요](01_개요_세계관.md) |
| 흐름 띠 | 계획 보드 아래의 피로·스트레스·수면 부채 예상 그림 | [한 주의 흐름](10_한주의_흐름.md) |
