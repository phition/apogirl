# 갤러리·2회차·되돌리기

## 1. 엔딩 갤러리
- 타이틀 메뉴에 있다. 세이브와 따로 기록된다.
- 엔딩마다 처음 본 주차와 본 횟수를 남긴다. 완치 엔딩은 본 **변형**도 따로 기록한다.
- "N / M 해금". 보지 못한 칸은 "? ? ?"로 나온다.

## 2. 음악실
- 한 번이라도 들은 CD 곡을 타이틀에서 다시 들을 수 있다. → [CD 수집과 음악실](45_CD와_음악실.md)

## 3. 2회차
엔딩을 하나라도 본 뒤 새 게임을 시작하면 2회차다.

### 3.1 시작 보너스(하나 고름)
| 보너스 | 효과 |
|---|---|
| 단련된 몸 | 체력·근력·민첩 +5 |
| 먼저 읽은 책 | 지력 +5, 감수성 +3, 인문·의학 Lv1 |
| 숨겨 둔 상자 | 식량·물 +12, 의약품 +4, 등산 배낭 |

### 3.2 달라지는 이야기
- 창고의 6일 동안 처음에는 들리지 않던 문장이 섞인다.
- 여섯째 날 회상 「창고 안의 7일」이 나온다. ⚠️ 여기서 진실 단서 하나와 자기 이해 +2를 얻는다. 이 단서는 2회차에서만 얻을 수 있다.

## 4. 이번 주 되돌리기
| 항목 | 내용 |
|---|---|
| 난이도 | 이야기 중심만 |
| 해금 | 한 번이라도 **52주차까지 가서** 엔딩을 봤을 때 |
| 위치 | 주간 결산 일기장 아래 |
| 효과 | 방금 실행한 주를 시작 직전으로 되돌린다 |
| 제한 | 같은 주는 한 번만. 게임 오버가 난 주, 세이브를 불러온 직후에는 안 된다 |

> "…이번 주는 다시 되돌릴 수 없다."

## 5. 저장
- 결산 때마다 자동으로 저장한다. 위쪽 띠의 "저장"으로 슬롯에 직접 저장할 수도 있다.
- 타이틀의 "이어하기"·"불러오기"로 다시 시작한다.
