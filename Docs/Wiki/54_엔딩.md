# 엔딩 목록

> ⚠️ **모든 엔딩의 조건이 나온다.** 스스로 찾아보고 싶다면 읽지 않기를 권한다.

## 1. 정하는 방식
1. **게임 오버**(52주 전에 체력 0, 정신 붕괴, 감염 100)면 원인에 맞는 **배드 엔딩**이 된다.
2. 52주를 버텨 **구조**되면, 조건을 만족한 엔딩 가운데 **우선순위가 가장 높은 것**을 고른다. 우선순위가 같으면 점수가 높은 쪽이다.
3. 아무 조건도 맞지 않으면 기본 엔딩 「옥상의 아침」이다.

## 4. 엔딩 연출 순서 (구조 엔딩)
1. 제목 → 엔딩 컷 3장
2. 공통 덧붙임 줄
   - 선생님: 완치 / 마지막 수업 / 격리 / 드러남 / 남겨 둠 / 기본
   - 친구: 물자 / 털어놓음 / 약속 / 기본 — 프롤로그의 약속이 여기서 돌아온다
   - 찾은 치료 단서 수(1·3·6개)
   - 탐험 성향: 집 / 밤 / 낮 / 섞음
3. **그 뒤의 이야기**(후일담, §5)
4. **1년의 기록**: 능력치 그래프, 낮·밤 탐험 횟수, 동료, 주요 장면, 일기 52줄
5. 타이틀로

## 5. 후일담
묶음마다 조건을 만족한 줄 가운데 우선순위가 가장 높은 **한 줄**이 나온다.

| 묶음 | 갈래(우선순위 높은 순) |
|---|---|
| 사거리 파 | 같이 막음 > 준이 막아섬 > 적대 결말 > 휴전 > 기본 |
| 더불어 마트 | 호의를 두고 떠남(정 반장의 엽서) > 창고를 두고 봄 > 떠남 > 기본 |
| UBC | 동맹 > 민규를 구함 > 구조 명단 중계 > 기본(98.3의 잡음) |
| 동료(5명 각자) | 위기 이탈로 떠남 > 그 사람만의 갈래 > 가까움(호감 80+) > 기본 > 서먹함(20 미만) |
| 그 밖 | 좌석 빈자리, 고양이, 준, 유랑자(백의 나침반), 졸업장("담임 도장만 찍혀 있었다") |
| 마음 | 프롤로그에서 고른 마음가짐의 장면들을 어떻게 지나왔는가 |
| 희망 | 희망으로 붙잡은 동료가 있었는가 |

그 사람만의 갈래:
- 도현: 어머니를 만남
- 박 선생님: 의족을 완성함
- 송예지: 작별 장면
- 하린: 다시 만나기 / 여기서 끝
- 선배: 막아섬 / 이름을 지킴 / 웃음 / 옥상 고양이

## 6. 엔딩 비율 (자동 시험, 표준 난이도)
다섯 가지 전략을 자동으로 40판씩 돌린 결과다(2026-11-25). 사람이 하는 판과는 다르다.

| 묶음 | 전체 |
|---|---|
| 기본·균형 | 23% |
| 특화 | 8% |
| 관계·서사 | 14% |
| 히든 | 3% |
| 배드 | 53% |

낮과 밤을 **섞어서** 나가는 전략이 가장 오래 산다(열 판 가운데 여덟 판쯤 구조된다). 밤에만 나가면 수면 부채와 물림으로 무너지기 쉽다.
