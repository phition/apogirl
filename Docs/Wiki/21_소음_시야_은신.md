# 소음·시야·은신

> 보이지 않는 것을 **듣고**, 들리지 않게 **걷고**, 들키면 **숨는다**.

## 1. 소음
모든 동작은 반경(칸 단위) 안의 좀비에게 들린다. 좀비는 소음을 ×1.4로 더 크게 듣는다.

| 동작 | 반경 |
|---|---|
| 웅크려 걷기 | 0.8 |
| 버리기 | 3 |
| 수색(0.5초마다) | 3.5 |
| 걷기 | 4 |
| 계단 | 4.5 |
| 문 | 5.5 |
| 밀치기 · 쇠지렛대 | 7 |
| 달리기 | 11 |

| 무기 | 휘두를 때 |
|---|---|
| 경찰 삼단봉 | 4 |
| 대걸레 · 나무 몽둥이 · 테이프 감은 몽둥이 | 5 |
| 야구방망이 | 6 |
| 쇠파이프 | 7 |
| 철근 덧댄 몽둥이 | 8 |

**소음을 바꾸는 것**
| 요인 | 배율 |
|---|---|
| 벽 너머(방 ↔ 복도) | ×0.6 |
| 비 오는 주 | −25% |
| 특성「그림자」 | −20% |
| 장바구니 / 등산 배낭 / 프레임 배낭 | ×0.9 / ×1.05 / ×1.08 |
| 매트 덧댄 보호구 / 두꺼운 패딩 / 철판 덧댄 조끼 | ×1.05 / ×1.1 / ×1.15 |
| 깊은 곳 / 침수층 | ×1.2 / ×1.5 |
| 무게 초과 | ×1.5 |

## 2. 잠든 무리
- 낮의 좀비는 무리 지어 잠들어 있다. 무리는 **각성 게이지**를 함께 쓴다.
- 소음이 닿거나 근처(4칸 안)에 머물면 게이지가 오른다. 화면에는 "무리가 뒤척인다"가 뜬다.
- 100이 차면 "무리가 깨어났다…" — 함께 깨어나고, 반경 12 안의 다른 무리도 줄줄이 깬다.
- 잠든 좀비도 때릴 수 있다. 하지만 맞히는 소리로 무리가 깨기 쉽다.

## 3. 시야와 어둠

### 3.1 어두운 곳
- 밤, 황혼에 무리가 깨어난 뒤, 그리고 **낮이라도 방 안과 깊은 곳**은 어둡다.
- 어두운 곳에서는:
  - 맨눈으로 3.5칸까지만 보인다.
  - 손전등을 켜면 비추는 쪽으로 9칸까지 보인다(헤드랜턴·랜턴 멀티툴은 약 12칸).
  - 좀비·사람뿐 아니라 **장식·수색할 곳도 안개처럼 가려진다.**
- 다른 층·다른 방에 있는 것은 낮에도 보이지 않는다.

### 3.2 좀비 눈에 띄는 정도
| 상황 | 배율 |
|---|---|
| 낮 | 1 |
| 어둠 | 0.6 |
| 손전등 켬 | 1.5 (멀리 보는 대신 잘 들킨다) |
| 헤드랜턴·랜턴 멀티툴 켬 | 1.3 |
| 웅크림 | 좀비 시야 ×0.6 |

### 3.3 손전등
- 도구 칸에 손전등(또는 헤드랜턴·랜턴 멀티툴)이 있어야 F로 켤 수 있다.
- 빛 도구는 **전력**을 쓴다. 켜 둔 동안에만 줄어든다. 바닥나면 꺼지고, 배낭에 건전지가 있으면 하나를 써서 40%를 채운다.
- 마우스 높이를 따라 빛이 위아래 ±50° 꺾인다(보이는 빛만 바뀐다).
- 밤·황혼에 손전등 없이 수색하면 시간이 ×1.6 걸린다.

## 4. 문 앞의 감각

### 4.1 문틈 살피기 (W 길게)
| 때 | 보이는 범위 |
|---|---|
| 낮, 복도 쪽 | 7칸 |
| 낮, 방 안 | 문 근처 2.5칸 |
| 황혼(낮 시계가 끝난 뒤) | 밤과 같다 |
| 밤 | 아무것도 안 보인다 — "너무 어두워 문틈 너머가 보이지 않는다. 귀를 기울여 보자 (S)" |

- 살피는 동안 안쪽 좀비에게 0.35배로 노출된다. 들키면 "안쪽의 무언가가 이쪽을 봤다!"

### 4.2 귀 기울이기 (S 길게, 1.2초)
| 문구 | 뜻 |
|---|---|
| "조용하다. 아무 소리도 들리지 않는다." | 안전하다(적어도 가까이에는) |
| "낮은 숨소리… 잠든 무언가가 있다." | 8칸 안에 잠든 좀비가 있다 |
| "안쪽에서 발소리가 들린다. (하나/여럿)" | 깨어 있는 좀비가 있다 |
| "바로 문 너머에서 발소리가 난다!" | 4칸 안에 있다. 들어가지 말 것 |

### 4.3 창 너머 실루엣
- 방 안에서는 창밖 복도의 좀비가, 복도에서는 교실 창 안의 좀비가 **창 유리 안에만** 어두운 형체로 보인다.
- 잠든 좀비는 낮게 보인다. 밤에는 시야 규칙을 따른다.

## 5. 숨기
- 사물함·책상 앞에서 **Space를 길게** 누른다.
- 걸리는 시간 = 1.5초 ÷ (1 + 민첩×0.01), 최소 0.4초
- 쫓아오는 좀비가 4칸 안에서 보고 있으면 "숨을 틈이 없다!" — 숨을 수 없다.
- 적대적 생존자는 2.5칸 안이면 숨은 사람도 찾아낸다.
- 숨은 뒤 Space를 한 번 누르면 나온다.

### 5.1 숨다가 잠들기
- **수면 부채 2 이상**이면 숨어 있는 1초마다 (부채 − 1) × 1.5% 확률로 잠든다.
  - 부채 2면 1.5%/초, 5면 6%/초
- "긴장이 풀려 깜빡 잠들어 버렸다…"
- 잠든 동안 **시계가 2배로** 흐른다.
- Space 연타 한 번에 12%씩 깨어나고, 손을 놓으면 초당 30%씩 도로 잠긴다.
- 물리면 바로 깬다: "윽! 물리는 아픔에 번쩍 깼다!"

## 6. 추격에서 벗어나기
- 좀비는 문과 방을 따라 들어오지만 **계단은 따라오지 않는다.**
- 놓친 좀비는 5초쯤 서성이다 물러난다.
  - 낮: 6칸 물러나 다시 잠든다.
  - 밤: 18칸 물러나 깨어 있는 채 돌아다닌다.
- 밀치기(범위 1.3, 기절 2.5초, 쿨다운 1.5초)로 틈을 만들 수 있다.
- 기절한 좀비와 생존자의 머리 위에는 별이 돈다. 별이 도는 동안은 움직이지 못한다.
- 물린 뒤 2초 동안은 다시 물리지 않는다.
- **휴대 허수아비**를 세워 두면 소리를 내서 좀비를 그쪽으로 끌어모은다. → [제작 §7.2](19_제작.md#72-휴대-허수아비--울리는-허수아비)

## 7. 수색
| 수색할 곳 | 기본 시간 |
|---|---|
| 책상 | 2초 |
| 상자 | 2.5초 |
| 사물함 | 3초 |
| 수납장 | 3.5초 |
| 냉장고 | 4초 |

- 실제 시간 = 기본 × (1 − 손재주×0.3%, 최대 30% 단축) × 0.7
- 스트레스 60을 넘으면 더 오래 걸린다(100이면 +50%). 그 순간 짜증 섞인 한숨 소리가 난다.
- 특성「세심한 눈」은 +20%, 정찰 역할 동료는 +10% 빠르게 한다.
- 수색하는 동안 0.5초마다 소음 3.5가 난다.
