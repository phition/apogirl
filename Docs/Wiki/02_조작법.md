# 조작법

## 1. 허브(학교)

| 키 | 동작 |
|---|---|
| 마우스 왼쪽 | 방·버튼·칸 고르기. 단면도에서 방을 누르면 그 방에서 할 수 있는 행동이 뜬다 |
| 마우스 오른쪽 | 계획 보드에서 칸 비우기 |
| **Tab** | 계획 보드 열기·닫기 |
| **Esc** | 맨 위 창 닫기(배분·세력 화면이 먼저 닫힌다) |
| Space / Enter | 대사·엔딩 넘기기 |

- 결과 카드, 대화, 결산, 출정 준비, 배분 화면이 열려 있을 때는 Tab·Esc로 보드를 조작할 수 없다.
- 위쪽 띠의 **사람들** 버튼은 인물 서랍을, 왼쪽 생명 수치 요약은 **생활기록부**를 연다.

## 2. 탐험

| 키 | 동작 |
|---|---|
| A / D, ← / → | 걷기 |
| Shift | 달리기(스태미너 소모, 소음 큼) |
| 왼쪽 Ctrl | 웅크려 걷기(소음 아주 작음, 좀비 눈에 덜 띔) |
| **마우스 왼쪽** 또는 Q | 바라보는 방향 공격. 무기가 없으면 밀치기 |
| **마우스 오른쪽** 또는 E | 길게: 수색. 짧게: 들어가기·계단·문·탈출·다가가기 |
| **Space 길게** | 숨기(사물함·책상 앞). 숨은 뒤 Space 한 번에 나오기. 잠들었으면 연타로 깨기 |
| F | 손전등 켜기·끄기(도구 칸에 손전등 필요) |
| 마우스 위아래 | 손전등 빛 방향(±50°) |
| **W 길게**(문 앞) | 문틈 살피기 |
| **S 길게**(문 앞) | 귀 기울이기(1.2초) |
| 1 ~ 4 | 퀵슬롯 소모품 쓰기 |
| Tab | 배낭 열기 |
| Space / Enter | 탐험 중 대화 넘기기 |

- 열린 배낭이나 전리품 창 위를 누르면 공격·수색이 아니라 창이 그 클릭을 받는다.
- 자세한 규칙은 [소음·시야·은신](21_소음_시야_은신.md)에 있다.

## 3. 휴대폰판

- 지금 휴대폰판에는 터치 탐험이 없다. 탐험은 **자동**으로 결과만 받는다. → [탐험 기초 §6](20_탐험_기초.md#6-자동-탐험)

## 4. 개발용 키 (테스트 빌드)

| 화면 | 키 |
|---|---|
| 허브 | F1 디버그 패널(해금, 이벤트 강제, 엔딩 확인) |
| 탐험 | F2 ×10 속도 · F3 AI·소음 보기 · F4 무적 · F5 시야 · F6 아이템 · F7 +1분 · F8 시계 끝 · F9 후처리 켜고 끄기 |

디버그 기능을 쓴 판은 플레이 기록에서 빠진다.
