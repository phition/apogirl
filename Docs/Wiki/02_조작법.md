# 조작법

## 1. 허브(학교)

| 키 | 동작 |
|---|---|
| 마우스 왼쪽 | 방·버튼·칸 고르기. 단면도에서 방을 누르면 그 방에서 할 수 있는 행동이 뜬다 |
| 마우스 왼쪽 끌기 | 계획 보드에서 행동 카드를 칸에 끌어다 놓기, 넣은 칸을 다른 칸으로 옮기기 |
| 마우스 오른쪽 | 계획 보드에서 칸 비우기 |
| **Tab** | 계획 보드 열기·닫기 |
| **Ctrl+Z** / Ctrl+Shift+Z·Ctrl+Y | 계획 보드에서 되돌리기 / 다시 하기 |
| **Esc** | 맨 위 창 닫기(배분·세력 화면이 먼저 닫힌다) |
| Space / Enter | 대사·엔딩 넘기기 |

- 결과 카드, 대화, 결산, 출정 준비, 배분 화면이 열려 있을 때는 Tab·Esc로 보드를 조작할 수 없다.
- 위쪽 띠의 **사람들** 버튼은 인물 서랍을, **거점** 버튼은 거점 상황 서랍을, 왼쪽 생명 수치 요약은 **생활기록부**를 연다.
- 컴퓨터실의 컴퓨터를 누르면 PC통신에 접속한다. 명령은 글자로 치고 Enter를 누른다. → [PC통신 '이제누리'](46_PC통신.md)

## 2. 탐험

| 키 | 동작 |
|---|---|
| A / D, ← / → | 걷기 |
| Shift | 달리기(스태미너 소모, 소음 큼) |
| 왼쪽 Ctrl | 웅크려 걷기(소음 아주 작음, 좀비 눈에 덜 띔) |
| **마우스 왼쪽** 또는 Q | 바라보는 방향 공격. 무기가 없으면 밀치기 |
| **마우스 오른쪽** 또는 E | 길게: 수색. 짧게: 들어가기·계단·문·탈출·다가가기 |
| **Space 길게** | 숨기(사물함·책상 앞). 숨은 뒤 Space 한 번에 나오기. 잠들었으면 연타로 깨기 |
| F | 손전등 켜기·끄기(도구 칸에 빛 도구 필요) |
| 마우스 위아래 | 손전등 빛 방향(±50°) |
| **W 길게**(문 앞) | 문틈 살피기 |
| **S 길게**(문 앞) | 귀 기울이기(1.2초) |
| Tab | 배낭(가방이 없으면 주머니) 열기 |
| Space / Enter | 탐험 중 대화 넘기기 |

**배낭 안에서**

| 조작 | 동작 |
|---|---|
| 물건 왼쪽 클릭 | 작은 설명 창(분류·설명·효과, 사용·장착·버리기 단추) |
| 물건 오른쪽 클릭 | 소모품은 쓰기, 장비는 장착, 그 밖은 버리기 |
| Shift + 오른쪽 클릭 | 버리기 |
| 장비 칸 오른쪽 클릭 | 벗기(가방은 벗을 수 없다) |

- 화면 아래에 장비 칸 다섯 개(무기·방어구·가방·도구 1·도구 2)가 있다. 배낭에서 고른 장비를 칸에 놓으면 장착한다.
- 큰 문과 빗장 걸린 문은 마우스 오른쪽을 길게 눌러 연다. → [깊은 곳](25_깊은_곳.md)
- 열린 배낭이나 전리품 창 위를 누르면 공격·수색이 아니라 창이 그 클릭을 받는다.
- 자세한 규칙은 [소음·시야·은신](21_소음_시야_은신.md)에 있다.
