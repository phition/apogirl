# 윤 선생님의 병

> ⚠️ 3막 후반 이후의 전개와 히든 엔딩 조건이 나온다.

## 1. 재감염
- 한파·식량 부족·체력 저하가 겹치면 **33~35주**에 앞당겨지고, 아니면 **36주**에 반드시 일어난다.
- 주인공이 고르는 길:

| 길 | 뜻 | 열리는 것 |
|---|---|---|
| 치료법을 찾는다 | 치료 루트 | 완치 시도 |
| 거점에서 돌본다 | 돌봄 루트 | 완치 시도, "함께 남는다"(인간성 72 이상) |
| 거리를 둔다 | 거리 두기 루트 | "조용한 작별" |

## 2. 병세
- 매주 **+6**씩 진행한다.
  - 늘리는 것: 한파 +2
  - 줄이는 것: 의학 Lv마다 −1(최소 2), 보건실 −1, 간호 역할 −1
- 25마다 한 단계씩 오른다. 숫자 대신 증상으로 보인다.

| 단계 | 증상 |
|---|---|
| 1 | 잦은 기침 |
| 2 | 열이 오르내림 |
| 3 | 거의 누워 지냄 → 몸져눕는 장면(교안을 받을지 고른다) |
| 4 | 의식이 흐려짐 |

- **선생님 돌보기**(밤, 의약품 1): 병세 −4, 호감 +1
- 단계가 오를수록 선생님 수업의 호감 보너스가 20%씩 약해진다.

## 3. 완치
아래 조건을 모두 갖추면 **50주까지** 밤에 완치 시도 장면이 나온다.

| 조건 | 내용 |
|---|---|
| 길 | 치료 또는 돌봄 |
| 연구 자료 | 정수장 지하 기록실(밤) |
| 혈액 | 선생님은 **B형**이다. 주인공이 O형이나 B형이면 직접 수혈하고, 아니면(모름 포함) **혈액 팩**이 있어야 한다(약국 진료실 냉장고, 밤) |
| 치료 단서 | 6개 이상 |
| 의학 숙련 | Lv4 이상 |

- 성공률은 **30%**다.
  - 성공하면 완치되어 병세가 사라진다.
  - 실패하면 병세 +5, 스트레스 +10이 붙고 **다시 시도할 수 없다**.
- 어느 쪽이든 주인공은 체력 −15, 피로 +20이다.
- 완치하면 히든 엔딩 「마지막 수업 이후」로 간다. → [엔딩 목록](54_엔딩.md)

## 4. 마지막 선택 (51주~, 완치하지 못했을 때)
| 선택 | 조건 |
|---|---|
| 마지막 수업 | — |
| 방송실 격리 | — |
| 숨기고 함께 탄다(검진에서 드러난다) | — |
| 함께 남는다 | 돌봄 루트 + 인간성 72 이상 → 히든 엔딩 「구조를 거부한다」 |
| 조용한 작별 | 거리 두기 루트 |

- 고른 선택은 엔딩의 '선생님' 줄을 바꾼다.
