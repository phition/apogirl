# 메인 UI 개편 기획서 (2026-11-21, 초안)

거점 허브(메인 화면)와 주간 스케줄의 **편성 → 실행 → 결산** 흐름을 다시 짜기 위한 추천안 5가지.
상태: **방향 선택 대기**. 방향이 정해지면 화면 시안 → 설계 요약 → 구현 순서로 간다.

---

## 1. 지금 화면의 문제

지금 허브는 한 화면에 다섯 덩어리(상단 자원, 왼쪽 상태, 가운데 그림 + 선생님 한마디, 오른쪽 행동 목록, 아래 7일 × 낮/밤 표)를 모두 펼쳐 놓았다.

| 문제 | 내용 |
|---|---|
| 한 화면에 전부 | 생명 수치 8개, 능력치 8개, 숙련도 9개, 자원 7개, 행동 목록, 14칸 표가 늘 같이 보인다. 지금 봐야 할 것과 가끔 볼 것의 구분이 없다 |
| 주인공이 없다 | 육성 게임인데 화면에 주인공이 보이지 않는다. 키우는 대상의 변화(옷·표정·상처)를 볼 자리가 없다 |
| 거점이 그림 한 장 | 시설·동료·세력이 왼쪽 패널 맨 아래 글자 몇 줄이다. 학교를 고쳐 가는 재미가 화면에 드러나지 않는다 |
| 편성이 표 채우기 | 행동을 고르고 칸을 누르는 반복. 하루의 흐름이나 "이번 주는 이렇게 산다"는 감각이 약하다 |
| 실행 연출이 없다 | "한 주 실행"을 누르면 결과 카드가 차례로 뜬다. 무슨 일이 일어나는지 보는 맛이 없다 |
| 도구 같은 생김새 | 어두운 패널과 글자 목록. 세계관(버려진 학교, 마지막 학기)이 UI에 묻어나지 않는다 |
| 깊이가 없다 | 화면이 한 겹이라 새 기능(세력, 요리, 부상, 청결…)이 생길 때마다 같은 패널에 줄이 늘어난다 |

## 2. 어떤 안을 고르든 지킬 것

1. **적층 구조 (다섯 겹)**
   - 0겹 **장면**: 거점의 모습. 시간·계절·날씨·시설 상태가 여기에 보인다
   - 1겹 **상시 표시**: 날짜, 핵심 자원 2~3개, 위험 신호만. 화면 가장자리에 얇게
   - 2겹 **펼침 패널**: 상태·거점·동료·세력·일기. 필요할 때 옆에서 밀려 나온다
   - 3겹 **집중 화면**: 주간 편성, 탐험 준비, 결산. 장면을 흐리게 덮는 전용 화면
   - 4겹 **이야기**: 대사·선택지·컷. 지금 대화창을 그대로 쓴다
2. **한 주의 세 박자**: 편성(고민) → 실행(구경) → 결산(되새김)이 서로 다른 화면 분위기를 가진다
3. **점진적 노출 유지**: 1주차에는 식량·물만 보이는 지금 규칙(문서 5.3)을 그대로 따른다. 겹이 나뉘면 오히려 지키기 쉽다
4. **선생님의 자리**: 편성 중 조언, 결산의 화자. 재감염 뒤 문장과 초상이 바뀌는 것이 눈에 띄어야 한다
5. **결산은 수치와 이야기를 함께**: 능력치 그래프 옆에 일기 한 단락을 나란히 둔다
6. **기준 1920×1080**, 1280×720까지 깨지지 않게. 키보드·패드로 다 되게(M8-4와 맞물림)
7. **코어는 그대로**: `GameSession`·`WeekRunner`는 건드리지 않는다. 바뀌는 것은 `Hub.uxml`·`HubScreen`·`HubViews`·`Theme.uss`

## 3. 추천안

### A안. 정통 육성 시뮬레이션 (프린세스 메이커 계열)

**한 줄**: 방 안에 선 주인공을 가운데 크게 두고, 명령 메뉴로 한 겹씩 들어간다.

```
┌──────────────────────────────────────────────────────────┐
│ 4월 3주 · 봄 · 맑음            식량 14  물 20   ⚠ 수면 부족 │
├──────────────────────────────────────────────────────────┤
│                                              ┌─────────┐ │
│   (거처 배경: 창고 / 교실)                     │ 일정    │ │
│                                              │ 상태    │ │
│          ┌────────┐                          │ 거점    │ │
│          │ 주인공  │    윤 선생님              │ 사람들  │ │
│          │ 입상    │    (앉은 모습)            │ 일기    │ │
│          │        │                          │ 외출    │ │
│          └────────┘                          │ 저장    │ │
│                                              └─────────┘ │
│ ┌──────────────────────────────────────────────────────┐ │
│ │ 윤 선생님: 이번 주는 물이 빠듯하겠다. 하루는 받으러 가자. │ │
│ └──────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────┘
```

- **적층**: 메뉴 → 전용 화면. "일정"을 누르면 달력 화면이, "상태"를 누르면 능력치 화면(오각형 그래프 + 입상)이 장면을 덮는다
- **편성**: 달력 화면에서 하루씩 낮·밤을 고른다. 행동은 카테고리 아이콘 → 세부 목록 두 단계
- **실행 연출**: 슬롯마다 작은 무대에서 SD 캐릭터가 그 행동을 한다(공부하면 책상에서 끄덕, 실패하면 졸기). 아래에 수치가 톡톡 올라간다. 빠르게·건너뛰기 가능
- **결산**: 선생님이 통지표를 읽어 주는 화면
- **장점**: 장르 팬에게 가장 익숙하다. 주인공이 늘 보여 애착이 생긴다. 옷·표정·상처 변화(문서의 레이어드 스프라이트)를 보여 줄 자리가 생긴다
- **단점**: **그림이 가장 많이 든다**. 주인공 입상(옷 4 × 표정 × 상처), 행동별 SD 애니메이션 20여 종. 거점을 고쳐 가는 느낌은 여전히 약하다
- **작업량**: UI 중간, 아트 큼

### B안. 거점 단면도 (공간이 곧 메뉴)

**한 줄**: 학교 건물의 단면을 화면에 펼치고, 방을 눌러 그 방에서 할 일을 고른다.

```
┌──────────────────────────────────────────────────────────┐
│ 4월 3주 · 봄 · 맑음   식량 14  물 20         [수첩] [메뉴] │
├──────────────────────────────────────────────────────────┤
│ 옥상   │ 물통 ▒▒  텃밭(잠김)          하늘·날씨           │
│────────┼──────────────────────────────────────────────── │
│ 2층    │ [교실 = 수업]   [과학실]   [음악실]   [양호실]    │
│        │   선생님 ●        잠김                 도현 ●     │
│────────┼──────────────────────────────────────────────── │
│ 1층    │ [거처] 주인공 ●  [창고 = 물자]  [가사실]  [교문→] │
│────────┴──────────────────────────────────────────────── │
│ 월 화 수 목 금 토 일   ← 이번 주 띠 (낮/밤 14칸, 누르면 편성) │
└──────────────────────────────────────────────────────────┘
```

- **적층**: 0겹이 건물 단면. 방을 누르면 그 방 패널(할 수 있는 행동, 시설 단계, 거기 있는 사람)이 옆에서 나온다. 교문을 누르면 외출·탐험 준비. 사람을 누르면 대화·역할
- **편성**: 방에서 행동을 골라 아래 주간 띠에 놓는다. 띠의 칸에는 그 방의 작은 아이콘이 찍힌다. "어디서 무엇을"이 한눈에 보인다
- **실행 연출**: 시간이 흐르며 단면도 안에서 인물들이 실제로 움직인다. 주인공이 교실로 걸어가 앉고, 밤이 되면 창이 어두워지고 거처에 불이 켜진다. 사건이 생기면 그 방이 강조된다. 습격은 교문 쪽에서 온다
- **결산**: 단면도가 어두워지고 수첩이 펼쳐진다
- **장점**: **탐험에 쓰는 픽셀 아트(방·가구·인물 동작·조명)를 그대로 쓸 수 있다**. 거점이 커 가는 것이 눈에 보인다(시설을 지으면 방이 바뀐다). 탐험 화면과 그림체가 이어진다. 동료·세력이 화면에 사람으로 나온다
- **단점**: 지금 허브의 일러스트(거처 그림)와 그림체가 갈린다. 건물 단면을 화면 하나에 담는 구도를 새로 잡아야 한다. 행동 중 "장소가 없는 것"(휴식, 명상)의 자리를 정해야 한다
- **작업량**: UI 큼, 아트 작음(재사용)

### C안. 대시보드 (웹게임·관리 시뮬레이션)

**한 줄**: 카드 위젯을 격자로 놓고, 숫자와 경고를 읽기 좋게 정리한다.

```
┌──────────────────────────────────────────────────────────┐
│ 마지막 학기   4월 3주      개요 | 일정 | 거점 | 사람 | 기록 │
├───────────────┬──────────────────┬───────────────────────┤
│ 오늘의 경고    │ 이번 주 일정      │ 주인공                │
│ ⚠ 물 2일치     │ 월 수업 / 휴식    │ HP ▓▓▓▓▓░  피로 ▓▓░░ │
│ ⚠ 수면 부채 3  │ 화 물 받기 / …    │ 능력치 변화 ▁▂▃▅      │
├───────────────┼──────────────────┼───────────────────────┤
│ 물자          │ 거점              │ 사람들                │
│ 식량 14 (−9/주)│ 정수 Lv1 · 발전 0 │ 선생님 ♥ 42 · 도현 …  │
│ 물 20 (−12/주) │ 다음: 빗물받이    │ 사거리 파: 경계        │
└───────────────┴──────────────────┴───────────────────────┘
```

- **적층**: 탭(개요·일정·거점·사람·기록) + 카드를 누르면 오른쪽에서 상세 패널. 수치마다 "왜 이 값인가"를 풀어 보여 줄 수 있다
- **편성**: 일정 탭의 주간 달력. 행동을 놓는 즉시 옆 카드의 예상치(식량 −9, 피로 +12)가 바뀐다. 계획의 결과를 미리 읽는 재미
- **실행 연출**: 약하다. 타임라인이 흐르며 기록 줄이 쌓이고 그래프가 움직이는 정도
- **결산**: 지난주 대비 증감표와 그래프
- **장점**: 정보가 가장 잘 읽힌다. 새 기능이 생겨도 카드 하나를 더하면 된다. 그림이 거의 안 든다. 구현이 가장 빠르다. 밸런스 확인에도 좋다
- **단점**: **분위기가 가장 약하다**. 주인공도 학교도 보이지 않아 지금의 "도구 같은 생김새"가 더 깔끔해질 뿐이다. 이야기 중심 게임과 결이 다르다
- **작업량**: UI 중간, 아트 거의 없음

### D안. 다이어리 (주인공의 수첩이 곧 UI)

**한 줄**: 책상 위에 펼친 학교 다이어리. 주간 계획표가 실제 다이어리 쪽이고, 탭 스티커로 넘긴다.

```
┌──────────────────────────────────────────────────────────┐
│   (책상 위: 랜턴, 컵, 휴대폰 — 자원과 시간이 물건으로 보임)  │
│  ┌────────────────────────┬───────────────────────────┐  │
│  │ 4월 셋째 주             │ 할 일                     │ 계획│
│  │ 월  낮 국어 수업         │ □ 물 받기 (이틀 치 남음)   │ 나 │
│  │     밤 쉬기             │ □ 선생님 약                │ 학교│
│  │ 화  낮 물 받으러         │                           │ 사람│
│  │     밤 ____             │ 선생님 메모 (빨간 펜)      │ 일기│
│  │ 수  낮 ____             │ "화요일은 비 온다더라."    │    │
│  │ …                      │                           │    │
│  └────────────────────────┴───────────────────────────┘  │
└──────────────────────────────────────────────────────────┘
```

- **적층**: 탭(계획·나·학교·사람·일기)이 쪽 넘김. 쪽 위에 포스트잇(경고), 끼워 둔 사진(이벤트 그림), 선생님의 빨간 펜 메모(조언)가 겹친다
- **편성**: 빈 줄을 누르면 행동 스티커 묶음이 나온다. 붙이면 손 글씨로 적힌다. 지난주 쪽을 넘겨 "그대로 베끼기"
- **실행 연출**: 하루가 지날 때마다 그 줄에 동그라미·가위표가 그려지고 여백에 한 줄 낙서가 생긴다("졸았다"). 책상 위 물건이 변한다(랜턴 기름, 컵의 물, 창밖 날씨)
- **결산**: 일기 쪽. 왼쪽에 주인공이 쓴 일기, 오른쪽에 선생님의 생활기록부 평. 수치는 성적표 모양
- **장점**: **세계관과 가장 잘 붙는다**("마지막 학기", 학교, 기록). 이미 있는 일기·선생님 코멘트 시스템이 주인공이 된다. 수치와 이야기를 한 쪽에 나란히 두기 쉽다. 그림은 종이 질감과 소품 정도
- **단점**: 손 글씨·종이 표현에 읽기 쉬움이 밀릴 수 있다(접근성 옵션으로 또렷한 글꼴 필요). 거점과 인물이 직접 보이지 않는다. 정보가 많은 쪽(능력치·숙련도)을 종이에 예쁘게 담기가 까다롭다
- **작업량**: UI 큼(질감·넘김 연출), 아트 중간

### E안. 섞어 쓰기: 단면도 + 수첩 (추천)

**한 줄**: 평소에는 B안의 살아 있는 거점을 보고, 계획과 결산은 D안의 수첩을 펼친다.

| 겹 | 내용 | 어디서 가져오나 |
|---|---|---|
| 0겹 장면 | 건물 단면, 인물이 움직임, 시간·날씨 | B안 |
| 1겹 상시 | 날짜, 식량·물, 경고 1줄, 수첩 단추 | 공통 |
| 2겹 패널 | 방·사람을 눌렀을 때 옆 패널 | B안 |
| 3겹 집중 | **수첩**: 주간 계획, 나(상태), 학교(시설), 사람, 일기 | D안 |
| 4겹 이야기 | 대사·선택지 | 지금 것 |

- **한 주의 흐름**
  1. **월요일 아침**: 단면도가 밝아지고 선생님 한마디. 수첩이 저절로 펼쳐진다
  2. **편성**: 수첩의 주간 쪽에 스티커를 붙인다. 오른쪽 쪽에 예상(물 이틀 치 부족 등)이 포스트잇으로 붙는다. 방을 눌러 고르는 길과 수첩에서 고르는 길 둘 다 된다
  3. **실행**: 수첩이 접히고 단면도에서 한 주가 흐른다. 화면 아래에 요일 띠가 지나간다. 사건이 생기면 멈추고 대사
  4. **결산**: 일요일 밤, 거처에 불 하나. 수첩의 일기 쪽이 펼쳐진다
- **장점**: "구경하는 화면"과 "고민하는 화면"이 갈려 세 박자가 뚜렷하다. 픽셀 아트 재사용 + 이미 있는 일기 시스템 활용. 숫자를 깊게 보고 싶으면 수첩의 "나" 쪽에서 C안식 표를 쓸 수 있다
- **단점**: 두 가지를 다 만들어야 해 작업량이 가장 크다. 픽셀(장면)과 종이(수첩) 두 그림체를 한 화면에서 어울리게 해야 한다
- **작업량**: UI 매우 큼, 아트 중간

## 5. 추천

**E안을 목표로 두고, B안부터 단계로 간다.**

1. **1단계 (겹 나누기)**: 지금 화면을 다섯 겹으로 쪼갠다. 상시 표시를 얇게 줄이고 상태·숙련도를 펼침 패널로 뺀다. 어느 안을 고르든 필요한 기초 공사다
2. **2단계 (단면도)**: 0겹을 건물 단면으로 바꾸고 방·사람을 누를 수 있게 한다. 실행 중 인물이 움직인다
3. **3단계 (수첩)**: 편성과 결산을 수첩으로 옮긴다
4. **4단계 (다듬기)**: 넘김·전환 연출, 소리, 접근성 글꼴

1~2단계만으로도 B안으로 완결되므로, 3단계는 그때 가서 해도 된다.

이유:
- 탐험 쪽 그림(방 18종, 가구 300여 종, 인물 동작, 조명)을 이미 만들어 두었다. 허브에서 다시 쓰면 그림 비용 없이 화면이 살아난다
- 탐험과 거점이 같은 그림체로 이어지면 "저 학교에서 살고, 저 문으로 나간다"가 한 세계로 읽힌다
- A안은 주인공 입상과 SD 동작을 새로 많이 그려야 해 지금 단계에서 가장 비싸다
- C안은 빠르지만 말씀하신 "실제 게임으로서 부족함"을 풀지 못한다. 다만 C안의 카드 구성은 수첩의 "나"·"학교" 쪽 내용으로 흡수한다

## 6. 스케줄 편성과 연출 (공통 상세)

**편성**
- 행동을 놓는 길 두 가지: 칸을 먼저 누르고 행동 고르기 / 행동을 먼저 들고 칸에 놓기(끌어 놓기)
- 하루 단위 묶음: "평일 낮은 수업" 같은 붓질(여러 칸 한 번에)
- 프리셋·지난주 복사는 수첩의 "지난 쪽 베끼기"로
- 놓는 즉시 예상 표시: 식량·물 며칠 치, 피로·스트레스 끝값, 수면 부채, 성공 확률
- 잠긴 칸(갇힘, 강제 휴식, 부상)은 이유가 적힌 채로 미리 채워져 있다
- 선생님 조언은 계획이 바뀔 때 한 줄씩 바뀐다("밤을 세 번 새우는구나.")

**실행**
- 요일 띠가 흐르고, 슬롯마다 2~3초의 작은 장면(빠르게 ×2·×4, 건너뛰기)
- 낮·밤 전환: 창 밖 색, 조명, 소리
- 결과는 장면 위에 작게 뜬다(성공·대성공·실패 + 오른 수치). 카드로 멈추지 않는다
- 멈추는 것은 이야기 사건, 선택지, 탐험 출발뿐
- 탐험 슬롯: 주인공이 교문으로 걸어 나가고 화면이 탐험으로 넘어간다. 돌아오면 가방을 내려놓는 장면

**결산**
- 왼쪽: 일기 한 단락(이번 주에 일어난 일을 주인공의 말로)
- 오른쪽: 수치 변화(능력치 막대의 늘어난 부분만 색으로, 자원 증감, 숙련도)
- 아래: 선생님의 한 줄 평, 다음 주 예고(날씨, 다가오는 날)
