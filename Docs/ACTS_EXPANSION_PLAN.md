# 2~4막 보강 계획: 세력·관계 서사·계절·학사력·소풍·수학여행

사용자 요청 (2026-11-20): 1막 이외 막의 대사·이벤트 보강. NPC와의 관계 서사, 적대·중립·우호 외부 세력과의 관계를 내러티브 있게. 계절 고유 이벤트, 학사 일정, 프린세스 메이커식 계절 소풍·수학여행.

- 세력 이름 (사용자 지정): 약탈 패거리 **사거리 파**, 라디오 DJ 쪽 **UBC**, 마트 무리 **더불어 마트**. 설계 승인.

| X-b | 소풍 | **계절 일정 카드**: 계절마다 정해진 몇 주만 열리는 '소풍' 행동, 행선지 선택 |

## 1. 세력 시스템

### 세력 셋 (기존 인물·사건을 묶는다)
| 세력 | 처음 태도 | 누구 | 기존 연결 |
|---|---|---|---|
| **사거리 파** (적대) | 적대 −40 | 학교 앞 큰 사거리를 근거지로 삼은 약탈 패거리. 두목 '강철'(가명) | 약탈자 위기(`EVT_RND_A2_LOOTERS`의 담장 표시), 낮 탐험 적대적 생존자, 3·4막 낮 침입 깡패, 4막 마지막 습격 |
| **더불어 마트** (중립) | 중립 0 | 새벽마트·물류창고의 어른 열한 명. 정 반장 | `EVT_A3_MART_GROUP`(거래·동맹·거절), 최하린(가해 학생)이 이 무리에 있다 |
| **UBC** (우호) | 우호 +20 | 라디오 DJ가 방송하는 곳(옛 방송국 건물의 생존자들). 체육공원 대피소 생존자들이 옮겨 간 곳 | DJ 방송·사연(`EVT_A3_DJ_SHOW`·`REQUEST`), 도현 어머니 소식(`EVT_DH_07_SHELTER`), 52주 구조 경로 |

### 평판과 단계
- 평판 −100~+100. 단계: **적대**(−60↓) · **경계**(−20↓) · **중립** · **호의**(+30↑) · **동맹**(+60↑). 단계가 바뀔 때마다 그 세력의 장면이 한 번 뜬다(예: 사거리 파 '경계' → 두목의 전갈).
- 처음에는 모르는 세력(허브에 안 보임). 첫 만남 이벤트가 `알게 됨`으로 바꾼다.
- 평판을 바꾸는 것: 이벤트 선택지(`GameEffect.Factions`), 탐험 조우 선택지(조우에도 세력 효과 추가), 거래, 시간(대피소는 연락이 끊기면 조금씩 식는다).

### 영향 표 (데이터: `factions.json`의 단계별 효과)
| 세력 | 낮을 때 | 높을 때 |
|---|---|---|
| 사거리 파 | 밤 습격 강도 +, 낮 침입·낮 탐험 적대적 생존자 확률 × 1.3 | '휴전'(통행세를 주기로 함): 침입·적대적 생존자 × 0.6, 대신 매주 식량 일부를 바침 |
| 더불어 마트 | 마트 탐험에서 적대 조우, 거래 거부 | 거래 가능(호의부터), 동맹이면 좋은 교환비 + 수학여행 때 트럭을 빌려 줌 |
| UBC | 방송 정보가 줄어듦 | 호의: 무전으로 위험 예보(밤 탐험 쓰러짐 ↓), 동맹: 약품 공수 한 번, 구조 경로 장면이 달라짐(엔딩 후일담) |

### 거래
- 허브 세력 칸 → 세력 카드 → **거래** (계획 단계에서 바로, 세력마다 주 1회). 교환표는 데이터(예: 더불어 마트 의약품 1 ↔ 식량 4, 호의/동맹에서 비율 개선). 대피소는 무전 거래라 '다음 주 도착'.
- 거래 기록·평판 변화는 세력 카드의 '최근 일' 3줄로 보인다(서사 로그).

### 화면
- 허브 상태 칸 '거점' 아래에 **세력** 칸: 아는 세력마다 이름 · 단계 · 평판 막대 · 한 줄 근황("정 반장이 무전을 기다린다").
- 세력 카드(오버레이): 소개, 지금 단계의 영향(위 표의 문장), 최근 일 3줄, 거래 버튼.

### 코드 (구조 변경)
- `FactionDef`(`Content/Base/factions.json`), `FactionState`(`GameState.Factions`, 세이브 v6 마이그레이션), `GameEffect.Factions`, `EncounterChoiceDef.Factions`, `ValueKind.FactionStanding`, `FactionRules`(단계·영향·거래·주간 변화), `RaidRules`·`IntrusionRules`·`HostileRules`에 세력 배율, 허브 `FactionSectionView`·`FactionCardView`·거래 오버레이, 봇 거래 규칙.

## 2. 계절 소풍 (일정 카드)
| 계절 | 열리는 주 | 행선지 (조건) |
|---|---|---|
| 봄 | 4~7주 (벚꽃·현장체험학습) | 운동장 벚나무 아래 / 옥상 / 근처 하천 산책로(목발) |
| 여름 | 18~22주 (방학) | 수영장 물놀이(빈 학교 수영장, 빗물) / 옥상 밤하늘 피크닉 / 계곡 같은 뒷산 개울(목발) |
| 가을 | 34~37주 (단풍) | 뒷산 단풍길 / 운동장 낙엽 / 더불어 마트와 함께하는 바비큐(호의 이상) |
| 겨울 | 44~48주 (눈) | 운동장 눈사람 / 옥상 첫 일출 / 얼어붙은 하천 썰매(목발) |
- 계절마다 한 번, 낮 칸 하나, 도시락(식량 1·물 1). 행선지마다 위험 판정·스트레스 회복·선생님·동료 호감·작은 발견이 다르다. 동료가 있으면 같이 가는 대사.

## 3. 수학여행 (가을 1박 2일)
- 30~33주(원래 수학여행 철), 한 번. 낮 칸을 고르면 **그날 밤 칸도 '여행 중'으로 잠긴다**(새 필드 `ActionDef.LocksNextSlots`).
- 거점을 비운 밤: 습격 판정에서 방어 절반·경비 없음, 동료가 남으면 그 동료가 지킨다.
- 행선지: 걸어서 뒷산 전망대(바다가 보이는 곳) / 더불어 마트 동맹이면 트럭으로 바닷가. 목발이 없으면 선생님은 거점에 남고 장면이 달라진다.
- 장면 3개(출발 → 밤 모닥불 → 귀환), 기념품(조개껍데기 등 일기·엔딩 후일담 연결).

## 4. 계절·학사력 (데이터만)
- 봄: 벚꽃(4주), 1학년 수련회 예정일 회상(6주), 현충일(13주).
- 여름: 장마 시작(15~16주, 날씨 연동), 초복(18주), 광복절(23주).
- 가을: **한글날**(30주, 국어 선생님의 날), 수학여행 예정일 회상(31주), 첫서리.
- 겨울: 첫눈(무작위 겨울 첫 번째), 동지 팥죽(41주), 설날(47주), 정월대보름(49주).

## 5. 막별 관계 서사
- **2막**: 간호사 +3(병원에서의 마지막 날, 약 배분 원칙, 선생님 다리 다시 보기), 방관자 +3, 도현·간호사 사이 장면, 동료 사이 갈등(식량 분배), 사거리 파 첫 흔적 → '알게 됨', UBC 첫 방송.
- **3막**: 더불어 마트 아크(첫 만남 → 거래 → 갈등 → 떠남, 최하린 갈래와 연결), 사거리 파 확대(전갈·통행세·습격), 대피소 사연·무전 교신, 방랑자 +2, 최하린 합류 뒤 +3.
- **4막**: 사거리 파 결말(마지막 습격 `EVT_A4_FINALE_RAID`와 연결: 휴전·격퇴·도망), 대피소 → 구조대 음성으로 이어지는 경로, 더불어 마트 소식, 동료마다 졸업식·작별 한 장면.

## 진행 순서
1. 공통 틀: 세력 시스템(코드·UI·세이브·봇), 소풍·수학여행 행동, 테스트.
2. 2막 장면 → 봇·헤드리스 점검 → 커밋.
3. 3막 → 점검 → 커밋.
4. 4막 → 점검 → 커밋. 엔딩 분포 다시 확인.
