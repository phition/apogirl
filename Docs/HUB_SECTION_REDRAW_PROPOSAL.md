# 학교 단면도 다시 그리기 — 설계 기획서 (초안)

- 2026-11-26, 브랜치 `claude/game-ui-design-implementation-fe47d4` (fablable). 상태: **A안 구현 완료 (2026-11-26, 사용자 결정: A안 + 필요한 도트는 PixelLab)** — 결과는 9절.
- 대상: 허브 0겹의 학교 단면도 (`HubSectionView`, `Resources/Art/hub_section.json`).
- 전제: 1차는 **이미 있는 그림만** 쓴다(탐험 도트 `Resources/Art/ExplorationPixel/`, 하늘 `UI/HubSky/`). 새 그림이 꼭 필요한 곳은 5절에 따로 적는다.

## 1. 지금 단면도

| 항목 | 지금 |
|---|---|
| 크기 | 폭 780 × (3층 × 120 + 옥상 96), 화면에서는 2배 = 1560 × 912px |
| 구조 | 층마다 방 4~5개가 벽 하나를 사이에 두고 한 줄로 붙어 있다. 계단실(폭 48)은 오른쪽 끝 하나 |
| 방 | 14개 — 1층 현관·본관 창고·급식실·보건실·교무실 / 2층 교실·과학실·도서관·가사실 / 3층 방송실·음악실·컴퓨터실·체육관 / 옥상 |
| 벽 그림 | 방마다 뒷벽 타일 한 장(`wall_*` 128×144)을 가로로 반복, 바닥 띠(`wall_floor_*`), 위에 슬래브 5 |
| 방 사이 | 회색 벽 8 + 문선. 걷는 사람이 가까이 오면 문이 열린다 |
| 바깥 | 양끝 벽돌 벽 10, 지면 10. 건물 왼쪽은 하늘·마을 그림과 주인공 입상 |

### 고칠 점

1. **방이 상자 줄이다.** 폭만 다른 같은 모양의 칸이 나란해서, 방 이름표를 가리면 어디가 어딘지 실루엣으로 구분되지 않는다.
2. **계단이 한쪽 끝이라 동선이 길다.** 현관(왼쪽 끝)에서 3층 방송실(왼쪽 끝)까지 가려면 건물을 두 번 가로지른다. 실행 중 걷는 시간이 대부분 이 왕복이다.
3. **뒷벽에 깊이가 없다.** 창·몰딩·그늘이 없고 타일 경계가 방 폭과 맞지 않아 벽지가 잘려 보인다. 탐험 화면의 방에는 있는 창(`prop_window`)과 측벽 그림(`wall_side_*`)을 여기서는 쓰지 않는다.
4. **탐험에서 걸어 본 학교와 닮지 않았다.** 탐험의 교실동은 긴 복도에 교실이 줄지어 있고 방마다 창이 있는데, 단면도는 다른 건물처럼 보인다.
5. **건물이 변하지 않는다.** 방이 열리면 어둠이 걷힐 뿐이다. 버려진 곳을 치우고 고쳐 가는 과정이 벽과 바닥에는 드러나지 않는다.
6. **학교 바깥이 없다.** 동료가 탐험을 나가면 현관에서 그냥 사라진다. 교문·마당이 없어 "밖"이 느껴지지 않는다.

## 2. 무엇을 그리든 지킬 것

- 방 ID 14개, 방별 행동·시설·역할 방 묶음·지은 구조물(`Built`·`BuiltProps`)·CD 벽 전시·방 패널·빛 테두리는 그대로 동작해야 한다.
- 걷기 규칙(같은 층은 가로로, 다른 층은 계단으로), 문 열림, 외출·귀환(현관), 고양이, 낮·밤·정전·날씨 표현을 유지한다.
- 배치는 계속 데이터(`hub_section.json`)로 둔다. 좌표를 코드에 박지 않는다.
- 화면 자리: 입상은 왼쪽, 건물은 오른쪽 아래. 상단 띠·도크·선생님 포스트잇과 겹치는 범위는 지금과 같게.
- 게임 규칙·세이브에는 영향이 없다(보이는 것만 바뀐다).

## 3. 구조 — 세 가지 안

### A안. 중앙 계단형 (추천)

계단실을 건물 가운데로 옮겨 좌우 날개로 나눈다. 폭 780과 층 높이는 그대로다.

```
            ┌──────── 옥상 ───────[계단탑]────── 옥상 ────────┐
 3층  │ 방송실 166 │ 음악실 200 │계단│ 컴퓨터실 150 │ 체육관 216 │
 2층  │ 교실 200   │ 과학실 166 │ 48 │ 도서관 180   │ 가사실 186 │
 1층  │현관 96│창고 130│급식실 140│계단│ 보건실 170 │ 교무실 196 │
 ─교문·마당─┴──────────────────────────────────────────────────┴─
```

- 좌우 날개 폭은 각각 366으로 같다. 방 순서는 지금과 같아서 방마다 X와 폭만 바뀐다.
- 어느 방에서든 계단까지 최대 366이라, 층을 오가는 걷기가 지금의 절반쯤으로 줄어든다.
- 옥상 가운데에 계단탑이 서서 건물 윤곽에 중심이 생긴다. 물탱크·빗물받이는 왼쪽, 텃밭·안테나는 오른쪽.
- 코드: `StairsX` 하나로 끝나지 않는다. 지금 벽 짓기(`BuildWalls`)는 계단실이 맨 오른쪽이라고 보고 있어서, 계단실 양쪽에 문을 내도록 고쳐야 한다. 걷기 경로는 "계단 X로 간다"라 그대로 쓸 수 있을 것으로 보이지만 구현 전에 확인한다.

### B안. 본관 + 별관

건물을 두 채로 나눈다. 왼쪽 본관 3층(교실·특수실), 오른쪽 별관(1층 급식실, 그 위 2층 높이 체육관), 사이에 연결 통로.

- 체육관이 천장 높은 큰 방이 되어 실루엣이 확 달라진다. "본관 창고"라는 지금 이름과도 맞는다.
- 대가: 방 높이가 층 단위가 아닌 방(2층 높이), 건물마다 계단, 건물 사이 걷기 경로가 새로 필요하다. 지은 구조물·역할 자리 좌표도 전부 다시 잡아야 한다. A안보다 작업이 2~3배다.

### C안. 구조 유지 + 벽만 다시

방 배치와 계단은 그대로 두고 4절의 벽 그림만 적용한다. 가장 싸지만 고칠 점 1·2·4는 남는다.

## 4. 벽 그림 — 겹을 나눠 다시 쌓기

구조 안과 상관없이 적용한다. 방 하나를 아래 겹 순서로 그린다(뒤 → 앞).

| 겹 | 그리는 것 | 쓰는 그림 |
|---|---|---|
| 1 뒷벽 | 방별 벽 타일. 타일 시작점을 방 가운데에 맞춰 양끝이 대칭으로 잘리게 | `wall_classroom`·`wall_science`·`wall_nurse` 등 지금 것 |
| 2 창 | 방 폭에 따라 1~2개, 탐험 방 템플릿의 창 자리와 같은 비율로. 유리 색은 하늘 시각을 따라 낮 하늘색·황혼 주황·밤 남색 | `prop_window` (102×52) |
| 3 벽 장식 | 방 정체성 한 점씩: 칠판, 시력검사표, 세계지도, 작곡가 초상, ON AIR 등 | 이번에 넣은 `decor_*` + 탐험 뒷벽 장식 `wall_onair`·`wall_redcross`·`wall_periodic`·`wall_whiteboard` |
| 4 가구 | 바닥에 선 집기 (지금 Props) | `prop_*`·`decor_*` |
| 5 방치 흔적 | **잠긴 방에만**: 넘어진 의자, 잔해, 거미줄, 죽은 화분. 방을 열면 사라진다 | `decor_chair_fallen`·`decor_debris`·`decor_cobweb`·`decor_plant_dead` |
| 6 지은 것 | 설비·제작물 (지금 BuiltProps) | 지금 것 |
| 7 그늘·불빛 | 천장 아래 그늘 띠, 밤 전등 불빛, 정전이면 촛불·랜턴 한 점 | 코드 사각형 + `decor_candle`·`decor_lantern` |

건물 전체:

- **외벽**: 벽돌 타일 위에 층 사이 슬래브 띠를 건물 폭 전체로 이어 그려 층이 읽히게 한다. 외벽에 실외기·배관을 붙인다(`decor_acunits`·`decor_pipes`).
- **계단실**: 층마다 같은 계단 그림(`hub_stair_up`)에 비상구 표지(`decor_exitsign`)·소화기를 더해 방과 구분한다.
- **옥상**: 지금의 철조망·난간 유지. A안이면 계단탑(`hub_stair_roof`)이 가운데.
- **바깥(왼쪽)**: 지면을 건물 밖으로 이어 낮은 담과 교문을 둔다(`out_wall_street_low`). 외출하는 동료는 현관을 나와 교문 쪽으로 걸어 화면 밖으로 사라지고, 돌아올 때 그쪽에서 들어온다. 방어 단계가 오르면 교문 앞에 모래주머니(`decor_sandbags`).

### 건물이 변하는 모습 (고칠 점 5)

| 계기 | 보이는 변화 |
|---|---|
| 방을 처음 연다 | 방치 흔적 겹이 사라지고 어둠이 걷힌다 |
| 거처를 교실로 옮긴다 | 침낭·랜턴 (지금도 있음) |
| 전력 복구 | 밤에 창 유리가 따뜻한 색으로 켜진다(켜진 방만) |
| 방어 강화 | 현관 바리케이드(지금도 있음) + 1층 창에 판자 |
| 계절 재해 | 장마에는 1층 바닥에 양동이(`decor_bucket`), 폭설에는 옥상·교문에 눈 띠 |

## 5. 있는 그림으로 안 되는 것

- 창 **판자**, 옥상 **눈 띠**, **교문** 문짝: 없다. 1차에서는 `decor_barricade`·흰 사각형·담 그림으로 대신하고, 마음에 안 들면 Aseprite로 3장 그린다.
- 체육관용 **높은 벽**(B안): 벽 타일이 144 높이라 2층 높이(240)를 못 채운다. B안을 고르면 새 타일이 필요하다.
- 방별 **측벽**(`wall_side_*` 72×133): 방 폭을 양쪽 72씩 먹어 지금 방 폭(130~216)에는 너무 크다. 쓰지 않는 쪽을 추천한다.

## 9. 구현 결과 (A안, 2026-11-26)

- **구조**: 계단실을 가운데(`StairsX` 366)로, 좌우 날개 366씩. 방 14개의 X·폭·소품을 다시 잡았다(`hub_section.json`, 다시 쓰는 도구 `code_temp/apogirl/tools/fablable_shots/section_layout_a.py`). 벽 짓기는 계단실 양쪽과 방 사이 어디에나 문을 낸다(`BuildWalls`의 `Edge`). 옥상 가운데에 계단탑.
- **벽 겹**: 뒷벽 타일 가운데 맞춤 → 창(`RoomDef.Windows`, 그림 `WindowKey`) → 가구 → 잠긴 방 방치 흔적(`LockedProps`) → 지은 것 → 천장 그늘(`.hub-ceil-shade`). 잠긴 방 어둠은 0.92(선형 색공간이라 0.72로는 거의 안 어두웠다) — 흔적이 실루엣으로 비친다.
- **지은 것이 방 안에 놓인다** (`BuiltPropDef`에 조건 `MinTraps`·`MinCompanions`·`Npc`·`Disaster` 추가): 현관 바리케이드 2단계·깡통 경보, 창고 작업대 Ⅰ·Ⅱ, 과학실 모래 여과기 → 자동 정수기, 가사실 끓임 정수대, 방송실 자전거 발전기, 보건실 응급 카트, 도서관 공부 자리. 동료 1명부터 교무실 당번표, 2명부터 교실 침낭 줄, 3명부터 급식실 긴 식탁, 고양이가 오면 교실 잠자리. 방어를 강화하면(`PlankFlag` = `ENTRANCE_REINFORCED`) 1층 창에 판자, 장마에는 1층 양동이, 폭설에는 옥상 난간·담 위 눈 띠(`SnowCap`).
- **바깥** (`Outside`): 실내 바닥 높이에 맞춘 마당, 낮은 담, 교문. 방어 20부터 모래주머니, 함정을 깔면 함정, 허수아비. 외출하는 동료는 현관을 나와 `ExitX`까지 걸어가 사라지고 그쪽에서 돌아온다.
- **PixelLab 그림 21장** (`ExplorationPixel/hub_*.png`, 생성 `code_temp/apogirl/tools/gen_hub_a.py`·넣기 `install_hub_a.py`, 후보 `scratch/pl/hub_a/`): 계단탑·교문·창 판자·눈 띠, 지은 설비 13(`hub_built_*`), 동료용 4(침낭 줄·고양이 잠자리·긴 식탁·당번표). 사용액 약 $1.82(남은 잔액 $2.67, 구독 생성 횟수는 소진 — 애니메이션은 못 만든다).
- **아직 안 쓴 그림**: `hub_built_cooking`(조리대 — 가사실·급식실에 자리가 없다).
- **확인**: 배치 모드 Unity 화면 그림 — 초반(잠긴 방), 20주차 전부 해금 + 지은 것 + 동료 3·고양이, 폭설 주. EditMode 515 통과. **못 본 것**: 밤·정전, 장마 양동이, 외출하는 동료가 교문으로 걷는 모습(실행 중에만 보인다), 실제 플레이.
- **기획과 달라진 점**: 창은 모든 방이 아니라 벽이 비는 방 5곳(급식실·교무실·가사실·음악실·체육관)에만 — 칠판·게시판·지도와 겹친다. 창 유리 색이 시각을 따르는 것(R3)은 따로 만들지 않았다(밤에는 방 어둠 막이 창까지 덮는다).
