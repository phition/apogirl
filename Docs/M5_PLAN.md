# M5 엔딩 시스템 계획

목표: **태그 누적 → 엔딩 판정 → 후일담 연출 → 1년의 기록 → 갤러리**를 한 번에 확인할 수 있게 한다. 배드 엔딩도 포함한다.
2~4막 콘텐츠는 M6에서 만든다. 그 플래그가 필요한 엔딩은 조건만 걸어 두고, 디버그로 확인한다.

## 결정 사항 (2026-11-19, 추천안 채택)

| # | 항목 | 결정 |
|---|---|---|
| M5-a | 엔딩 범위 | 문서 8.2의 엔딩 전부를 데이터로 정의하고 후일담은 짧게(3컷). 2~4막 플래그가 필요한 엔딩(완치·구조 거부·진실·직면)은 조건만 걸어 두고 M6에서 다듬는다 |
| M5-b | 배드 엔딩 원인 | 4종: 탐험 중 사망, 습격 사망, 정신 붕괴(스트레스 한계 지속), 굶주림·탈수. 그 밖의 체력 0은 공통 배드 엔딩. 감염 배드 엔딩은 감염 시스템과 함께 M6 |
| M5-c | 배드 엔딩의 친구 암시 | 일부 배드 엔딩 후일담에 "친구가 뒤늦게 학교를 찾아오는" 한 컷 |
| M5-d | 후일담 연출 | 글과 엔딩별 배경색. 일러스트 자리는 M6 아트 단계 |
| M5-e | 회차 요소 | 갤러리까지. 시작 보너스·"창고 안의 7일" 프롤로그는 M6 |
| M5-f | '나의 1년' 공유 카드 | 게임 안 "1년의 기록" 화면까지. 이미지 저장·공유는 M8 |

## 설계

- **EndingDef** (`Content/Story/endings.json`)
  - 종류: Bad, Normal, Balanced, Specialized, Relationship, Narrative, Hidden
  - 우선순위와 조건: 기존 `ConditionDef` 재사용
  - 점수식: `(ValueKind, Key, Weight)` 목록
  - 후일담 컷: UI 문자열 키
  - 배경색
  - 배드 엔딩은 종료 원인(`EndCauses`)으로 고른다.
- **판정 (`EndingResolver`, 부록 B)**
  - 게임오버면 원인이 맞는 배드 엔딩 중에서 고른다.
  - 구조면 배드를 뺀 후보 중 조건을 만족한 것을 우선순위, 그다음 점수 순으로 고른다.
  - 아무것도 맞지 않으면 기본 엔딩.
- **공통 레이어 (8.3)**: 대사 줄(`LineDef`) 종류를 추가한다. 구조 엔딩에만 붙는다.
  - `EndingTeacher`, `EndingFriend`, `EndingCure`, `EndingTendency`: 각각 가장 높은 우선순위 하나를 후일담 뒤에 덧붙인다.
  - `EndingMoment`: 조건을 만족하는 줄 전부가 "1년의 기록"의 주요 장면이 된다.
- **파생 수치 (`ValueKind`)**: 조건·점수에서 쓴다.
  - `NightRatio`: 밤 탐험 비율 0~100
  - `DiaryCount`, `Companions`(합류한 NPC 수)
  - `StatSpread`(능력치 최대−최소), `StatMin`
  - `BreakdownWeeks`
- **배드 엔딩 원인 기록**
  - 체력 0이 되면 상황으로 원인을 정한다: 탐험 중, 습격 밤, 굶주림·탈수, 그 밖.
  - 정신 붕괴: 주간 정산 때 스트레스가 `CollapseStress` 이상인 주가 `CollapseWeeks` 연속이면 종료된다. 1주째부터 일기·선생님 한마디로 경고한다.
- **주간 기록**: `GameState.History`에 매주 능력치·체력·스트레스를 남긴다(세이브 v4). 엔딩 화면 그래프에 쓴다.
- **갤러리**: 세이브와 별개인 `persistentDataPath/Gallery.json`. 엔딩 ID, 처음 본 주차, 본 횟수를 기록한다.
- **화면**
  - 엔딩: 제목 → 후일담 컷(클릭으로 넘김) → 1년의 기록(능력치 그래프, 탐험 성향, 동료, 주요 장면, 일기 모음) → 타이틀로.
  - 타이틀에 "엔딩 갤러리" 메뉴를 둔다.
- **디버그 (F1)**: "52주차로", "지금 상태로 구조 엔딩", "배드 엔딩(원인 선택)".
