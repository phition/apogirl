관련 절: 10장 UI(접근성·분위기 토글), 11장 기술(로컬라이제이션·성능), 13장 4·5(수위 옵션·트리거 경고), 6.3.2(인벤토리 열람 시 시간 정지 `[결정 필요]`).

## 단계 (제안)

| 단계 | 내용 | 끝났다고 보는 기준 |
|---|---|---|
| **M8-1 릴리즈 안전장치** | 디버그 패널·디버그 키를 개발 빌드에서만 켜기, 전역 오류 기록(파일), 세이브 백업 1벌과 임시 파일·손상 복구, 손상 시 안내 문구, 버전 번호 표시(타이틀 구석) | 릴리즈 빌드에서 F1~F8이 안 먹음. 세이브를 일부러 망가뜨려도 백업으로 이어하기. 테스트 추가 |
| **M8-2 설정 화면** | 타이틀·허브·탐험에서 여는 옵션 화면. 음량(전체·배경·효과·목소리), 창 모드·해상도, 글자 크기, 대사 속도, 설정 파일 저장 | 값이 저장되고 다시 켜도 유지. 1280×720~2560×1440에서 화면이 깨지지 않음 |
| **M8-3 접근성** | 색약 대응 색(상태 표시를 색만으로 구분하지 않기), 깜빡임·화면 흔들림 줄이기, 인벤토리 열 때 시간 정지 옵션, 표현 수위 옵션, 첫 실행 주제 안내 화면 | 옵션마다 화면으로 확인. 주제 안내는 첫 실행에 한 번, 설정에서 다시 볼 수 있음 |
| **M8-4 입력** | 조작을 InputAction으로 옮기고 게임패드 지원, 화면 안내를 지금 쓰는 장치에 맞춰 표시, (선택) 키 바꾸기 | 패드만으로 타이틀 → 새 게임 → 한 주 → 탐험 한 판 → 저장까지 |
| **M8-5 번역 구조** | 로케일 고정값 걷어내기, 언어 바꾸면 화면이 바로 바뀌기, 글꼴을 빌드에 포함, 조사(은/는) 처리와 기본 이름을 언어별로, 빠진 키 점검 테스트. 실제 번역은 "결정 필요" 2에 따름 | 가짜 언어(모든 문자열에 표시를 붙인 것)로 돌려 빠진 문자열 0 |
| **M8-6 성능** | 프로파일링 먼저(4층 교실동 밤, 좀비 최다) → 문제로 확인된 것만 고침(풀링, 틱 분산, 문자열 할당). 목표 사양 정하기 | 목표 사양에서 60fps, 탐험 중 멈칫거림(GC) 없음. 측정값을 문서에 기록 |
| **M8-7 스팀 빌드** | Steamworks 연동(초기화, 오버레이, 클라우드 세이브, 업적), 빌드 번호·업로드 절차 문서 | 스팀 클라이언트로 실행해 오버레이·클라우드 확인. **스팀 계정·앱 ID가 있어야 함** |
| **M8-8 마무리** | 전체 통독 플레이(52주), 남은 M6-5 그림 확인(지역 5곳 실내 등), 크레딧 화면, 알려진 문제 목록 | 처음부터 엔딩까지 막힘 없이 한 번 |

순서 이유: M8-1은 지금 테스트 빌드를 남에게 줄 때도 필요한 것이라 먼저. 설정 화면(M8-2)이 있어야 접근성(M8-3)·입력(M8-4)·언어(M8-5) 옵션을 넣을 자리가 생긴다. 스팀(M8-7)은 외부 계정이 필요해 뒤에 둔다.

## 결정 필요

1. **인벤토리를 열 때 시간 정지** (마스터 프롬프트 6.3.2 `[결정 필요]`)
   - A. 옵션으로 제공, 기본은 꺼짐(시간이 흐름) — **추천**. 문서의 "긴장감 우선"을 지키면서 접근성 옵션을 준다.
   - B. 옵션으로 제공, 기본은 켜짐
   - C. 난이도에 묶기 (쉬움에서만 정지)
2. **언어 범위**
   - A. 한국어만 출시, 번역 구조만 갖춰 둠 — **추천**. 대사 약 2,100줄에 조사·말투가 얽혀 있어 번역 품질 확보가 큰 일이다.
   - B. 영어 추가 (기계 번역 초안 + 직접 검수)
   - C. 영어·일본어 추가
3. **게임패드 범위**
   - A. 패드 지원 + 안내 표시 전환, 키 바꾸기는 안 함 — **추천**
   - B. 패드 지원 + 키보드·패드 키 바꾸기까지
   - C. 키보드만 (패드는 출시 뒤)
4. **표현 수위 옵션의 범위** (13장 4)
   - A. 2단계: 기본 / 완화(피격 붉은 효과 끄기, 민감 장면 앞에 건너뛰기 안내) — **추천**
   - B. 장면 종류별로 세세하게 고르기
5. **목표 사양**: 예) 내장 그래픽 노트북에서 1080p 60fps. 기준으로 삼을 기기가 있으면 알려 주면 된다.
6. **스팀**: 앱 ID와 Steamworks 계정이 있는가. 없으면 M8-7은 "연동 코드와 절차 문서까지"만 하고 실제 확인은 계정이 생긴 뒤로 미룬다. 업적 목록(엔딩 22개 기준?)도 정해야 한다.
7. **M7에 남은 것을 어떻게 둘지**: 엔딩 기준 재조정·부상 밸런스 결정이 `M7_PLAN.md`에 남은 것으로 적혀 있다. 최근 전리품(가방·방망이)과 좀비 행동도 바꿨다. M8-8 전에 봇 시뮬레이션을 한 번 다시 돌려 확인하는 것을 권한다.
