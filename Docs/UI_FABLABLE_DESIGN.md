# UI 설계 보고서 — ver-fablable0.1 「교실의 물건들」

- 브랜치 `claude/game-ui-design-implementation-fe47d4`, 태그 `ver-fablable0.1`. 2026-11-26.
- 범위: 화면 전체의 **겉모습·재질·글꼴·상태 표현**. 게임 규칙·화면 흐름·문구·저장 형식은 건드리지 않는다.
- 새 그림은 만들지 않는다. 이미 있는 종이 묶음(`Resources/Art/UI/Paper/`)·아이콘·글꼴 두 개만 쓴다.

## 1. 한 줄 개념

이 게임의 화면은 **교실에 남아 있는 물건**으로 만든다. 늘 떠 있는 틀은 **칠판**, 읽는 정보는 **종이**, 상태와 판정은 **분필·빨간 펜·도장·포스트잇**이다.
지금 화면은 서랍(생활기록부·거점·인물·결산)만 종이·손글씨이고 나머지는 회색 상자라, 한 게임 안에 두 가지 말투가 섞여 있다. 이번 판은 그 둘을 하나로 묶는다.

## 2. 재질 세 가지

| 재질 | 쓰는 곳 | 색·글꼴 |
|---|---|---|
| **칠판** (늘 있는 틀) | 상단 띠, 아래 도크, 계획 보드, 서랍·전용 화면 바탕, 탐험 HUD | 짙은 녹색 `#1c2824`~`#2c3d37`, 분필 흰색 `#eeece1`, 나무 테 `#9b7448`. 제목은 학교안심 엣지 |
| **종이** (읽는 정보) | 결과 카드·하루 보고, 선생님 한마디(포스트잇), 방 패널, CD 상세, 말풍선, 타이틀 차림표 | 상아색 `#f3ead6`, 잉크 `#2a2620`. 카드 위에 마스킹 테이프 |
| **표시** (상태·판정) | 고른 것 = 노란 분필 테두리, 경고 = 빨간 펜, 좋음 = 초록 분필, 주 완료·판정 = 도장 | 노랑 `#f0cf6b`, 빨강 `#dc5a4c`, 주황 `#e39a4e`, 초록 `#8fcf8a` |

낮·밤 색 언어(낮 상아색 / 밤 남색 / 둘 다 사선)는 그대로 둔다 — 이미 계획 보드·도크·보고가 이 색으로 읽히고 있고, 칠판 위에서 더 또렷해진다.

## 3. 화면별 설계

1. **타이틀**: 키 아트와 칠판 로고는 그대로. 메뉴는 나무 테 두른 차림표 칠판 한 장에 모으고, 단추는 분필 밑줄만 있는 줄 — 올리면 노란 분필로 바뀌며 오른쪽으로 밀린다.
2. **허브 상단 띠**: 칠판 윗테. 날짜는 제목 글꼴, 자원은 분필 칩, 메뉴 단추는 둥근 분필 테두리. 아래에 나무 테 2px.
3. **도크(14칸)**: 분필 받침. "한 주 실행"은 노란 분필로 칠한 가장 큰 단추 하나(화면에서 유일한 채운 노랑 = 주 행동).
4. **계획 보드**: 칠판 한 장이 아래에서 올라온다. 탭은 색 견출지 느낌(고른 탭만 노랑 밑줄), 카드·칸은 낮/밤 종이, 선생님 메모는 포스트잇.
5. **선생님 한마디**: 칠판 구석에 붙은 노란 포스트잇(잉크색 글, 손글씨).
6. **서랍 4종**: 지금의 종이·손글씨를 유지하고 바탕만 칠판 녹색으로 맞춘다. 카드 = 칠판 위 분필 테두리 칸.
7. **카드·하루 보고·토스트**: 테이프로 붙인 종이 한 장. 잉크색 글, 문단 머리는 파란 잉크, 대성공·실패는 빨강·초록 펜.
8. **대화**: 그림(이벤트 컷)을 가리지 않게 짙은 칠판 띠. 화자 이름은 종이 이름표, 선택지는 줄 공책 줄(올리면 노란 형광펜).
9. **전용 화면**(결산·출정 준비·배분·세력·설계도·엔딩·갤러리·음악실): 바탕 칠판, 판은 나무 테 두른 칠판, 주 단추만 노랑.
   - **리포트 그래프**(막 평가 카드·1년의 기록, 2026-11-28): 분필 막대. 막 평가 카드(종이 위)에서는 나무 테 두른 작은 칠판에, 엔딩 1년의 기록에서는 칠판 없이 반투명으로 뒤 그림이 비치게(사용자 결정 — 막대에 짙은 외곽선, 글자에 그림자). 시간 순서 계열은 노란 분필 한 색의 옅음 → 짙음, 시작은 테두리만 있는 빈 막대, 늘어남은 초록 분필 `+n`·줄어듦은 빨간 펜 `−n`(색만으로 구분하지 않게 부호를 붙인다), 눈금·이름은 흰 분필. 종이 카드 위에서도 그래프는 칠판이다(`.card .stat-chart-*`).
10. **탐험 HUD**: 분위기를 해치지 않게 최소. 위치·시계는 분필 글씨 + 얇은 칠판 띠, 배낭·전리품·미니창은 칠판 판, 장비 칸은 분필 테두리.
11. **디버그·밸런스 표**: 개발 도구라 모양을 바꾸지 않는다(색 변수만 따라온다).

## 4. 구현 방법

- `UI/Theme.uss`: 색 변수(`:root`)를 새 재질 값으로 바꾸고, 박혀 있던 회색 값들을 변수로 돌린 뒤, 맨 끝에 **"fablable 0.1" 절**을 더해 부품별 모양을 덮어쓴다. 배치·크기 규칙(그동안 맞춘 것)은 그대로 둔다.
- `UI/Expedition.uss`: 같은 방식.
- C#: 색이 박힌 곳만 고친다 — `FieldStyle`(입력 칸), 흐름 띠·그래프의 바탕색 등. 화면 구조·이름은 그대로.
- 글꼴: 제목류 = 학교안심 엣지, 종이 위 손글씨 = 부산단디손글씨, 본문 = 지금의 고딕. 숫자가 많은 곳(자원·막대)은 고딕 유지.

## 5. 하지 않는 것

- 배치를 크게 옮기지 않는다(다섯 겹·서랍 폭·보드 높이 유지). 새 그림·새 문구·새 화면 없음.
- 낮/밤 카드 색, 세력 단계 색, 인물 글줄 색은 뜻이 붙어 있어 그대로.
- main에는 넣지 않는다. 이 브랜치와 태그에만 남긴다.

## 6. 확인 방법과 한계

- 본 에디터는 main을 열고 있으므로, 워크트리를 따로 연 Unity 배치 모드(6000.6.8f1)에서 확인했다.
- **화면 그림으로 본 것** (임시 PlayMode 테스트가 UI 패널을 1920×1080 그림으로 떠서): 타이틀, 엔딩 갤러리, 음악실, 허브(20주차·전부 해금), 계획 보드, 생활기록부·거점·인물 서랍, 메뉴 카드, 하루 보고 카드, 방 패널, 토스트, 대화(이름표·선택지), 주간 결산 책.
- **틀만 본 것** (내용 없이 열어 봄): 배분·세력 거래·출정 준비. **겹쳐 찍혀 판단 못 한 것**: 탐험 HUD(허브 패널과 한 그림에 겹침 — 스타일 오류 없이 그려지는 것까지만 확인).
- **못 본 것**: 프롤로그 입력, 엔딩 연출, 설계도, 밤·정전 허브, 실행 중 결과 한 줄, 실제 탐험 화면 위 HUD. 실제 플레이에서 한 번 훑어야 한다.
- 확인하다 고친 것: 반투명 틀이 선형 색공간에서 많이 비쳐 상단 띠·도크·대화창을 불투명으로, 음악실 CD 표지가 제목을 덮던 것(기존 문제)에 여백.
- 캡처 도구는 커밋하지 않았다: `I:/workshop/code_temp/apogirl/tools/fablable_shots/`(테스트 파일·실행 스크립트·색 옮기는 도구·찍은 그림).
