## M1 코어 시뮬레이션 ✅

- 능력치·자원·턴(52주 × 7일 × 낮/밤 = 주 14칸)·행동 판정·세이브/로드. UI 없이 테스트로 검증한다.

깊은 곳 특별한 방을 넣은 뒤의 결과다. #16(사용자가 밸런스 표로 식단·수확을 맞춘 뒤)과 거의 같다.

| 묶음 | 전체 | 목표 |

| 기본 | 24% | 15~25% |

| 관계·서사 | 13% | 6~12% |
| 히든 | 2% | 1~3% |
| 배드 | 51% | 45~55% |

방향성:
- 특별한 방(#17)은 엔딩 묶음을 거의 흔들지 않았다. 다만 깊은 곳 CD 5장·진실 단서 2개는 헤드리스에서 방을 연 판만 나와 조금 드물어졌다.
- 식단 개편 뒤 100%였던 배드가 51%로 목표 안에 들었다. 굶주림 사망은 중후반(중앙 34주)으로 밀렸다.
- 전략 격차가 크다. MIXED 배드는 18%, NIGHT_ONLY·CARE 배드는 75%다. NIGHT_ONLY는 감염, DAY_ONLY는 굶주림이 많다.
- 특화는 목표 아래(12%, 거의 EDUCATION의 의사)이고, 관계·서사는 조금 넘친다(DAY_ONLY 직면).
- 마지막 조정 때 전략 격차와 특화 문턱부터 본다.

---|---|---|
| 기본 | 26% | 15~25% |

| 관계·서사 | 15% | 6~12% |
| 히든 | 3% | 1~3% |
| 배드 | 41% | 45~55% |

방향성:
- 프롤로그의 메아리(좋아하는 과목·성격 F·희망) 뒤로 배드가 44%에서 41%로 줄어, 목표 아래로 내려갔다.

   - 이벤트가 없어 보류한 컷: `evt_deep_door`·`evt_deep_oneway`·`evt_season_*`·`evt_cat_warn`, 그리고 `stand_item_*`.
