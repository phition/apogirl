### 지금 봇 결과 (BOT_ENDING_LOG #22, 2026-11-25, 표준 · 5전략 × 40판)

봇이 제작을 하게 된 뒤(제작 P7), MIXED 설비 칸을 설비 먼저로 둔 결과다(사용자 결정 2026-11-25).

| 묶음 | 전체 | 목표 |
|---|---|---|
| 기본 | 23% | 15~25% |
| 특화 | 8% | 15~25% |
| 관계·서사 | 14% | 6~12% |
| 히든 | 3% | 1~3% |
| 배드 | 53% | 45~55% |

방향성:
- 배드 49%(#20) → 59%(#21, MIXED 제작 먼저) → 53%. MIXED는 제작 전 그대로(생존 80%)이고, 제작은 거의 하지 않는다(판당 손전등 1번).
- 제작 효과가 보이는 전략은 EDUCATION 하나다. 교육 칸 하나를 제작에 내줘 생존 58→50%, 특화 48→30%로 줄었다.
- 1단계 가방(12칸, 지금은 장바구니)은 헤드리스 기준 칸(20)보다 작아 차면 수확이 준다. 봇은 만들지도 차지도 않는다.
- 마지막 조정 때 볼 것: 전략 격차·특화 문턱, 장비를 잃는 규칙과 다시 만드는 비용, 1단계 가방(장바구니) 칸 수, 자동 정수기 조건, 제작 위주 봇 전략을 따로 둘지.

---|---|---|
| 기본 | 26% | 15~25% |
| 특화 | 16% | 15~25% |
| 관계·서사 | 15% | 6~12% |
| 히든 | 3% | 1~3% |
| 배드 | 41% | 45~55% |

방향성:
- 프롤로그의 메아리(좋아하는 과목·성격 F·희망) 뒤로 배드가 44%에서 41%로 줄어, 목표 아래로 내려갔다.
- 관계·서사는 넘친다(15%). 대부분 DAY_ONLY의 직면 엔딩이다.
- 전략 사이 격차가 크다. MIXED 배드는 15%, NIGHT_ONLY 배드는 78%이고, EDUCATION은 특화가 65%다.
- 사망 원인은 감염이 가장 많다(56).
