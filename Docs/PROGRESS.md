## M1 코어 시뮬레이션 ✅

- 능력치·자원·턴(52주 × 7일 × 낮/밤 = 주 14칸)·행동 판정·세이브/로드. UI 없이 테스트로 검증한다.
- 진입점은 `NewGameFactory.Create`이고, 한 주는 `WeekRunner`가 돈다(`PrepareWeek` → `ExecuteNextSlot` × 14 → `FinishWeek`).
- 정의 DB는 `Assets/_Project/Data/DefinitionDatabase.asset`이다.
- 세이브 버전은 지금 v11이고, 옛 버전은 차례로 변환한다.

## M2 UI 프로토타입 ✅

## M2b 탐험 모드 프로토타입 ✅

- 횡스크롤 익스트랙션 탐험: 이동·은신·소음·수색·배낭(6×4)·추출·시간 시계.
- 낮(휴면 군집, 깨우지 않기)과 밤(활성 좀비, 어둠) 두 변형이 있다.
- 탐험 씬은 Additive로 연다. `ExpeditionRequest`/`ExpeditionResult`로 허브와 잇는다.
- 디버그 키는 F2~F9이다.
- 플레이 기록은 `PlayLogs/expeditions.jsonl`에 남는다. 이 기록으로 헤드리스 모델을 보정한다.

## 남은 작업 (해야 할 것)

순서는 권하는 차례다.

1. **안드로이드 모듈 지우고 메타 되돌리기**
   - 사용자가 Unity Hub → Installs → 6000.6.8f1 → 모듈에서 Android Build Support를 지운다.
   - 그 뒤 main에 남은 메타 약 3,400개(다시 붙은 안드로이드 블록)를 `git checkout`하거나 `code_temp/apogirl/tools/strip_android_meta.py`로 지운다.
2. **에셋 10차 연결**
   - `ArtInbox/sprites10/`에 그림이 들어오면 연결한다.
   - 대걸레 웅크려 걷기, 무기 공격 20프레임과 `Combat.ImpactAt` 다시 맞추기, `fx_hit_`, 좀비 맞음·쓰러짐, 새 동작 96묶음.
   - PixelLab 땜질 프레임(`patch_player_frames.py`)도 새 그림으로 바꾼다.
3. **M6-5 남은 연결**
   - 이벤트가 없어 보류한 컷: `evt_deep_door`·`evt_deep_oneway`·`evt_season_*`·`evt_cat_warn`, 그리고 `stand_item_*`.
   - CD 음원 8곡(8차 2.4절).
   - 고양이 임시 그림 `hub_cat`을 정식 그림으로 바꾼다.
4. **M7 최종 목표 맞추기** (D26: 마지막에 한 번에)
   - 봇을 다시 돌린다. 최근 전리품·좀비 행동·재해·타격 판정이 바뀌었다.
   - 엔딩 기준을 다시 맞춘다. 관계·서사가 넘치고 배드는 하한 근처다.
   - 전략 격차를 줄인다. NIGHT_ONLY·CARE 배드가 높고, 감염 사망이 많다.
   - 폭설 한파 `ForceChance`(0.8 → 0.6 검토)를 본다.
   - 장마 침수층의 실제 수확·위험을 플레이 기록으로 확인한다.
5. **M8 시작 — `M8_PLAN.md` 결정 필요 7개를 사용자가 정한 뒤**
   - M8-1 릴리즈 안전장치: 디버그 키를 개발 빌드에서만 켠다, 오류 기록, 세이브 백업·복구, 버전 표시.
   - M8-2 설정 화면, M8-3 접근성·주제 안내, M8-4 입력, M8-5 번역 구조, M8-6 성능, M8-7 스팀, M8-8 통독 플레이.
6. **빌드용량** — 4의 배수가 아닌 큰 그림 약 260장이 무압축이다. 사용자가 나중으로 미뤘다.
