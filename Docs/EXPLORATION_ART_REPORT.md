# 탐험 픽셀 아트 전면 교체 보고서 (2026-11-20)

PixelLab 유료 계정(Tier 1, 2,000회)으로 탐험 화면의 그림을 전부 다시 만들고, 이어서 받은 2차 요청(책상 방향·평면 모니터·가방 색·빛줄기 수·대걸레·층 가림·무너진 계단·바깥 길)까지 반영한 결과다.
생성 횟수는 약 1,350회를 썼고 약 650회가 남았다.

## 2. 만든 것

### 주인공 (1,600프레임)
- 이름 규칙: `player_{옷}_{무기}_{동작}_{0..15}`
- 옷: 교복(uniform), 보호대(guard), 패딩(padding), 진압복(riot)
- 무기: 맨손(none), 대걸레(mop), 야구방망이(bat), 쇠파이프(pipe), 진압봉(baton)
- 걷기·뛰기·웅크려 걷기는 첫 장과 끝 장이 같은 반복 동작이다.
- 공격은 "준비 → 내리침"과 "내리침 → 준비" 두 구간을 따로 만들고, 더 깨끗한 쪽을 거꾸로 이어 붙였다. 16프레임을 한 번에 뽑으면 몸이 돌아가거나 사람이 겹쳐 나와서 이렇게 했다.
- 대기 동작은 생성 결과에 입김·연기가 자주 섞였다. 15벌은 잡티를 지웠고, 5벌(보호대 맨손·파이프, 패딩 맨손, 진압복 맨손, 교복 진압봉)은 기본 자세에서 숨쉬기 동작을 직접 만들었다.

### 가방
- `bag_{school|hiking|tote}_{색}`. 붙일 자리는 프레임마다 머리와 몸통 위치를 찾아 계산해 `player_anchors.json`에 넣었다 (1,600개).

### 좀비·생존자·조우 인물
- 좀비: 대기·걷기·기절·휴면 등 16프레임. 생존자와 조우 인물(다친 사람 등)은 숨 쉬는 반복 동작.

### 환경
- 벽 23종: 복도, 교실, 양호실, 과학실, 음악실, 컴퓨터실, 가사실, 방송실, 교무실, 편의점, 마트, 약국, 가정집, 지하철, 거리, 골목 등
- 문 4종(학교·철문·가정집·가게, 닫힘·열림), 출구 2종(잠김 포함), 계단 3종(위·아래·무너짐), 이어 붙는 창문, 칠판
- 소품 약 320종: 컨테이너, 지역별 가구, 바닥·벽 장식, 바깥 길 소품(차·스쿠터·버스 정류장·가로등·모래주머니·셔터·공중전화 등 32종)

## 3. 바뀐 구조

- **그림 표** `Resources/Art/exploration_art.json` + `ExplorationArtMap.cs`: 어느 지역·방에 어떤 벽·문·소품·장식을 쓸지 데이터로 정한다. 그림이 없으면 예전 규칙과 코드 그림으로 돌아간다.
- **바깥 길** `BuildingView.BuildOutdoor`, `ExpeditionDirector`: 바깥 구역 두 개(진입로·탈출로), 통로(`TargetKind.Passage`), 소음·위협 연결. 길 너비는 `BalanceConfig.ApproachRoadWidth`(18)·`EscapeRouteWidth`(14).
- **무너진 계단** `ConnectorDef.Collapsed`, `LocationBuilder.Stairs(…, collapsedFrom)`.
- **조명** `ExplorationLighting`: 빛줄기·바닥 빛·방 창문 빛·먼지, 층마다 1~2곳. 수치는 모두 `BalanceConfig` 조명 절.
- **디버그** `ExpeditionDebug.Start/Room/SetClock`, `ExpeditionDirector.DebugGoTo`: 원하는 지역·장비·자리로 바로 가서 화면을 확인한다.
- 문서: `Docs/HIGGSFIELD_ASSETS.md` 8.3절, `Art/ThirdParty/Higgsfield/CREDITS.md`, `CLAUDE.md`.

## 5. 확인하지 못했거나 남은 것

- **지역 8곳 중 5곳의 실내는 화면으로 보지 않았다** (약국·주택가·지하철·경찰서·정수장). 그림 표는 채워져 있지만 배치가 어색한 곳이 있을 수 있다.
- **빛줄기 1~2곳**은 이번 판에서는 화면으로 다시 보지 않았다.
- **가방 색**은 빨강만 화면에서 봤다. 나머지 다섯 색은 그림으로만 확인했다.
- 자동 점검에 걸린 동작이 몇 개 있다: 진압복+대걸레의 뛰기·웅크려 걷기(몸 크기가 프레임마다 튐), 교복+진압봉의 공격. 눈으로 다시 봐야 한다.
- 패딩을 입고 웅크리면 가방이 몸에 가려 거의 보이지 않는다.
- 바깥 길의 먼 건물은 단색 사각형이다. 창문 줄이 건물 폭 전체에 걸쳐 있어 조금 단조롭다.
- 교실 칠판은 빈 벽이 없으면 창문과 겹쳐 보인다 (앞벽 유리 너머로 비치는 표현, 이전부터 그랬다).
- 테스트 빌드는 만들지 않았다 (메뉴 `ApoGirl/Build/Windows Test Build`를 직접 눌러야 한다).
- **푸시하지 않았다.** `main`이 `origin/main`보다 41커밋 앞서 있다.
