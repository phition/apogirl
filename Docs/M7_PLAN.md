### M7-1 봇 시뮬레이터 (쓰는 법)
- 메뉴 `ApoGirl/Balance/Run Bot Simulation` (전략마다 설정의 판 수) / `… (Quick, 5 per strategy)`. 실제 `DefinitionDatabase.asset`(지역·조우 포함)으로 돌린다. 200판에 약 4초.
- 결과: `Temp/BotSim/summary.md`(요약·M7-c 목표 대비), `runs.csv`(판별), `weeks.csv`(전략·주·지표별 평균·하위·상위 10%), `expeditions.csv`(전략·지역·낮밤별 쓰러짐·물림·수확).
- 전략·판 수·시드: `Assets/_Project/Balance/bot_strategies.json` (콘텐츠 폴더 밖, 개발 도구 데이터)
  - `Groups`: 행동 묶음 (`First` = 해금된 첫 행동, `Random` = 가중 무작위)
  - 전략의 `Day`·`Night`: 1~7일 칸마다 `"후보|후보"`. 안 되면 휴식
  - `Rules`(전략) → `CommonRules`(공통) 순으로 적용. `When`은 이벤트 조건과 같은 `ConditionDef`, `Slots`는 `D1`~`D7`·`N1`~`N7`
  - `ChoiceBias`: 이벤트 선택지 ID별 가중치 (기본 1, 0이면 고르지 않음). `EncounterFirstChoiceWeight`: 조우 첫 선택지 가중치
  - `PrologueGroups`: 성격 유형처럼 한 문항에서 여러 번 고르는 프롤로그. 나머지 문항(혈액형 등)은 무작위
- 봇의 판단 난수는 게임 난수와 따로 둔다. 같은 시드면 전략끼리 같은 세계에서 시작한다.
- 테스트 `M7BotTests`: 설정 점검(모르는 행동·묶음·칸), 밤 탐험 해금 전후, 공통 규칙, 선택 가중치, 프롤로그, 전략마다 한 판 끝까지 + 보고서.

### M7-2 맞출 목표 (문서 9.0)
- 1회 출정 기대 수익이 주 소모의 60~90%
- 쓰러짐률: 일반 지역 5~10%, 고위험 지역 20~30%
- 밤 탐험 실질 부담은 낮의 약 2배
- 낮만 / 밤만 / 혼합 전략의 생존율·엔딩 도달률 격차가 크지 않을 것
- 탐험 주 1~2회가 표준, 후반으로 갈수록 자원 압박이 서서히 오름(지금은 4막 식량이 200 안팎으로 남음)

### 탐험 추가: 적대적 생존자·교실동 상자 고갈 (2026-11-20, 사용자 요청)
- **적대적 생존자** (`EnemyDef.Kind = Survivor`, 데이터 `ENEMY_SURVIVOR`)
  - 좀비보다 시야(12)·청각(×1.8)·인지 속도(2.2)가 높고, 낮 활동 보정(좀비가 낮에 둔해지는 것)을 받지 않는다. 배회 반경이 넓다(14).
  - 경계(조사·추격·수색) 중에는 2.5 안에 숨은 사람을 찾아낸다 → 숨기 어렵다. 달리기 3.7 (주인공 4)이라 도망은 가능하다.
  - 붙잡히면 피해 대신 **대치**: 성향 문장 → 암전 → 귀환 (문서 13장 4항: 암전·짧은 문장, 구체 묘사 없음).
  - 등장·성향은 `HostileRules.Roll`이 출정 시드로 정해 요청(`ExpeditionRequest.HostileTemperament`)에 싣는다. 실시간·헤드리스가 같은 판정을 쓴다. 헤드리스는 생존자가 있으면 50%로 붙잡힌다.
  - 결과 `ExpeditionResult.Hostile`: 쫓겨남(스트레스 +4) / 강탈(얻은 것 전부 + 들고 간 소모품, 스트레스 +8) / 구타(강탈 + 무기, 체력 −40·최소 1 남김, 스트레스 +15, 트라우마 +1, 숨김 트라우마 회복 −3).
  - 값: `BalanceConfig` (Hostile*, Beaten*, *Trauma*), 지역별 배율·시작 위치: `LocationVariantDef.HostileChanceMultiplier`·`HostileSpots` (튜토리얼은 0).
  - 그림: 전용 그림이 오기 전까지 주인공 그림에 어두운 색을 얹어 쓴다.
- **교실동 상자 고갈** (`LocationDef.DepletingContainers`, 교실동만)
  - 상자 키(복도 `C{i}`, 방 `R{문}.{i}`)를 세이브 `Exploration.LootedContainers`에 기록. 다음 출정에서는 그 상자가 수색 완료·빈 상자로 나온다(낮·밤 공통).
  - 교실동 상자 152개. 헤드리스는 1회에 10개(`ExpeditionModelDef.ContainersPerRun`)를 뒤진 것으로 보고, 남은 상자가 10개 미만이면 수확이 그 비율로 준다.
  - 봇은 남은 상자가 1회분의 절반 미만이면 교실동을 고르지 않는다.
- 테스트 `M7HostileTests` 6개. EditMode 229/229.
