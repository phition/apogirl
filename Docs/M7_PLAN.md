### M7-1 봇 시뮬레이터 (쓰는 법)
- 메뉴 `ApoGirl/Balance/Run Bot Simulation` (전략마다 설정의 판 수) / `… (Quick, 5 per strategy)`. 실제 `DefinitionDatabase.asset`(지역·조우 포함)으로 돌린다. 200판에 약 4초.
- 결과: `Temp/BotSim/summary.md`(요약·M7-c 목표 대비), `runs.csv`(판별), `weeks.csv`(전략·주·지표별 평균·하위·상위 10%), `expeditions.csv`(전략·지역·낮밤별 쓰러짐·물림·수확).
- 전략·판 수·시드: `Assets/_Project/Balance/bot_strategies.json` (콘텐츠 폴더 밖, 개발 도구 데이터)
  - `Groups`: 행동 묶음 (`First` = 해금된 첫 행동, `Random` = 가중 무작위)
  - 전략의 `Day`·`Night`: 1~7일 칸마다 `"후보|후보"`. 안 되면 휴식
  - `Rules`(전략) → `CommonRules`(공통) 순으로 적용. `When`은 이벤트 조건과 같은 `ConditionDef`, `Slots`는 `D1`~`D7`·`N1`~`N7`
  - `ChoiceBias`: 이벤트 선택지 ID별 가중치 (기본 1, 0이면 고르지 않음). `EncounterFirstChoiceWeight`: 조우 첫 선택지 가중치
  - `PrologueGroups`: 성격 유형처럼 한 문항에서 여러 번 고르는 프롤로그. 나머지 문항(혈액형 등)은 무작위
- 봇의 판단 난수는 게임 난수와 따로 둔다. 같은 시드면 전략끼리 같은 세계에서 시작한다.
- 테스트 `M7BotTests`: 설정 점검(모르는 행동·묶음·칸), 밤 탐험 해금 전후, 공통 규칙, 선택 가중치, 프롤로그, 전략마다 한 판 끝까지 + 보고서.

### M7-2 맞출 목표 (문서 9.0)
- 1회 출정 기대 수익이 주 소모의 60~90%
- 쓰러짐률: 일반 지역 5~10%, 고위험 지역 20~30%
- 밤 탐험 실질 부담은 낮의 약 2배
- 낮만 / 밤만 / 혼합 전략의 생존율·엔딩 도달률 격차가 크지 않을 것
- 탐험 주 1~2회가 표준, 후반으로 갈수록 자원 압박이 서서히 오름(지금은 4막 식량이 200 안팎으로 남음)

## 진행 기록

### M7-0 (2026-11-20)
- **수혈 (D16)**
  - 규칙 `BloodRules.CanDonate` (ABO만): O → 모두, AB ← 모두, 같은 형끼리. 모르면 부적합.
  - 조건 값 `BloodCompatible`(Key = 받는 사람 혈액형): 주인공이 줄 수 있으면 1. `Flag`(Key = 플래그): 켜져 있으면 1 → `AnyChecks`로 "직접 수혈 또는 혈액 팩"을 표현.
  - 연구 자료를 얻은 뒤 밤에 보건실 교직원 건강 기록 이벤트가 하나 뜬다(주인공 혈액형에 따라 `EVT_A4_BLOOD_MATCH` / `MISMATCH` / `UNKNOWN`). 플래그 `TEACHER_BLOOD_KNOWN`, 부적합·모름이면 `NEED_BLOOD_PACK`.
  - 약국 밤 2층 의원 처치실에 조우 `BLOOD_FRIDGE`(보냉 상자, `NEED_BLOOD_PACK`일 때만) → `BLOOD_PACK`.
  - 완치 시도 `EVT_A4_CURE_ATTEMPT`: `TEACHER_BLOOD_KNOWN` + (적합 또는 혈액 팩). 선택지 `TREAT_SELF`(직접 수혈, 체력 −15·피로 +20) / `TREAT_PACK`(팩 소모) / `WAIT`. 성공률 30%는 그대로.
- **헤드리스 조우**
  - `EncounterRules`: 활성 조우 판정·선택 기록 플래그를 실시간 탐험과 헤드리스가 같이 쓴다.
  - 무사히 돌아온 헤드리스 탐험은 조건이 맞는 조우마다 `ExpeditionYield.EncounterChance`(기본 0.5, 데이터로 덮어씀)로 만나고 `IEncounterChooser`(기본 무작위)로 고른다. 기존 굴림 뒤에 굴려 자원 결과는 바뀌지 않는다.
  - 지역 정의가 없는 DB(콘텐츠 JSON만 읽는 막별 테스트)에서는 조우가 없다. 봇 시뮬레이터(M7-1)는 지역이 든 실제 DB를 쓴다.
- 조우 정의에 `SpriteKey`(탐험 화면 그림) 추가. 혈액 팩은 `prop_fridge`.
- 테스트: `M7Tests`(혈액형 표, 혈액형별 기록 이벤트, 부적합이면 팩 필요, 직접 수혈 부담, 헤드리스 조우 3종). EditMode 214/214.
- 디버그: 허브 F1 "지역·시설 전부 해금"이 데이터의 모든 탐험 지역·시설을 연다(2~4막 지역 누락 수정).

### M7-1 (2026-11-20)
- 코어 `ApoGirl.Core.Simulation.Bots`: `BotPlanner`(주간 틀·규칙·설정 점검), `BotEventChooser`·`BotEncounterChooser`(가중 무작위), `BotSimulator`(프롤로그 → 시작 이벤트 → 52주 → 엔딩), `BotReport`(CSV·요약). 설정 읽기 `Systems.Content.BotConfigJson`, 메뉴 `Editor/BotSimulationMenu`.
- 프롤로그 효과 합치기를 `Core.Rules.PrologueRules`로 옮겨 화면(`PrologueFlow`)과 봇이 같이 쓴다.
- 전략 5종: `DAY_ONLY`(낮 주 2회) / `NIGHT_ONLY`(밤 주 2회, 해금 전엔 낮) / `MIXED`(낮 1 + 밤 1) / `EDUCATION`(탐험 주 1~2회, 의학·인문 위주, 밤 공부) / `CARE`(밤 대화·돌봄, 받아들이는 선택). 공통: 감염 25↑ 처치, 체력 35↓ 탐험 대신 휴식, 선생님 재감염 시 돌봄. 식량·물 20↓이면 그 자원이 많은 곳으로 간다.
